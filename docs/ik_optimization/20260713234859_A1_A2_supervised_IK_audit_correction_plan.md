# A1/A2 有监督逆运动学诊断审计修正计划

## 一、问题定义

本计划针对 A1/A2 单点磁化导管的有监督逆运动学失败现象。这里的“有监督逆运动学”是指：外层调整八路线圈电流和推进量，内层调用正运动学求解导管平衡形态，并用真实刚性末端位置误差判断外层更新是否有效。

当前固定基线如下：

- 重力：关闭。
- 空间离散：`M_list=5`。
- 正运动学容差：`1e-5`。
- 电流范围：`[-20, 20] A`。
- 推进范围：`[0.003001, 0.203] m`。
- 成功判据：最后刚性段远端的真实末端误差小于 `5 mm`。
- 计算设备：必须使用 GPU。

本轮多智能体审查认为，当前主要问题不是正运动学求解器明显错误，而是外层逆运动学把“局部平衡分支附近可信的控制方向”误用为“冷启动全局搜索空间”。因此，后续修正重点应从“继续收窄控制通道”转为“先进入可行吸引域，再做局部可靠精修”。

## 三、核心诊断结论

### 3.1 通道审计结论不能脱离状态来源

外层局部模型可写为：

\[
\Delta \mathbf p \approx \mathbf J(\mathbf c^\*, \mathbf z^\*) \Delta \mathbf c ,
\]

其中 \(\mathbf c^\*\) 是当前电流和推进量，\(\mathbf z^\*\) 是正运动学求得的平衡状态。灵敏度矩阵 \(\mathbf J\) 只在该状态附近有效。如果审计状态来自失败态或不同平衡分支，就不能直接迁移到成功态或冷启动阶段。

因此，后续所有通道分类必须绑定：

- 实验目录；
- Git 提交号；
- 状态类型，即历史最小误差状态或最后接受状态；
- 控制量；
- 平衡分支回环误差；
- 有效步长窗口。

### 3.2 强门控不应作为冷启动主路径

通道门控是指只允许通过审计的控制通道参与更新。它适合用于局部精修，不适合直接定义全局搜索空间。若门控后有效控制维数小于目标空间维数，外层更新难以完成三维末端定位。

A1-pt01 是关键反例：无门控可达到 `3.614 mm`，强门控后退化为 `93.908 mm`。这说明当前门控策略破坏了进入目标吸引域的能力。

### 3.3 A1-pt13 与 A2 仍不能生产放行

A1-pt13 目前只证明存在小步长有限使用通道，尚未证明存在稳定生产级通道。A2 的代表点仍有较强状态依赖和分支不稳定风险，不应进入正式全量实验。

## 四、修正总体路线

后续采用分层外层求解策略。

### 4.1 第一阶段：全局入盆

目标是在不使用硬门控的情况下，将真实末端误差拉入局部精修可工作的范围。

建议设置：

- 不启用硬门控，或仅启用软约束。
- 允许较大步长，例如单步电流上限 `5 A`、推进上限 `20 mm`。
- 接受准则以真实末端误差为主，但允许总目标函数明显改善时的短期非单调变化。
- 当真实末端误差小于 `10-15 mm`，或有效控制秩稳定后，进入局部精修。

### 4.2 第二阶段：局部可靠精修

目标是在已经接近目标的同一平衡分支附近，使用审计通过的通道进行小步更新。

建议设置：

- 启用硬门控。
- 只使用生产级通道；有限级通道必须绑定更小步长。
- 单步电流上限可降至 `0.125 A` 或审计给出的有效窗口。
- 恢复严格真实末端优先接受。
- 每次使用有限级通道后记录裁剪前后步长，禁止静默超窗。

### 4.3 第三阶段：候选池与热启动修正

当前流程主要继承上一个成功点的电流和推进量，失败点的历史最优接受状态没有充分利用。后续应引入候选池：

- 保存每个点的前若干个历史最优接受状态。
- 候选排序依据包括真实末端误差、目标角度邻近性、平衡分支回环误差和控制边界余量。
- 对失败点允许从多个候选短跑，而不是只沿用单一热启动。
- 只有通过平衡分支检查的候选才允许传给后续点。

## 五、阶段性实施计划

### P0：证据来源和记录口径修正

目标：确保后续每个结论都可追溯。

任务：

- 修正报告中“是否启用门控”的文字口径，避免出现机器记录与正文不一致。
- 在点级结果中记录状态来源、状态哈希、Git 提交号、入口脚本、设备信息和有效运行边界。
- 区分物理配置文件中的最大长度和本轮实际推进搜索上限。
- 对子集实验继续标记为小回归，不纳入正式 20 点统计。

验收：

- 三点小回归的每个点都能追踪到输入状态和输出状态。
- 报告、`summary.json`、`summary.csv` 对门控状态的描述一致。

### P1：代表点双状态全通道审计

目标：确认哪些控制通道在当前状态附近真正可信。

对象：

- A1：pt01、pt12、pt13。
- A2：pt05、pt17、pt19。

每个点至少审计两个状态：

- 历史最小真实末端误差状态。
- 最后接受状态。

每个状态审计九个控制通道：

- 八路线圈电流；
- 推进量。

分类：

- 生产级：回环通过，强响应相对误差不超过 `5%`。
- 有限级：回环通过，强响应相对误差不超过 `10%`，且只允许小步使用。
- 分支失败：回环误差超过门限。
- 弱响应：控制通道对真实末端几乎无作用。
- 超限：误差超过 `10%`。
- 未审计：没有有效数据。

验收：

- 同一点不同状态结论冲突时，不得进入 P2，必须先做状态来源归一化。
- A2 若三代表点中少于两个点具备可用低维更新子空间，则不得进入 A2 小回归。

### P2：A1 三点分层策略小回归

目标：验证“先全局入盆，再局部精修”是否修复强门控退化。

必须运行四组同预算对照：

1. 无门控大步长对照。
2. 强门控但恢复大步长，用于隔离小步长影响。
3. 前若干接受步无门控大步长，接近后切换为门控小步长。
4. 从无门控近解状态开始，只测试局部门控精修。

验收：

- A1-pt01 不得从 `3.614 mm` 显著退化，最终应进入 `5 mm`。
- A1-pt13 应进入 `5 mm`，或给出唯一主因标签。
- A1-pt12 至少相对强门控结果改善 `20 mm`，且不能只以增加迭代次数换取无效下降。

### P3：A1 五点和十点扩展

目标：验证分层策略不是三点特化。

准入：

- P2 中 A1-pt01 稳定成功。
- A1-pt13 得到成功或明确单一主因。
- 报告中没有状态来源错位或门控口径冲突。

验收：

- 五点小回归中，已有成功点不得退化。
- 十点回归中，失败点必须具备唯一主因分类。

### P4：A2 代表点与小回归

目标：在 A1 共享外层逻辑稳定后，再验证 A2。

准入：

- A1 分层策略稳定。
- A2 三代表点完成双状态全通道审计。
- A2 代表点至少两个具备有效更新子空间。

验收：

- A2 小回归不得出现大规模拒绝停滞。
- 所有失败点必须给出灵敏度、分支、步长、控制维数或疑似可达边界中的唯一主因。
