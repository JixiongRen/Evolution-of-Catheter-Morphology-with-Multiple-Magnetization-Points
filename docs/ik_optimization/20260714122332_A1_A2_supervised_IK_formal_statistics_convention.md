# A1/A2 有监督逆运动学正式统计口径说明

## 一、目的

本文档固定 A1/A2 有监督逆运动学实验的统计口径，避免把冷启动能力、热启动延拓能力、人工初值验证和分支状态重放混为同一类成功率。

从本文档建立后，所有正式报告必须同时给出原始命中率和分账命中率。只有严格满足冷启动条件的结果，才允许计入“冷启动算法成功率”。

## 二、末端定义

正式成功判据只使用最后刚性段远端，即真实物理末端。柔性段末端只作为诊断量记录，不能作为成功判据。

台账字段约定如下：

| 字段 | 含义 | 是否作为正式成功判据 |
|---|---|---|
| `err_true_mm` | 最后刚性段远端到目标点的误差 | 是 |
| `err_flex_mm` | 柔性段末端到目标点的误差 | 否 |
| `success_true_tip_5mm` | 由 `err_true_mm <= 5` 重新计算得到 | 是 |
| `success_flex_tip_5mm` | 由 `err_flex_mm <= 5` 重新计算得到 | 否 |
| `success_5mm_raw_field` | 原始结果文件中的旧成功字段 | 否 |
| `success_5mm_convention_drift` | 旧字段与真实末端口径是否不一致 | 诊断用 |

## 三、结果分类

| 类别 | 定义 | 是否计入冷启动算法成功率 |
|---|---|---|
| 冷启动成功 | 标准初始形态起步，不加载历史分支状态，真实末端误差不超过 `5 mm` | 是 |
| 失败后冷重启成功 | 前一点失败后重新从冷启动状态出发并成功 | 单独统计 |
| 邻点延拓成功 | 使用相邻目标点或旧成功点控制量作为初值并成功 | 否 |
| 人工初值成功 | 手动给定控制量或历史控制量作为初值并成功 | 否 |
| 分支状态重放成功 | 加载历史平衡状态后成功 | 否 |
| 阶段辅助结果 | 入盆阶段、精修阶段、烟测或零迭代验证结果 | 否 |
| 来源不明结果 | 缺少初值来源或分支来源字段 | 否 |

## 四、冷启动成功硬门禁

一条结果只有同时满足以下条件，才可计入冷启动算法成功率：

1. `success_true_tip_5mm=true`。
2. `initial_branch_state_enabled=false`。
3. `branch_state_warm_start=false`。
4. `warm_start_source` 表示标准冷启动来源。
5. `algorithm_statistics_included=true`。
6. 没有超时。
7. GPU 环境有效。
8. 结果、摘要、报告、图像均使用真实末端口径。

不满足任一条件时，结果必须进入其他分账类别。

## 五、报告最低要求

每份正式报告至少列出：

1. 原始 `success_5mm` 字段命中数。
2. 真实末端 `5 mm` 命中数。
3. 严格冷启动成功数。
4. 失败后冷重启成功数。
5. 邻点或旧成功点延拓成功数。
6. 人工初值成功数。
7. 分支状态重放成功数。
8. 分支回环停滞数。
9. 旧成功字段与真实末端口径漂移数。

其中，只有第 3 项可称为冷启动算法成功率。

## 六、A1/A2 当前口径结论

截至 2026 年 7 月 14 日，当前完整 40 点基线的原始 5 mm 命中数为 `11/40`，但严格冷启动成功数为 `0/40`。因此，不得再把 `A1 7/20、A2 4/20` 表述为冷启动算法成功率。

更准确的表述为：当前完整 40 点基线证明了若干点存在延拓可达、路径依赖可达或分支状态重放可达证据，但尚未证明标准冷启动能够稳定达到这些目标点。

## 七、后续使用方式

1. 每次重新生成台账时，必须使用 `DELIVER_TO_EXP/audit_supervised_ik_success_ledger.py` 重新计算真实末端成功字段。
2. 若旧字段与新字段存在漂移，必须先解释漂移来源，再讨论成功率。
3. 任何热启动、人工初值、分支状态重放和阶段辅助结果，都只能作为诊断证据，不能进入冷启动算法成功率。
