# A1/A2 有监督逆运动学诊断审计后的修正计划

## 一、文档目的

本文依据 2026 年 7 月 13 日完成的 A1/A2 有监督逆运动学诊断、灵敏度审计、小步回环审计和 P2 外层求解器烟测结果制定。目标是把当前诊断结论转化为可执行、可审计、可回退的代码修正与实验路线。

本文只适用于当前固定条件：

- 无重力。
- `M_list=5`。
- 前向运动学容差 `1e-5`。
- 电流范围 `[-20,20] A`。
- 推进范围 `[0.003001,0.203] m`。
- 真实末端定义为最后刚段远端。
- 成功阈值为真实末端位置误差不超过 `5 mm`。
- 交付对象为 A1 轴向单点磁化导管和 A2 径向单点磁化导管。

如果后续加入重力、末端姿态、双磁体、不同网格或不同容差，必须重新执行本文的前置门禁。

## 二、多智能体审查结论

本轮并行审查从三个角度展开：方案扩展、反方审查和风险审查。三方结论基本一致，但反方审查对证据口径提出了更严格要求。

### 2.1 已经可以成立的结论

1. 当前不能简单认为 IK 整体不可用。更准确的表述是：旧灵敏度主故障已基本定位，剩余问题集中在平衡分支保持、局部线性有效域过小、少数控制通道稳定偏差和外层步长策略失效。
2. 当前主灵敏度路线应采用残差空间奇异值分解。残差空间奇异值分解是指直接在残差方程的一阶线性化上求解状态对控制量的导数，避免使用法方程导致病态程度放大。
3. `svd_rcond=1e-9` 是当前较合理的工作点。A1-pt12 在更粗截断下曾出现明显幅值偏差，改为 `1e-9` 后明显改善；进一步改为 `1e-10` 没有显示稳定收益。
4. A1-pt01、A1-pt12 已有较可信的同分支局部灵敏度证据。
5. A1-pt13 的问题不是单纯扰动步长过大。其电流通道在缩小到可回环步长后仍有约 `25%--40%` 的灵敏度偏差，说明该局部状态附近不能使用完整九维控制更新。
6. A2 不是整体灵敏度崩溃。A2-pt05、A2-pt17 在小步或分段回环后进入或接近门禁，说明主要问题是步长和路径；A2-pt19 的一个电流通道仍存在稳定偏差。
7. P2 外层求解器烟测只能证明代码路径可运行，不能证明根因已经修复。

### 2.2 当前不能外推的结论

1. 不能把 A1 三个代表点的审计结果写成 A1 导管级 P1 通过。
2. 不能把 A2-pt05、A2-pt17 的改善外推成 A2 已经可以进入全量正式修正。
3. 不能把 P1 的末端位置局部导数一致性外推成外层目标函数、边界投影、电流正则项和推进耦合项的预测下降全部正确。
4. 不能把 `best_accept` 状态的灵敏度审计当作失败态附近的灵敏度已经可信。`best_accept` 是按历史最小末端误差反选出的状态，存在乐观偏差。
5. 不能继续用自动选择最大响应电流通道的方式给出整体结论。后续必须预注册失败通道和代表通道。
6. 不能把当前代码中的真实末端定义统一外推到所有历史产物。历史数据中若出现 `tip_p_dim`、`rigid_mid_*`、`terminal_p_dim` 混用，必须单独标注口径。
7. 不能把采样未覆盖目标写成物理不可达。当前可达性采样证据仍弱，只能作为后续困难点分析的辅助依据。

## 三、当前核心卡点

### 3.1 灵敏度只在部分状态和通道上可信

控制向量为：

\[
\mathbf c=[I_1,\ldots,I_8,x]^T .
\]

理想情况下，末端位置对控制量的局部导数应满足：

\[
\Delta \mathbf p \approx \mathbf J_{\mathbf p,\mathbf c}\Delta \mathbf c .
\]

但在平衡分支跳变或局部线性区域过小时，同一个有限差分扰动得到的 \(\Delta \mathbf p\) 不再对应同一条平衡分支。此时即使公式本身正确，也无法用该差分样本验证灵敏度。

当前证据表明：

- A1-pt13 的部分电流通道属于局部坏方向。
- A2-pt05、A2-pt17 更接近步长和路径问题。
- A2-pt19 的一个电流通道属于稳定偏差通道。

### 3.2 外层优化器不能继续默认九维全量更新

旧外层求解在大量失败点上表现为阻尼增大、步长趋零和平台停滞。这是失败表征，不是根因。可能原因包括：

- 灵敏度通道不可靠。
- 步长超出局部线性有效域。
- 边界投影后实际步长与预测步长不一致。
- 平衡分支发生跳变。
- 控制正则项压制了有效电流方向。

因此，下一步不能只调阻尼参数，而应引入受限更新策略：只沿可信子空间更新，并在每次接受前核对真实末端误差是否改善。

### 3.3 证据链仍需闭环

已有 P0 证明部分状态可以重载，但还不能证明新代码能复现旧失败分类，也不能证明旧失败根因完全解释清楚。因此正式修正前必须补一个 P0.5：

- 对六个代表点比较旧运行和新运行的最终误差、终止原因、最终控制量、灵敏度配置和状态文件完整性。
- 若旧运行和新运行分类不同，应先解释差异，不能直接用新运行结论解释旧失败。

## 四、修正总路线

推荐路线为：

\[
\text{P0.5 证据闭环}
\rightarrow
\text{P1 预注册灵敏度审计}
\rightarrow
\text{P1b 异常通道收口}
\rightarrow
\text{P2 外层受限优化器对照}
\rightarrow
\text{A1 十点小回归}
\rightarrow
\text{A1 二十点正式回归}
\rightarrow
\text{A2 受限子空间小回归}
\]

A2 不应直接进入全量回归。A2 必须先处理 pt19 的稳定偏差通道，并把结论限定为受限子空间可控。

## 五、分阶段修正计划

### P0.5：新旧运行证据闭环

#### 目标

确认当前代码、当前参数和当前状态保存逻辑能复现实验分类，避免用不可比运行解释旧失败。

#### 代表点

- A1：pt01、pt12、pt13。
- A2：pt05、pt17、pt19。

#### 任务

1. 读取旧正式实验输出和当前新运行输出。
2. 对比每个点的最终真实末端误差、最终控制量、终止原因、FK 状态分类、灵敏度配置、P2 配置和状态清单完整率。
3. 检查实际识别点列表是否与命令中预期点列表一致。
4. 检查真实末端定义是否为最后刚段远端。
5. 检查 GPU 设备、首次编译时间、稳态运行时间和 FK 调用数。

#### 验收

- 六个代表点均有完整 `run_config.json`、`result.json`、`formal_point_summary.json` 和状态清单。
- 若新旧分类不同，必须给出唯一原因标签。
- 不允许再出现“命令写了六点，实际只跑三点”的情况。

### P1：预注册灵敏度审计

#### 目标

消除 `best_accept` 和自动通道选择带来的乐观偏差，建立可用于外层优化的真实灵敏度证据。

#### 状态选择

每个代表点至少审计两类状态：

- `last_accept`：最后一次接受状态。
- `best_accept`：历史最小真实末端误差状态，仅作辅助对照。

必要时加入 `final_state`，用于解释终止点附近的实际优化行为。

#### 通道选择

预注册通道，不再只由被测雅可比自动选择：

- A1-pt13：电流通道 3、4。
- A2-pt05：电流通道 1、3。
- A2-pt17：电流通道 4。
- A2-pt19：电流通道 5。
- 推进量通道必须保留。

#### 审计方法

1. 固定 `residual_svd + hard + svd_rcond=1e-9` 为基线。
2. 对强响应通道做中心差分，差分两侧均从同一基准状态启动。
3. 每个扰动状态必须返回基准控制量做回环检查。
4. 只统计通过回环门禁且非弱响应的样本。
5. 弱响应样本改用绝对位移误差评价，不用相对误差评价。

#### 验收

- 强响应可审计样本中位误差不超过 `5%`。
- 强响应可审计样本 90 分位误差不超过 `10%`。
- 方向夹角 90 分位不超过 `15 deg`。
- 回环后真实末端偏差不超过 `0.25 mm`，中心线最大偏差不超过 `0.5 mm`。

### P1b：异常通道收口

#### 目标

把 A1-pt13 和 A2-pt19 的坏通道转化为外层优化器可使用的明确规则。

#### 任务

1. 对 A1-pt13 的电流通道 3、4 建立安全步长图谱。
2. 对 A2-pt19 的电流通道 5 做谱参数、小步和分段回环复核。
3. 对无法通过门禁的通道标记为不可靠方向。
4. 输出每个状态的可靠控制子空间。可靠控制子空间是指只包含通过同分支和预测准确性门禁的控制方向集合。

#### 验收

- A1-pt13 必须明确是“可在降维子空间优化”还是“需要分支候选池”。
- A2-pt19 通道 5 若仍不过门禁，必须在 A2 小回归前降权或剔除。
- 每个异常通道必须有唯一主因标签：分支失败、灵敏度偏差、局部线性域过小、弱响应或边界限制。

### P2：外层受限优化器修正与对照

#### 目标

把可信灵敏度转化为可收敛的外层控制更新。

#### 主要修正

1. 启用物理信赖域。物理信赖域是指在电流和推进量的真实尺度上限制每轮控制变化，避免一步跨出局部线性有效区。
2. 启用真实末端误差优先接受。只有真实末端误差改善且 FK 平衡通过，才允许接受关键更新。
3. 启用可靠子空间。对有效秩不足、回环失败或通道偏差过大的状态，禁止完整九维更新。
4. 投影后重新计算预测下降，避免边界裁剪后仍沿用裁剪前预测。
5. 最多做 3 次回溯。若仍失败，则重新线性化或切换初值，不继续盲目增大阻尼。
6. 对 `r_Ix` 做门控。`r_Ix` 是电流和推进量耦合正则项；当推进变化很小时，该项可能过度压制纯电流更新，应只在有明确物理必要时启用。

#### 必须做的对照

在六个代表点上做同预算对照：

- 旧外层策略。
- P2 全策略。
- P2 去掉可靠子空间。
- P2 保留可靠子空间但不关闭 `r_Ix`。

#### 验收

- 旧成功点不退化到 `5 mm` 之外。
- 接受步不应频繁出现真实末端误差变差。
- 阻尼不应无解释增长到 `1e5` 以上。
- 每个失败点必须有唯一主因标签。
- P2 烟测不得作为正式成功证据，正式证据必须来自代表点对照。

### P3：A1 小回归与正式回归

#### 目标

优先使 A1 达到可交付的无重力位置控制水平。

#### 流程

1. 先运行 A1 十点小回归，点位覆盖圆周不同象限和历史困难点。
2. 若十点中旧成功点不退化，且总体趋势改善，再运行 A1 二十点。
3. 若十点中出现大量分支失败，则插入有限候选初值池，不直接跑二十点。

#### 验收

最低通过线：

- A1 至少 `15/20` 进入 `5 mm`。
- 旧成功点保持成功。
- 失败点均有唯一主因。

交付候选线：

- A1 至少 `15/20` 进入 `5 mm`。
- 真实末端误差中位数不超过 `3 mm`。
- 95 分位不超过 `10 mm`。
- 复测分类一致率不低于 `90%`。

### P4：A2 受限子空间推进

#### 目标

在不伪造全维可控性的前提下推进 A2。

#### 前置条件

- A2 三个代表点中至少两个点通过预注册强通道门禁。
- A2-pt19 通道 5 若仍失败，必须被显式降权或剔除。
- 报告中必须写明 A2 当前是受限子空间可控，而不是完整九维全局可控。

#### 验收

- A2 六点小回归相比旧基线有一致改善。
- 旧成功点不退化。
- 失败点不再被简单归因为阻尼过大，而必须有物理或数值主因。

### P5：残余困难点可达性分析

#### 目标

只对修正后仍失败的点分析是否可能超出当前导管和驱动系统的有效工作区。

#### 原则

1. 不优先做全域大采样。
2. 优先围绕历史最佳控制附近做局部加密。
3. 新采样若不能把最近距离改善至少 `5 mm`，停止同类采样。
4. 除非存在解析物理上界，否则不得写作严格不可达，只能写作高度疑似不可达。

## 六、实验记录与图像要求

每轮实验必须保存：

- 中文 `record.md`。
- 完整 `commands.sh`。
- 标准输出和标准错误。
- `run_config.json`、`result.json`、`formal_point_summary.json`。
- 状态清单和状态文件。
- 汇总 CSV/JSON。
- 中文图像。

图像必须记录实际使用的中文字体。若字体缺失，应先修复字体配置再重绘，不得把乱码图作为正式结论。

## 七、版本管理要求

1. 每轮大实验结束后提交到本地 `ik_optimize` 分支，不推送远程。
2. 提交前必须记录拟提交文件清单。
3. 代码、计划文档和小型摘要图表可以提交。
4. 大型可重生成原始数组应优先保留本地，不应盲目纳入版本库。
5. 不要把无关历史输出、临时归档和当前修正代码混入同一次提交。

## 八、最终推荐执行顺序

1. 补 P0.5 新旧运行证据闭环。
2. 补 P1 预注册通道审计，修正 `best_accept` 和自动通道选择的乐观偏差。
3. 对 A1-pt13 和 A2-pt19 做异常通道收口。
4. 在六个代表点上做 P2 外层优化器同预算对照。
5. 若代表点对照通过，运行 A1 十点小回归。
6. 若 A1 十点小回归通过，运行 A1 二十点正式回归。
7. A1 达到最低线后，再推进 A2 受限子空间六点小回归。
8. 对修正后仍失败的点开展残余可达性分析。

当前最保守结论为：

- A1 已具备进入外层受限优化试验的条件，但还不能称为正式修复完成。
- A2 的灵敏度和分支门禁尚未完全关闭，不能直接进入全量修正声明。
- 下一步的核心不是继续更换灵敏度公式，而是把可信灵敏度限制在可信步长和可信子空间内使用。
