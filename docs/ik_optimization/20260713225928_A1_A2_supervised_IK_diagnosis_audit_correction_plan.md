# A1/A2 有监督逆运动学诊断审计修正计划

## 一、文档目的

本文档汇总本轮多智能体审阅结果，面向 A1/A2 单点磁化导管的有监督逆运动学修正工作，给出可执行、可验收、可追溯的后续计划。

这里的有监督逆运动学，是指外层优化 8 路线圈电流和推进量，内层每一步调用正运动学求解器计算平衡姿态，并以最后刚段远端的真实末端位置误差作为主要评价指标。

当前首要目标不是直接提高 20 点圆周任务成功率，而是先把失败原因拆清楚：灵敏度是否可信、单步线性预测是否可靠、正运动学平衡分支是否保持一致、外层优化器是否使用了过大的控制步长，以及目标是否可能接近可达边界。

## 三、多智能体审阅共识

### 3.1 当前失败性质

当前失败是混合故障，不宜归结为单一原因。按证据强度排序为：

1. 灵敏度质量不足或局部线性窗口过窄。
2. 外层控制步长过大，或可靠控制子空间选择不稳。
3. 正运动学平衡分支和初值连续性存在风险。
4. 物理不可达目前证据最弱，不能作为主结论。

A1-pt13 曾达到约 `5.777 mm` 的真实末端误差，说明该点至少接近可达边界。因此，现阶段不能把失败写成“目标物理不可达”。更严谨的表述是：局部线性模型和分支保持条件尚不足以稳定把误差压入 `5 mm`。

### 3.2 灵敏度模式结论

残差奇异值分解灵敏度，代码名 `residual_svd`，应作为当前唯一主线。其含义是：在正运动学残差空间内对雅可比矩阵进行奇异值分解，再求取控制量对真实末端响应的局部线性近似。

尺度化高斯牛顿灵敏度，代码名 `gn_svd`，可作为一致性对照，不建议单独驱动正式外层优化。

求解器响应版，代码名 `solver_response`，以及驻点方程精确版，代码名 `stationarity_exact`，应降级为诊断项。它们在多个同分支有效样本上出现约 `70%` 到 `100%` 的相对误差，不能作为可信更新源。

### 3.3 A1 可信通道

当前通道结论只对本轮保存状态、当前代码提交和对应审计设置成立，不能跨批次直接复用。

| 点位 | 可生产使用通道 | 可有限使用通道 | 禁止或诊断通道 |
|---|---|---|---|
| A1-pt01 | I1、I3、推进量 | 无 | I2、I4 回环失败，其余未审计 |
| A1-pt12 | I0、I4、I6、推进量 | 无 | 其余未审计 |
| A1-pt13 | 无 | I5 | I3、I4、I6、推进量 |

A1-pt13 的 I5 在 `0.03125 A` 扰动下相对误差约 `6.55%`，在 `0.0625 A` 扰动下约 `9.68%`。它只能作为小步长有限使用候选，不能写成生产级通道。

### 3.4 A2 当前状态

A2 尚未通过前置灵敏度门禁。A2 三点审计的强响应相对误差 90 分位约 `12.44%`，超过 `10%` 门限；其中 pt05 存在大中步回环失败，pt17 存在大步分支风险，pt19 的 I5 在中小步下仍有约 `12.8%` 到 `13.3%` 幅值偏差。

因此，A2 目前只能开展定向复审，不能进入正式优化或正式 20 点回归。

## 四、主要风险

### 4.1 实验语义风险

当前最大风险不是再失败一次，而是把少量点烟测、小回归或诊断实验写成正式 20 点结论。凡未完成 20 个目标点的实验，都不得生成“正式 20 点回归”表述。

### 4.2 pt13 过拟合风险

A1-pt13 是重要停滞点，但不能以它单点结果推导全局策略。针对 pt13 的规则必须先验证不破坏 pt01 和 pt12，并至少在另一个困难点上显示收益，才允许升级为 A1 默认策略。

### 4.3 分支污染风险

若差分审计样本没有保持同一正运动学平衡分支，则灵敏度误差会混入分支跳变误差。后续应先强化分支一致性门禁，再复核真实末端偏导，最后重跑有限差分审计。

## 五、修正总原则

1. 正式目标点统一为最后刚段远端，不再以柔性段末端替代。
2. 未审计、审计失败、回环失败或版本不匹配的控制通道默认禁止使用。
3. 生产级通道和有限使用通道必须分开统计。
4. A1 与 A2 分开推进，A2 不得借用 A1 的门禁结论。
5. 不改变固定实验基线：无重力、`M_list=5`、正运动学容差 `1e-5`、电流范围 `[-20,20] A`、推进范围 `[0.003001,0.203] m`、真实末端成功阈值 `5 mm`。
6. 所有阶段必须使用 GPU；CPU 回退结果标为无效。
7. 每一轮实验必须保存命令、日志、环境、机器可读汇总、误差曲线、电流和推进量曲线、姿态图和中文报告。

## 六、阶段计划

### P0：实验语义与运行接口修正

目标：先消除不可比较结果，保证小回归、烟测和正式回归的语义清楚。

任务：

- 修正批量脚本的子集运行逻辑，三点或五点实验不得依赖 20 点固定索引。
- 支持按目标点分别配置门禁、未门禁对照或全放行。
- 点级汇总补充实验类型、决策标签、是否纳入正式统计、门禁口径标签。
- 报告标题和结论由实际运行点数决定，未跑满 20 点不得写正式 20 点统计。

验收：

- A1 三点可在同一批次内运行。
- pt13 可启用门禁，pt01 和 pt12 可明确标为未门禁对照或独立门禁口径。
- 每个点的机器可读结果能追溯其门禁状态和证据等级。

### P1：灵敏度与分支审计扩面

目标：把现有少量通道证据扩展为点级完整证据。

任务：

- 对 A1-pt01、A1-pt12、A1-pt13 覆盖 8 路电流和推进量。
- 对 A2-pt05、A2-pt17、A2-pt19 做同样的定向复审。
- 同时审计历史最小误差状态和最后接受状态。
- 电流扰动至少覆盖三档，推进扰动至少覆盖两档。
- 使用分段回环检查正运动学平衡分支是否保持一致。
- 输出每个通道的分类：可生产使用、可有限使用、同分支误差超限、回环失败、弱响应、未审计。

验收：

- A1 三点每个控制通道均有机器可读分类。
- A2 三个代表点至少完成定向分类，不进入正式优化。
- 生产级通道相对误差不超过 `5%`，有限使用通道相对误差不超过 `10%` 且必须限定更小步长。

### P2：受控外层优化修正

目标：在可信通道和有限使用通道分开的前提下，验证外层优化器是否能稳定改善真实末端误差。

任务：

- 只使用残差奇异值分解灵敏度作为主线。
- 在 A1 三点上分三种口径运行：仅生产级通道、生产级加有限级通道、无门禁对照。
- 对有限使用通道启用更小单步上限，不允许等同于生产级通道。
- 回溯时重算裁剪后的预测下降量。
- 连续拒绝后重算灵敏度或切换初值，不得只反复增大阻尼。

验收：

- A1-pt01 不退化。
- A1-pt12 不出现耗时显著增加但误差几乎不改善。
- A1-pt13 要么进入 `5 mm`，要么给出唯一主因标签。
- 每个失败点必须能归因到灵敏度不足、步长失效、分支不连续、控制维数不足或疑似可达边界之一。

### P3：A1 泛化回归与 A2 准入

目标：避免单点过拟合，逐步扩展到可交付实验规模。

任务：

- A1 先扩展到五点，再扩展到十点，最后再运行二十点。
- A2 仅在 P1 关键通道复审通过后进入三点小回归。
- 对每个失败点保存完整根因标签和证据链。
- 正式 20 点统计只允许在实际完成 20 点后生成。

验收：

- A1 五点和十点阶段保持成功点不退化。
- A1 正式 20 点阶段报告成功率、中位误差、95 分位误差和失败点根因分布。
- A2 若仍不能过 P1，只给诊断结论，不给优化成功率结论。
