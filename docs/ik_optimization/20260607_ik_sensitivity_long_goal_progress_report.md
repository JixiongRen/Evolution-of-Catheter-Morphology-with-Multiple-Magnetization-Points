# 磁控导管逆运动学灵敏度长期目标阶段性进展报告

日期：2026-06-07  
当前分支：`ik_optimize`

## 1. 本报告目的

本报告用于汇总当前“磁控导管逆运动学任务灵敏度”长期目标的实际推进状态。这里的长期目标不是只在个别算例中算出一个数值导数，而是在尽可能广泛的导管构型、磁化段数、磁化方向、工作空间和线圈电流组合下，获得高质量、可重复、可线性化的任务灵敏度；对于无法稳定求得灵敏度的工况，需要给出数学和物理层面的失败原因分析，并形成工程建议。

当前结论可以概括为：

> 已经建立了较完整的灵敏度可靠性判定框架，并在部分稳定工况中获得了可发布的局部灵敏度；但尚未完成长期目标。主要卡点是多平衡分支竞争、刚性磁体段载荷传播一致性、以及困难工况下扰动重求解后的分支保持问题。

综合判断，长期目标当前完成度约为 **40% 左右**。其中“框架建立”和“局部可信样本获得”进展较大，“广泛工况稳定性”和“论文级工程建议”仍未完成。

## 2. 术语说明

为避免表述混乱，本报告统一采用以下中文术语。

灵敏度：指外部控制量发生小扰动时，导管任务量的变化率。本阶段主要关注末端位置对载荷缩放系数或电流扰动的局部响应。

可发布样本：指该样本通过了当前设定的可靠性门禁，可以作为高置信灵敏度结果使用。门禁通常包括：一阶最优性残差足够小、扰动前后分支一致、局部线性近似误差足够小、载荷传播指标可接受、重复求解结果稳定。

诊断样本：指该样本有计算结果，但未通过可靠性门禁。诊断样本不能作为高置信灵敏度发布，只能用于分析失败原因。

一阶最优性残差：指当前求解结果是否接近优化问题的一阶必要条件。若该残差较大，说明求解点并不可靠，此时计算出的灵敏度没有坚实数学基础。

分支漂移：指扰动前后求解结果虽然末端量可能接近，但导管整体中心线进入了另一个平衡形态。软体导管问题可能存在多解，分支漂移会导致局部导数失去物理一致性。

载荷传播比例：用于衡量刚性磁体段受到的磁力和磁矩是否合理传递到相邻柔顺段。若该比例失控，说明当前打靶状态中的段间力学连续性不足，灵敏度结果不应直接发布。

扰动半径：指做有限扰动重求解时控制参数变化的幅度。扰动半径过大时，求解可能跨越不同平衡分支；扰动半径过小则可能受数值误差影响。

## 3. 已完成的关键工作

### 3.1 前置基础：前向运动学已达到可用水平

在进入灵敏度问题前，前向运动学求解器已经经过一轮较大规模优化。当前单次前向运动学的耗时已从早期数百秒降低到较可用水平，并整理出了 `forward_kinematics_project` 相关代码。这为后续逆运动学和灵敏度实验提供了基础。

需要强调的是：本阶段已经不再把前向运动学结果当作唯一真值。前向运动学主要作为次级参照和形态一致性检查工具。灵敏度质量最终仍需要由局部优化问题自身的一阶最优性、分支一致性和扰动重求解稳定性来判断。

### 3.2 从几何拟合转向物理打靶

早期打靶实验中曾使用参考中心线或刚性段中点作为拟合约束。这种方式可以得到外观上接近参考形态的曲线，但存在数据泄露风险，即求解过程利用了原本不应作为逆运动学输入的参考形态信息。

后续主线已经转向更干净的物理打靶形式：主要保留末端位置残差、末端姿态残差和物理边界残差，不再把整条参考中心线作为训练目标。这样得到的结果更接近真实逆静力学问题，但求解难度明显增加。

### 3.3 建立灵敏度可靠性门禁

从 P2c10 到 P2c21，逐步建立了当前可靠性评价框架。关键证据包括：

| 实验 | 主要结论 |
|---|---|
| P2c11 | 有效任务子空间审计显示，部分工况条件数过高，存在局部不可辨识风险。 |
| P2c13 | 刚性磁体段载荷传播审计发现，多个界面存在载荷传播不一致。 |
| P2c15 | 在受控样本中，压制松弛变量后，3 个扰动样本均通过线性、分支、载荷和一阶最优性门禁。 |
| P2c16 | 载荷缩放系数相图显示，5 个载荷点中 2 个可发布、1 个临界、2 个失败。 |
| P2c21 | 汇总 25 个样本，其中 17 个可发布、8 个为诊断样本；失败原因主要是一阶最优性退化、分支不一致或证据不足。 |

这一阶段的重要成果是：我们不再只看末端误差，而是形成了“先判断是否可求导，再发布灵敏度”的流程。

### 3.4 跨工况验证与失败模式识别

P2c22 至 P2c28 将评价框架推广到不同磁化段数、磁化方向和线圈组合。结果显示：

| 实验 | 样本范围 | 结果 |
|---|---:|---|
| P2c22 | 4 个跨工况样本，磁化段数覆盖 1、2、3 | 0 个可发布，4 个诊断，失败均表现为一阶最优性退化。 |
| P2c23 | 尝试完整参考初始化修复 | 4 个样本仍均为诊断，说明单纯改善初值不足以解决问题。 |
| P2c24 | 尝试界面权重延拓修复 | 2 个样本均未转为可信样本。 |
| P2c25 | 重新审计残差尺度和界面指标 | 2 个样本中 1 个可信、1 个诊断。 |
| P2c27 | 对一个受控样本做一阶最优性精修 | 3 个扰动半径全部可发布。 |
| P2c28 | 5 个跨工况复现性图谱 | 2 个可发布、3 个诊断；失败原因包括载荷传播失配和一阶最优性退化。 |

这一阶段说明：当前方法不是完全失败。它能在部分稳定工况中得到可靠灵敏度，但跨工况泛化仍不稳定。

### 3.5 困难工况 `n3_mixed_rand20` 的边界加密

最近主要精力集中在困难工况 `n3_mixed_rand20`。该工况具有 3 个磁化段和随机多线圈电流组合，是当前用于研究失稳边界的代表样本。

关键进展如下：

| 实验 | 主要结果 |
|---|---|
| P2c29 | 在 `alpha=0.4` 附近通过特定分支和直接重启得到可信基线；同伦路径修复效果不稳定。 |
| P2c30 | `eps=0.005` 和 `eps=0.010` 可发布，`eps=0.020` 因分支漂移失败。 |
| P2c31 | `eps=0.0125`、`0.015`、`0.0175`、`0.020` 均失败；临界区间位于 `0.010` 到 `0.0125` 之间。 |
| P2c32 | 综合已有证据，区分了低载荷传播失配和高扰动分支漂移两类失败机制。 |
| P2c33 | 审计发现部分历史扫描的目标和初值协议不严格，需要任意 `alpha` 的规范状态生成。 |
| P2c34 | 生成 `alpha=0.375,0.400,0.425,0.450` 的规范状态；其中 `0.400` 和 `0.425` 默认生成路径失败。 |
| P2c35 | 通过多初值分支修复，恢复 `alpha=0.400` 和 `0.425` 的可信分支，证明失败主要来自分支初始化，而非物理不可行。 |
| P2c36 | 在可信分支上复核，`alpha=0.400` 的 `eps=0.005,0.010` 可发布；`alpha=0.425` 的 `eps=0.005,0.010,0.0125` 可发布。 |
| P2c37 | 扫描 `alpha=0.405-0.420`，`eps=0.010` 全部可发布，`eps=0.0125` 全部失败。 |
| P2c38 | 加密 `alpha=0.421-0.424`，`eps=0.0125` 全部失败。 |

P2c38 的最新结果最关键：`alpha=0.421-0.424` 下，扰动半径 `eps=0.0125` 全部不能发布。失败主因不是一阶最优性残差，也不是末端局部线性误差，而是中心线分支漂移超过 `1 mm`。其中 `alpha=0.421` 和 `0.422` 是轻度临界，漂移约 `1.0-1.3 mm`；`alpha=0.423` 和 `0.424` 漂移增至约 `4.9 mm`。

该结果说明，`alpha=0.420-0.425` 附近并不是简单单调过渡，而存在明显分支竞争。即使末端响应看起来线性，整体形态也可能已经切换到另一个平衡分支。

## 5. 当前最重要的结论

### 5.1 灵敏度不是单纯数值求导问题

在磁控软体导管中，灵敏度质量首先取决于当前平衡状态是否稳定、局部是否可辨识、扰动后是否仍留在同一物理分支。若这些条件不满足，末端差分结果即使数值上很平滑，也不能作为可信灵敏度。

### 5.2 困难工况下的主要问题是分支竞争

`n3_mixed_rand20` 的最新证据表明：在 `alpha=0.4` 附近，小扰动可以得到可发布结果；扰动半径增大到 `0.0125` 后，中心线分支开始漂移。该现象不是普通数值误差，而更接近多平衡解之间的切换。

### 5.3 当前安全扰动半径应偏保守

对 `n3_mixed_rand20`，当前较稳妥的建议是：将安全扰动半径暂定为 `eps <= 0.010`。`eps=0.0125` 在部分分支上可能看似可用，但在 `alpha=0.421-0.424` 加密扫描中全部未通过中心线分支门禁。

### 5.4 分支保持比继续盲目加密扫描更重要

继续在 `alpha` 方向做更密集标量扫描，信息增益有限。更重要的是研究如何在扰动重求解时保持同一平衡分支，例如加入形态延拓、分支锁定、逐级扰动、中心线形态一致性约束等。

## 6. 当前主要卡点

### 6.1 多平衡分支问题尚未解决

同一控制参数附近可能存在多个平衡形态。优化器可能因初值、目标生成路径或扰动方向不同而落入不同分支。当前已经能检测该问题，但尚不能稳定避免。

### 6.2 刚性磁体段载荷传播仍是薄弱环节

刚性磁体段受到外部磁场作用后，其力和力矩应通过界面传递给柔顺段。当前打靶模型中的界面连续性仍可能过弱，导致某些样本虽然末端误差较小，但物理边界残差或载荷传播指标不可信。

### 6.3 跨工况泛化不足

目前成功样本集中在经过修复和筛选的稳定分支。对于不同磁化段数、不同磁化方向、不同随机电流组合，可靠性仍不稳定。长期目标要求“尽可能广泛工况”，当前覆盖仍不足。

### 6.4 数学层面的隐式可解性还不完整

当前主要通过重求解有限扰动进行灵敏度审计。后续如果要形成更强论文级结论，还需要更系统地检查局部雅可比矩阵的秩、条件数和隐式可解性，解释为什么某些区域可导、某些区域不可导或近似不可导。

### 6.5 实验版本管理仍有历史遗留

最新 P2c38 已成功提交到本地 `ik_optimize` 分支。但当前工作树中仍存在 P2c29-P2c37 等未跟踪目录，原因是此前 `.git` 一度只读，导致当时无法提交。这些目录需要后续分批整理、确认是否纳入提交，避免实验链路断档。

## 8. 建议的下一步

### 8.1 先整理版本链路

在继续大规模实验前，应先处理 P2c29-P2c37 的未提交实验目录。建议分批提交，避免实验记录和代码状态脱节。

### 8.2 对 `n3_mixed_rand20` 做扰动半径边界精定位

下一轮建议固定 `alpha=0.421-0.424`，扫描 `eps=0.010, 0.011, 0.012`。目标不是再证明 `0.0125` 失败，而是找出从可发布到分支漂移的最小扰动边界。

### 8.3 做正负扰动方向分解

对 `alpha=0.423-0.424`，分别检查正扰动和负扰动。若只有一个方向发生分支漂移，说明该区域的平衡分支边界具有方向性；若两个方向都漂移，则说明局部 basin 非常窄。

### 8.4 引入分支保持重求解策略

建议尝试三类方法：

1. 逐级扰动延拓：把一次扰动拆成多个小步，每步以上一步解为初值。
2. 形态一致性约束：在重求解时加入弱中心线一致性项，防止跳到远离原分支的形态。
3. 分支候选筛选：同一扰动点从多个初值出发，选择一阶最优性和中心线一致性同时满足的分支。

### 8.5 扩展工况覆盖，但不要盲目铺开

建议优先扩展三类工况：

1. 单磁化段稳定工况：用于建立低复杂度可靠基准。
2. 双磁化段中等电流工况：用于检查载荷传播是否随磁化段数恶化。
3. 三磁化段强耦合工况：用于研究多平衡分支和失稳边界。

每类工况都应先做小规模质量门禁，再决定是否扩大采样。

## 9. 最终判断

当前工作已经完成了从“尝试计算灵敏度”到“建立灵敏度可靠性判定体系”的关键转变。这个阶段的价值不在于已经拿到普适答案，而在于已经明确：哪些结果可以发布，哪些结果只能诊断，失败主要来自哪些数学和物理机制。

但长期目标尚未完成。下一阶段的核心任务不是继续简单增加样本数量，而是解决分支保持、载荷传播一致性和跨工况泛化三个问题。只有这三点得到进一步控制后，才可能形成面向导管构型、磁化配置、工作空间和电流限幅的可靠工程建议。
