# A1/A2 有监督逆运动学诊断审计修正计划 V3

## 一、文档目的

本文档综合 2026 年 7 月 14 日多智能体审计意见、A1-pt13 候选池结果、成功台账重分类结果，以及此前 A1/A2 代表点诊断结果，给出下一阶段有监督逆运动学的完整修正计划。

这里的有监督逆运动学是指：外层调整八路线圈电流和推进量，内层调用正运动学求解器重新求解导管静力平衡，并以最后刚性段远端的真实末端位置作为主要监督目标。本阶段仍限定在单点磁化导管 A1/A2、无重力、末端位置控制，不讨论末端姿态、多点磁化导管或重力工况。

本计划的核心目标不是立刻追求 20 点成功率，而是获得可审计、可复现、能解释失败原因的代表点闭环。只有在统计口径、分支来源和停止原因完全清楚后，扩点结果才具有算法意义。

## 二、术语说明

- 冷启动：从标准初始形态和标准控制初值开始，不加载相邻点、历史控制量或历史平衡状态。
- 热启动：使用相邻点、历史成功点、人工控制量或历史平衡状态作为起点。
- 平衡分支：同一组电流和推进量下，导管可能收敛到的不同静力平衡形态。
- 分支状态重放：加载历史保存的内部平衡状态，使正运动学回到历史形态。它只能证明该形态存在，不能证明冷启动算法可以找到它。
- 入盆：外层优化进入目标附近的小邻域，使局部线性近似开始有效。
- 灵敏度：末端位置对电流和推进量微小变化的响应关系。
- 信赖域：限制每次控制更新的物理步长，避免在局部线性近似失效的范围内盲目更新。
- 有效步长塌缩：名义更新量存在，但经过阻尼、回溯、边界裁剪或门禁裁剪后，实际执行的电流和推进量变化接近零。
- 真实末端：最后刚性段远端。柔性段末端只作为诊断量，不作为正式成功判据。

## 三、多智能体审计共识

### 3.1 已经相对明确的结论

1. A1 与 A2 必须分流处理。A1 可以进入代表点闭环和外层求解器稳定化；A2 只能先做三哨兵风险封存，不能直接扩点。

### 3.2 必须降级为“待复核”的结论

1. “完整 40 点严格冷启动成功为 `0/40`”目前应写为待权威台账复核的强提示，而不是最终定论。原因是旧台账脚本与新统计口径之间仍有字段一致性风险。

4. 历史 `2.810 mm` 控制量目前只完成控制量重放，不应写成“继续优化超时”。

## 五、数学解释

外层控制变量记为：

```text
c = [I_1, I_2, ..., I_8, x]^T
```

其中 `I_1` 到 `I_8` 为八路线圈电流，`x` 为推进量。导管平衡状态记为 `z`，静力平衡方程为：

```text
F(z, c) = 0
```

真实末端位置为：

```text
p = p(z, c)
```

在同一平衡分支的小邻域内，可以写出局部线性近似：

```text
p(c + Δc) ≈ p(c) + J(c) Δc
```

其中 `J(c)` 为末端位置对电流和推进量的局部灵敏度。这个关系只在当前平衡分支附近成立。若同一控制量从不同初值收敛到不同形态，则原灵敏度不具备跨分支预测意义。

外层更新应记录预测下降与真实下降的一致性：

```text
ρ = 实际下降量 / 预测下降量
```

若 `ρ` 持续异常，说明局部模型已经失效。此时应重新线性化、切换候选、缩小信赖域或回到入盆阶段，而不是继续单调增大阻尼。

## 六、总体修正路线

### P0：权威台账与门禁同构

目标：先防止热启动、分支状态重放和异常样本继续污染算法成功率。

任务：

1. 修正成功台账脚本，使严格冷启动成功与统计文档完全一致。
2. 将初值来源拆分为标准冷启动、失败后冷重启、邻点控制量、历史控制量、确定性扰动、人工调参和分支状态重放。
3. 对每条结果重新计算 `success_true_tip_5mm = err_true_mm <= 5`。
4. `NaN`、超时、GPU 无效、核心停止原因缺失、加载分支状态的行不得进入正式成功率。
5. 输出唯一权威台账，至少包含原始命中、真实末端命中、严格冷启动、失败后冷重启、邻点延拓、人工初值、分支状态重放、异常样本。

验收标准：

1. 文档口径和脚本口径逐项一致。
2. 任一成功结果均可追溯初值来源、分支来源和是否进入算法统计。
3. 对完整 40 点基线给出“已闭合”或“待复核”的明确标记，不使用含糊表述。

### P1：运行证据字段补齐

目标：让每一次失败都能定位到具体机制，而不是只写“未收敛”。

任务：

1. 每个接受状态保存平衡状态、中心线哈希、状态哈希、真实末端误差、柔性末端误差、电流、推进量和核心停止原因。
2. 每次外层更新记录名义步长、实际执行步长、阻尼、回溯次数、预测下降、真实下降和步长塌缩来源。
3. 每个运行目录记录 Git 提交、是否存在已跟踪文件改动、GPU 设备、校准文件哈希和配置哈希。
4. 对 `ik_stop_reason` 为空、误差为 `NaN` 或超时的样本单独列为异常，不进入主因统计。

验收标准：

1. A1-pt01、A1-pt12、A1-pt13 的每个有效接受态均有完整证据字段。
2. 任意停止结果能区分阻尼导致、回溯导致、物理边界导致、门禁裁剪导致或数值异常导致。

### P2：A1-pt13 近阈值修复

目标：判断 A1-pt13 是否能在不加载历史分支状态的条件下进入 `5 mm`；若不能，给出唯一主因。

任务：

1. 保留标准冷启动、pt01 前向控制量、确定性扰动候选和反向邻点候选。
2. 历史分支状态重放只作诊断，不进入算法成功率。
3. 对 `5--10 mm` 候选启用小信赖域精修，重点修正回溯后预测下降重算、阻尼恢复和实际步长门禁。
4. 若非分支候选进入 `5 mm`，必须做只给控制量重放确认。
5. 若三个以上非分支候选均停在 `5--10 mm` 且有效步长塌缩，停止刷随机种子，输出强分支依赖和局部停滞证据包。

验收标准：

1. A1-pt13 成功时必须满足真实末端误差不超过 `5 mm` 且不加载历史分支状态。
2. A1-pt13 失败时必须给出唯一主因：强分支依赖、入盆不足、局部模型失效或疑似可达边界。

### P3：A1-pt12 主因闭合

目标：把 A1-pt12 从“未收敛”转化为有证据等级的主因结论。

任务：

1. 运行标准冷启动、邻点控制量、反向候选、确定性扰动和历史最好候选。
2. 记录局部任务秩、主要响应方向、电流边界余量、推进量边界余量和平衡质量。
3. 进行低成本经验采样，判断 `10 mm` 内候选是否存在。
4. 对候选状态做有限差分复核，判断灵敏度是否只在同分支小范围内有效。

验收标准：

1. 不允许最终只写“未收敛”。
2. 必须在入盆失败、可控方向不足、分支跳变、弱平衡、疑似可达边界之间给出主因和证据等级。

### P4：外层求解器稳定化

目标：降低有效步长塌缩和错误早停的发生率。

任务：

1. 回溯和边界裁剪后，用实际执行步长重新计算预测下降。
2. 连续拒绝后触发重新线性化、阻尼重置、候选切换或回到入盆阶段，不再只单调增大阻尼。
3. 近阈值区域允许小幅非恶化步骤，但必须记录真实下降、预测下降和正则项变化。
4. 所有新策略必须有开关，保留旧路径对照。

验收标准：

1. A1-pt01 不退化，仍进入 `5 mm`。
2. A1-pt13 不再以不可解释的有效步长塌缩结束。
3. 若失败，报告必须明确是候选耗尽、分支回环、局部模型失效还是可达性不足。

### P5：A2 三哨兵风险封存

目标：不追求 A2 扩点成功率，只形成可追溯风险标签。

任务：

1. 对 A2-pt05、A2-pt17、A2-pt19 分别做控制量重放、分支状态重放、有限差分复核和多初值短跑。
2. A2-pt17 只有在跨初值复现弱平衡后，才能标记为弱平衡隔离。
3. A2-pt19 必须拆分分支不连续、响应过弱和目标过远三类因素。
4. 三哨兵完成前，禁止 A2 扩点。

验收标准：

1. 每个哨兵点输出一个主风险标签：有限使用、弱平衡隔离、分支不连续、证据不足或疑似可达边界。
2. 任何 A2 成功结果都必须说明是否依赖延拓或分支状态。

### P6：A1 分级扩点

目标：代表点闭合后恢复 A1 交付线。

扩点顺序：

1. 三点：A1-pt01、A1-pt12、A1-pt13。
2. 五点：加入两个历史失败或边界代表点。
3. 十点：覆盖圆周不同象限。
4. 二十点：正式交付候选。

准入条件：

1. A1-pt01 不退化。
2. A1-pt12 已有唯一主因。
3. A1-pt13 成功或主因闭合。
4. 权威台账、运行证据字段和中文图像均通过门禁。

## 八、无人值守门禁

出现以下任一情况，应停止当前批次并输出阻塞报告，不得自动扩点：

1. GPU 无效或发生 CPU 回退。
2. `ik_stop_reason` 缺失。
3. 真实末端误差或柔性末端误差为 `NaN`。
4. 加载分支状态的结果被混入冷启动统计。
5. 末端口径字段缺失。
6. A1-pt13 的三个以上非分支候选均大于 `10 mm` 且均因有效步长塌缩停止。
7. A2 三哨兵未封存前尝试 A2 扩点。
