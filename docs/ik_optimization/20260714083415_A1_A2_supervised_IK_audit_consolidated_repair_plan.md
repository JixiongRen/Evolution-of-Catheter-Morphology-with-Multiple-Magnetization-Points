# A1/A2 有监督逆运动学诊断审计综合修正计划

## 一、文档目的

本文档整合 A1/A2 有监督逆运动学近期诊断、审计和多智能体讨论结果，给出下一阶段可执行修正计划。

这里的“有监督逆运动学”指：外层调整线圈电流和推进量，内层调用正运动学求解器重新求解静力平衡，并用正运动学返回的真实末端位置作为监督信号。当前阶段暂不约束末端姿态，主要目标是让末端位置在无重力、固定圆周目标点下进入 5 mm 误差范围。

本文档的核心约束是：不能把局部灵敏度审计通过等同于逆运动学已经可交付；不能把 A1 的结论直接推广到 A2；不能把短期收敛失败直接解释为物理不可达。

## 二、术语说明

- 灵敏度：控制量发生小变化时，导管真实末端位置随之变化的局部线性关系。它相当于外层优化器使用的方向估计。
- 通道门禁：根据审计结果决定某个控制通道是否允许参与外层更新的规则。这里的控制通道包括 8 路线圈电流和推进量。
- 推进量：导管从近端向外伸出的长度变量。它会改变有效柔性长度和磁体相对工作空间的位置。
- 入盆：外层迭代进入目标附近正确吸引域的过程。进入吸引域后，小步局部优化才可能稳定收敛。
- 信赖域：限制单次控制量变化幅度的局部步长范围，用于避免局部线性模型在过大步长下失效。
- 回环一致：对同一控制量进行扰动后再回到原控制量，若末端和中心线几何基本恢复，则认为该次差分没有明显跨越平衡分支。它不等同于严格数学意义上的同一平衡分支证明。
- 弱平衡：正运动学虽然给出形态，但残差、重放或状态稳定性不足，不能作为可靠外层优化状态使用。

## 三、现有证据摘要

### 3.1 A1 代表点审计

P1b 代表点灵敏度审计显示，A1-pt01、A1-pt12、A1-pt13 的电流通道局部一阶关系总体可用。A1-pt01 是已成功点，末端误差约 3.64 mm；A1-pt12 和 A1-pt13 虽然局部灵敏度误差较小，但基准末端误差仍分别约 50.59 mm 和 69.83 mm。

这说明 A1 当前主要矛盾不是所有局部导数都错误，而是外层求解器没有稳定进入目标附近的正确区域。

### 3.2 A1 推进量门禁问题

P2 受控验证给出直接证据：A1-pt01 在普通外层下可达到 3.64 mm；启用 P2 但不启用通道门禁时仍可达到 3.61 mm；启用 P2 并临时放行推进量时可达到 4.38 mm；但启用严格门禁且禁用推进量后，误差退化到约 27.79 mm。

因此，A1-pt01 的退化不能归因于 P2 外层框架本身，而应归因于推进量被过早硬封禁。当前门禁把“局部精修阶段不够可信”误写成了“所有阶段都禁止使用”。

### 3.3 两阶段探针暴露的落盘口径缺陷

两阶段探针中，第一阶段允许推进量参与入盆，A1-pt01 达到约 4.38 mm。第二阶段从该状态切换到严格门禁后，日志显示初始状态已经满足 5 mm，且记录为 `Converged at init`。但汇总文件却把该点写成 `NaN/False`，并把电流、推进量写成空值。

这不是数值求解失败，而是“初始化即收敛”状态的结果落盘口径错误。若不先修复该问题，后续会把有效的两阶段策略误判为失败。

### 3.4 A2 的风险与 A1 不同

A2-pt05 虽然可进入 5 mm，但有限差分中存在大量回环失败；A2-pt17 被弱平衡门禁隔离；A2-pt19 可统计样本少且高分位误差较大。A2 当前主要问题是平衡分支连续性和弱平衡，而不是简单的推进量门禁问题。

A2 暂不应进入正式小回归，也不应复用 A1 的通道策略。当前更合理的任务是风险封存、分支分类和 A2 专属审计。

## 四、总体修正原则

1. 先修结果落盘口径，再做算法结论。
2. 先区分“入盆阶段”和“精修阶段”，再设计通道门禁。
3. 先在 A1 三个代表点闭环，再扩展到 A1 更多圆周点。
4. A2 只做风险封存和分类，不进入正式回归。
5. 每个失败点必须归入明确根因：数据记录错误、门禁过保守、入盆失败、弱平衡、分支不连续、局部模型失效、疑似物理不可达。
6. “疑似不可达”只能作为最后分类，必须在多初值、分支检查和经验采样均不能接近目标后才使用。

## 五、分阶段修正计划

### P0：结果记录和生产路径闭环修复

目标：保证实验结果可信，避免把记录错误误判为算法失败。

需要修改的重点文件：

- `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py`
- `inverse_kinematics/ik_multisite_lm_opt.py`

任务：

1. 修复“初始化即收敛”状态的落盘口径。若初始状态已进入成功阈值，汇总文件必须保留初始电流、推进量、真实末端、中心线、分支状态路径和成功标记。
2. 修复 `success_eps`、`success_5mm`、`I_A`、`x_m`、`p_tip_true` 等字段在早停场景下变为空值的问题。
3. 将通道门禁缺失从“静默失败”改为显式无效实验。缺失门禁表或点位键时，不应输出普通优化失败，而应标记为配置错误。
4. 记录运行环境、正运动学参数、真实末端定义、门禁表哈希、源状态哈希和控制量哈希。

验收标准：

- 两阶段 A1-pt01 严格精修从已成功状态启动时，汇总结果必须显示成功且误差约 4.38 mm。
- 任一失败状态都必须有明确停止原因和最后有效控制量；不得出现无解释的 `NaN/False`。

### P1：灵敏度审计语义修正

目标：把“弱响应”“单步可用”“分支不连续”和“硬禁用”分开，避免把不适合局部精修的通道直接删除。

需要修改的重点文件：

- `DELIVER_TO_EXP/run_a1_a2_sensitivity_reaudit.py`
- `inverse_kinematics/ik_control_gate.py`

任务：

1. 将通道门禁改为三类：精修可用、入盆可用、禁用。
2. 将推进量从单纯线性化通道中拆出来，允许其作为入盆阶段的有界小步搜索变量。
3. 对弱响应判据增加位移信噪比，而不是只用绝对位移阈值。
4. 增加门禁前后任务秩统计，记录禁用某通道后末端三维任务是否降秩。
5. 增加尺度一致性指标，包括不同扰动尺度下方向夹角、范数比和单调性。
6. 将“回环一致”从“同分支证明”中剥离，报告中统一使用更谨慎的表述。

验收标准：

- A1-pt01、A1-pt12、A1-pt13 的推进量不再被简单硬封禁，而是进入入盆可用或待复核类别。
- 门禁表必须显式记录适用源状态和不可外推边界。

### P2：A1 两阶段外层求解器修正

目标：让 A1 外层优化先能入盆，再进行局部精修。

需要修改的重点文件：

- `inverse_kinematics/ik_multisite_lm_opt.py`
- `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py`

任务：

1. 引入两阶段策略。第一阶段为入盆阶段，允许推进量和入盆可用通道小步参与；第二阶段为精修阶段，仅使用精修可用通道。
2. 对电流和推进量使用不同信赖域。推进量不与电流共用同一个步长缩放规则。
3. 若某候选在加载时已经进入 5 mm，立即判定成功，不再强行迭代。
4. 保存少量候选状态，包括历史最小真实末端误差状态、最后接受状态、较低控制量范数状态和不同推进量附近状态。
5. 连续拒绝时切换候选或重新线性化，不再重复沿同一方向加大阻尼。

验收标准：

- A1-pt01 不得被新策略破坏，误差应保持在 5 mm 内。
- A1-pt12 和 A1-pt13 若不能进入 5 mm，也必须输出明确归因：入盆失败、局部模型失效、分支跳变或疑似不可达。
- 所有代表点必须输出误差曲线、电流曲线、推进量曲线、接受/拒绝记录和最终姿态图。

### P3：A1 小范围回归

入口条件：P0、P1、P2 均通过，且 A1-pt01 不退化。

任务：

1. 先运行 A1 三点回归。
2. 若三点中至少成功点不退化，且失败点有唯一主因，再扩展到 A1 五点。
3. 若五点中成功率和归因质量可接受，再单独开启 A1 十点或二十点实验。

验收标准：

- 不以单纯成功率作为唯一指标，同时要求失败归因可追溯。
- 扩点前必须人工或文档门禁确认，不在同一无人值守目标中自动膨胀到全 20 点。

### P4：A2 风险封存

目标：防止 A2 被误判为已经可以套用 A1 策略。

任务：

1. 对 A2-pt05、A2-pt17、A2-pt19 生成风险表。
2. 将 A2 状态分为：局部可用、弱平衡隔离、分支不连续、样本不足。
3. 对 A2 暂不运行正式小回归，除非后续已有 A2 专属门禁和分支连续性策略。

验收标准：

- A2 的结论必须独立于 A1，不得写成“同策略可用”。
- A2 每个代表点都有清晰风险等级和下一步建议。

## 六、必须新增的审计指标

1. 门禁前后任务秩：用于判断通道封禁是否让三维末端任务退化。
2. 位移信噪比：用于区分真正弱响应和数值噪声主导的小差分。
3. 尺度一致性：用于判断不同扰动幅度下的响应方向是否稳定。
4. 推进量角色标签：区分精修线性化变量和入盆搜索变量。
5. 回环一致强化指标：除末端和中心线外，增加内部状态哈希、状态距离或重放差异。
6. 门禁消融指标：比较全通道、禁用推进量、仅放行推进量、三类门禁的误差和停滞原因。
7. 可诊断覆盖率：记录每点每通道可统计有限差分行数占比。

## 七、不可过度声称的结论

1. 不能声称 A1 逆运动学已经修复。当前只能说 A1 代表点暴露出明确可修的门禁和入盆问题。
2. 不能声称推进量已经是生产级可信灵敏度列。当前只能说它是 A1 入盆阶段不可直接禁用的重要自由度。
3. 不能声称 A2 已具备稳定求解能力。A2 仍受弱平衡和分支不连续限制。
4. 不能把回环一致写成严格同分支证明。
5. 不能把 pt12 和 pt13 直接判为物理不可达。
6. 不能把 A1 三个代表点的门禁表外推到全部 20 个圆周点。

## 八、下一阶段成功判据

下一阶段不以“所有点进入 5 mm”为唯一成功标准。更合理的成功判据如下：

1. 修复初始化即收敛结果落盘口径，并用 A1-pt01 两阶段探针复现。
2. A1 通道门禁由二值规则升级为三类规则。
3. A1-pt01 在新策略下稳定保持 5 mm 内。
4. A1-pt12 和 A1-pt13 得到明确、可复核的失败主因；若能改善则记录改善幅度。
5. A2 形成独立风险封存表，不进入正式回归。
6. 产物包含中文实验报告、结构化摘要、完整命令、日志、运行环境、图像和本地提交。

## 九、建议执行顺序

1. P0：修复落盘口径和配置错误标记。
2. P1：重构门禁语义，生成三类门禁表。
3. P2：实现 A1 两阶段外层策略，并在 pt01、pt12、pt13 上验证。
4. P4：封存 A2 风险。
5. 根据结果决定是否进入 P3 小范围扩点。

如果任一阶段失败，不应中止并只输出“失败”。应按失败类型进入预案：记录错误先修记录；门禁过保守先修门禁；入盆失败先做推进量和候选状态策略；弱平衡先隔离；分支不连续先做分支连续性审计。
