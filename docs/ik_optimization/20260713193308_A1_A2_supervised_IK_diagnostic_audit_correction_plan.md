# A1/A2 有监督逆运动学诊断审计后修正计划

日期：2026-07-13

## 一、目的

本文件汇总 A1/A2 单点磁化导管有监督逆运动学诊断与审计结果，并给出下一阶段的代码修正、实验验证和准入规则。当前目标不是直接扩大到全部 40 个目标点，而是先把灵敏度、分支稳定性和外层优化器三类问题拆开处理，避免把不同根因混合成不可解释的失败率。

本文件中的“有监督逆运动学”指外层调节八个线圈电流和推进量，内层每一步调用前向运动学重新求静力平衡，并用前向运动学结果评价真实末端误差。

## 二、证据来源

本计划依据以下实验与多代理审查结论形成：

- `20260713175426_p1_dual_selector_preregistered_channels`：双状态选择器与预注册通道灵敏度审计。
- `20260713184928_p1_normal_equation_rcond_smoke`：法方程截断修正小回归。
- `20260713170518_p1_failed_channel_smallstep_roundtrip`：失败通道小步与分段回环审计。
- `20260713173244_p2_outer_solver_smoke`：外层优化器稳定化烟测。
- `20260713190019_p2_a1_representative_outer_solver_compare`：A1 代表点普通外层与受限外层对照。
- 多代理审查结论：风险代理强调强通道回环失败不能进入灵敏度统计；代码路径代理指出正式批量入口和日志字段仍需补全；统计代理指出 A1 只在部分状态上可进入小回归，A2 仍未通过 P1 级门禁。

说明：本轮曾尝试新建代理线程，但接口返回代理线程上限已满，因此复用了已有代理线程的审查结果。

## 三、术语与判据

“真实末端”指最后刚段远端，不是柔性段末端。所有目标误差、成功判据和灵敏度审计均应以真实末端为主。

“强响应通道”指对某个控制量施加有限差分扰动后，真实末端位移足够大，能够稳定评价相对误差。当前位移门限为 `0.25 mm`。

“弱响应通道”指末端位移过小的通道。弱响应通道不适合用相对误差判定灵敏度优劣，因为分母太小会放大数值噪声。

“回环审计”指先扰动控制量、重新求平衡，再回到原控制量重新求平衡，检查导管末端和轴线是否回到原状态。若回环失败，说明扰动可能跨入另一条平衡分支，此时不能把有限差分结果当作同一平衡分支上的导数。

“残差谱分解灵敏度”指在平衡残差雅可比矩阵的奇异值空间中求解灵敏度。它避免直接使用法方程 `J^T J`，因为法方程会把奇异值平方，导致病态程度放大。

“分支”指相同控制量在不同初始状态下可能收敛到不同平衡形态。软体导管的静力平衡不是天然单解问题，因此分支管理是必要的工程约束。

## 四、当前可靠结论

### 4.1 灵敏度主线

残差谱分解灵敏度是当前最可信的生产候选。去阻尼高斯-牛顿实现经修正后，在 `A2-pt19` 小回归中与残差谱分解结果一致。求解器响应版和驻点方程版仍保留为诊断路径，不应作为外层优化的默认灵敏度。

数学上，当前可信路径对应如下线性化：

```math
J_z \Delta z \approx -J_c \Delta c
```

其中 `z` 为平衡状态变量，`c` 为控制量。残差谱分解路径直接对 `J_z` 做谱截断，而不是对 `J_z^T J_z` 做截断，因此数值条件更可控。

### 4.2 A1 与 A2 的状态

A1 不能被判定为完整通过 P1。虽然 A1 有效强响应样本的灵敏度统计较好，但 `pt13` 的两个电流强通道存在回环失败和明显幅值偏差，不能纳入单分支灵敏度统计。

A2 目前未通过 P1。`pt05` 与 `pt17` 主要表现为局部线性窗口过窄，较小扰动或分段回环后可改善；`pt19` 的电流通道 5 即使在修正后仍有约 `12.76%` 相对误差，说明它还存在谱截断或局部增益失配问题。

### 4.3 外层优化器

受限外层策略已经显示出局部价值。A1 代表点对照中：

- `pt01`：普通外层误差 `3.639 mm`，受限外层误差 `3.614 mm`，均进入 `5 mm`。
- `pt12`：普通外层误差 `51.713 mm`，受限外层误差 `51.271 mm`，几乎无实质改善，且耗时从 `292.5 s` 增至 `730.0 s`。
- `pt13`：普通外层误差 `72.626 mm`，受限外层误差 `5.777 mm`，显著改善但未进入 `5 mm`。

结论：受限外层策略对分支敏感点有帮助，但当前接受判据和回溯策略会显著增加耗时，不能直接扩大到全量正式实验。

## 五、主要问题归因

### 5.1 生产路径参数尚未完全闭环

正式批量入口已经可以记录灵敏度配置，但仍需确认所有正式命令默认使用残差谱分解、奇异值阈值和真实末端定义。任何未记录或未透传的参数都会污染正式实验结论。

### 5.2 分支不稳与灵敏度误差被混合

回环失败样本不能用于判断灵敏度公式对错。若扰动后导管落入另一条平衡分支，有限差分得到的是跨分支差值，不是同一分支导数。

### 5.3 A2 的异常不是单一原因

A2 同时存在局部线性窗口过窄和谱截断失配。直接扩大到 9 个控制通道会增加弱响应和不可审计样本，不能提高结论质量。

### 5.4 外层优化器仍缺少分级策略

当前受限外层策略对 `pt13` 有效，但对 `pt12` 造成大量拒绝和耗时上升。说明不能一律启用强回溯，而应先识别点位类型，再选择完整更新、可靠子空间更新或冷启动重规划。

## 六、修正路线

### P0：生产路径闭环

目标：保证正式批量入口、单点 IK 主脚本和审计脚本使用同一套末端定义、灵敏度参数和日志字段。

任务：

1. 检查正式实验脚本是否将灵敏度模式、奇异值阈值、谱滤波方式、推进量灵敏度方法和 P2 设置全部传入 IK 主脚本。
2. 在 `result.json`、逐迭代记录、点级 `summary.csv` 和中文报告中记录这些字段。
3. 将默认生产灵敏度设置为残差谱分解，奇异值阈值使用当前通过小回归的 `1e-9`。
4. 所有正式实验必须记录 GPU 设备、首次编译时间、稳态运行时间和 FK 调用次数。

验收：任意单点结果可以从 `summary.csv` 追溯到完整控制边界、真实末端定义、灵敏度方法和外层策略。

### P1：失败通道分支与谱截断复审

目标：把“分支不稳”和“同分支灵敏度偏差”分开。

任务：

1. 只审计以下失败强通道：`A1-pt13` 的电流 3、4；`A2-pt05` 的电流 1、3；`A2-pt17` 的电流 4；`A2-pt19` 的电流 5。
2. 使用更小扰动和分段回环，判断是否仍会跨分支。
3. 对已确认同分支但误差仍超过 `10%` 的通道，做小规模谱截断扫描。
4. 对弱响应通道只记录位移幅值和方向，不纳入相对误差统计。

验收：每个失败强通道必须被归为以下之一：分支不稳、步长过大、谱截断失配、弱响应、可通过。

### P2：外层优化器分级修正

目标：保留 `pt13` 的显著改善，同时避免 `pt12` 这类点位出现大量拒绝和耗时膨胀。

任务：

1. 增加点位级策略选择：普通更新、可靠子空间更新、冷启动、多候选热启动。
2. 对分支风险样本禁止完整九维大步更新，优先使用可靠子空间和较小信赖域。
3. 对持续拒绝样本加入提前重线性化或冷启动，不允许在同一方向上反复回溯。
4. 保留真实末端误差优先接受判据，但增加耗时上限和拒绝次数上限。

验收：A1 代表点 `pt01/pt12/pt13` 中，`pt01` 保持成功，`pt13` 进入或接近 `5 mm`，`pt12` 不允许出现比普通外层显著更差的耗时和误差。

### P3：小规模正式回归

目标：在修正后运行 A1 小规模正式回归，再决定是否扩展 A2 和 40 点。

任务：

1. 先运行 A1 5 个代表点，包括成功点、失败点和分支敏感点。
2. 若 A1 小回归通过，再运行 A1 10 点。
3. A2 只在 P1 复审通过后进入小回归。
4. 所有图像必须正确显示中文，并绘制最终姿态、目标圆环、误差迭代曲线、电流和推进量演化。

验收：A1 小回归中进入 `5 mm` 的比例明显高于旧正式实验；失败点必须有主根因和证据，不允许只写“未收敛”。

## 七、准入与停止规则

进入下一阶段必须满足：

- 没有 CPU 回退。
- 真实末端定义一致。
- 强响应通道回环通过后才允许进入灵敏度相对误差统计。
- 正式批量入口能完整记录灵敏度与外层策略配置。
- 任一点连续拒绝过多时必须切换策略，不得继续消耗长时间。

停止并回退的条件：

- 新策略使已成功点失去 `5 mm` 收敛。
- 新策略使代表点平均耗时增加超过 50%，且误差没有明显改善。
- 回环失败样本被误纳入灵敏度统计。
- 发现正式入口和 IK 主脚本参数不一致。

## 八、下一步执行优先级

1. 先完成 P0，保证正式路径可追溯。
2. 立刻完成 P1 失败强通道复审，避免继续混用跨分支差分。
3. 基于 P1 分类改 P2，不直接扩大到 20 点或 40 点。
4. 只在 A1 代表点通过后进入 A1 小规模正式回归。
5. A2 暂不承诺成功率，只做灵敏度修复和风险归因。

## 九、结论

当前不是“IK 已不可用”，而是“局部可信但尚未具备全量交付稳定性”。A1 已经有成功点和可改善点；A2 的灵敏度质量仍不足。下一步最重要的是建立可追溯的生产路径、分离分支风险与灵敏度误差，并把外层优化器从统一策略改成按点位状态选择的分级策略。
