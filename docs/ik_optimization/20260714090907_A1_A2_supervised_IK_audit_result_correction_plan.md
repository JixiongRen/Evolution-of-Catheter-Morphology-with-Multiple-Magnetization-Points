# A1/A2 有监督逆运动学诊断审计结果修正计划

## 一、文档目的

本文档整合近期 A1/A2 有监督逆运动学诊断、灵敏度审计、外层求解器验证和多智能体复核意见，给出下一阶段修正计划。

这里的有监督逆运动学指：外层调整线圈电流和推进量，内层调用正运动学求解器重新求解静力平衡，并以真实末端位置作为监督信号。当前阶段仍只讨论末端位置控制，不讨论末端姿态约束。

本文档的核心判断是：当前不能直接进入 A1 或 A2 扩点实验。必须先解决证据口径混杂问题，再做 A1 三点因果闭环和 A2 三点失败闭环。

## 二、近期审计结论

### 2.1 已经确认的事实

1. A1-pt01 是当前最稳定的成功点。普通外层基线可达到约 `3.64 mm`，启用 P2 但不启用通道门禁时也可达到约 `3.61 mm`。
2. 严格门禁禁用推进量后，A1-pt01 退化到约 `27.79 mm`。临时放行推进量后，A1-pt01 又可回到约 `4.38 mm`。
3. A1-pt12 和 A1-pt13 在 P1b 审计状态附近的局部灵敏度误差较小，但二者仍分别距离目标约 `50.59 mm` 和 `69.83 mm`。这只能说明该失败状态附近的局部导数较平滑，不能说明它们已经具备进入目标邻域的能力。
4. A2 的问题不同于 A1。A2-pt05 虽然能进入 `5 mm`，但存在大量回环失败；A2-pt17 被弱平衡门禁隔离；A2-pt19 可统计样本少且高分位误差大。
5. “初始化即收敛”结果落盘口径已经修复，`Converged at init` 状态不再被错误写成 `NaN/False`。
6. 三类通道门禁和门禁阶段选择接口已经完成：入盆阶段可使用 `basin_mask`，精修阶段可使用 `allowed_mask`。
7. 两阶段门禁烟测证明流程可运行，但该烟测使用了历史成功分支作为初始状态，且外层迭代次数为 `0`。它只能证明落盘和接口链路正确，不能证明两阶段求解策略本身已经有效。

### 2.2 当前最危险的误判

1. 把热启动后 `0` 次迭代成功误认为算法策略成功。
2. 把 `best_accept` 附近的局部灵敏度审计，误认为从冷启动进入目标邻域的生产级门禁。
3. 用生成门禁的同一批点验证门禁有效性，造成训练点与验证点混用。
4. 把 A1-pt01 的推进量证据直接外推到 A1-pt12、A1-pt13，甚至外推到 A2。
5. 把真实末端回环一致写成严格同一平衡分支证明。
6. 把 A2 的弱平衡和分支不连续问题简单归因于门禁过严。

## 三、根因归纳

### 3.1 A1 的主要根因

A1 当前最明确的问题是控制通道门禁语义不充分。推进量在局部精修阶段未必是高质量线性灵敏度通道，但在入盆阶段可能是必要自由度。旧二值门禁把“局部精修阶段不够可靠”误写成“全流程禁用”，导致求解器丢失进入目标邻域的自由度。

A1-pt12 和 A1-pt13 还存在证据口径问题。此前不同实验使用了不同源状态、不同灵敏度公式和不同分支重放协议，因此不能直接互相覆盖。后续必须在同一运行协议下判断：失败究竟来自入盆失败、局部模型失效、分支跳变，还是目标本身接近不可达边界。

### 3.2 A2 的主要根因

A2 当前不能套用 A1 结论。其主要风险是弱平衡和分支不连续，表现为同一控制量附近的有限差分回环失败、可统计样本不足和高分位误差偏大。A2 应先完成失败闭环和风险分级，再考虑外层策略优化。

### 3.3 工程记录层面的主要根因

近期若干结果同时混合了三类用途：结果落盘修复、热启动接口烟测、冷启动算法验证。三类实验的证据强度不同，不能共同进入成功率统计。今后必须在摘要表中显式标记：

1. 记录修复验证。
2. 热启动流程验证。
3. 冷启动或统一初值算法验证。
4. 辅助阶段行。
5. 最终判定行。

## 四、修正原则

1. 不改变 FK 容差、网格、重力设置、真实末端定义和控制边界来换取成功率。
2. 先修证据口径，再评价算法效果。
3. A1 与 A2 分开处理，不把 A1 的门禁策略外推到 A2。
4. 推进量不得简单全局放开，也不得简单硬封禁；它应作为阶段性控制自由度接受审计。
5. 热启动零迭代成功只作为流程验证，不作为算法成功证据。
6. 每个目标点最终只允许一行进入正式成功率统计，入盆辅助行只能作为诊断证据。
7. 对失败点必须给出唯一主因和证据等级，不能只写“未收敛”。

## 五、分阶段修正计划

### P0：证据口径与交付规范硬化

目标：保证后续实验结果可解释、可复现、不可混淆。

任务：

1. 在 `summary.csv/json` 中新增或规范化字段：实验类型、是否热启动、是否零迭代通过、是否辅助阶段行、是否最终判定行、初始状态来源、初始状态哈希、门禁表哈希、门禁阶段、停止原因。
2. 若 `outer_iter_count=0`，必须标记为零迭代通过。该类结果可以证明状态读取和落盘口径正确，但不得进入算法有效性统计。
3. 两阶段策略中，入盆阶段输出为辅助行，精修阶段输出为最终判定行。同一目标点不得有多行同时计入成功率。
4. 正式实验运行前记录 GPU、提交号、工作区状态、命令、门禁文件哈希、初始分支状态哈希和运行环境。
5. 若工作区非干净状态，则本轮实验必须标为“不可晋级”，除非同时保存变更清单和未追踪文件清单。
6. 修复或建立交付产物一致性检查：报告路径、摘要路径、图像索引、图像文件必须一致，不得出现索引引用不存在文件。

验收标准：

1. A1-pt01 的热启动零迭代结果被正确标为流程验证，而不是算法验证。
2. 每个实验目录内 `record.md`、命令、摘要、环境和图像索引互相一致。
3. 任一失败或成功结果都有明确来源、停止原因和最终判定身份。

### P1：A1 三点因果矩阵

目标：回答推进量和两阶段门禁是否真正改善 A1，而不是只修复烟测流程。

对象：

1. A1-pt01：旧成功点，验证新策略不退化。
2. A1-pt12：远离目标但局部导数平滑，验证是否入盆失败。
3. A1-pt13：存在证据冲突，验证源状态和分支口径。

实验矩阵：

1. 普通基线：不启用门禁，使用原外层策略。
2. 精修门禁：只使用精修可用通道。
3. 入盆门禁：只使用入盆可用通道。
4. 自动两阶段：先入盆，后精修。

控制要求：

1. 使用同一初始策略，优先冷启动或统一初值；热启动实验单独列为流程验证，不进入算法成功统计。
2. 每组都记录误差曲线、电流曲线、推进量曲线、接受/拒绝记录、最终姿态和分支状态。
3. 每个点输出唯一主因：门禁过保守、入盆失败、局部模型失效、分支跳变、弱平衡、疑似不可达。

验收标准：

1. A1-pt01 必须保持 `5 mm` 内。
2. A1-pt12 和 A1-pt13 若未进入 `5 mm`，必须完成可追溯归因。
3. 若自动两阶段不能改善 pt12/pt13，不允许继续扩点；应返回门禁审计或初始化策略。

### P2：A1 门禁语义再审计

入口条件：P1 显示门禁或阶段策略仍然是主因。

任务：

1. 将门禁分为入盆通道、精修通道、禁用通道。
2. 对推进量单独审计，不再只用相对误差判断。必须同时检查真实末端位移贡献、方向正确率、回环稳定性和不同步长下的一致性。
3. 增加门禁前后任务秩。若禁用某通道后末端三维任务降秩，必须在报告中说明。
4. 对 A1-pt13 复核不同源状态下的灵敏度结论，区分失败状态附近导数和近目标分支导数。

验收标准：

1. 推进量的角色被明确标注为入盆可用、精修可用、仅诊断可用或禁用。
2. 门禁表记录适用状态，不允许外推到未审计状态。

### P3：A2 三点失败闭环

目标：在不套用 A1 策略的前提下，把 A2 三个代表点的失败类型封存清楚。

对象：

1. A2-pt05：成功点，验证可保持性和分支连续性。
2. A2-pt17：弱平衡点，验证隔离规则是否稳定。
3. A2-pt19：严重失败点，验证分支不连续和样本不足是否可复现。

任务：

1. 复核三点的平衡质量、回环误差、分支连续性和有限差分稳定性。
2. 对每点输出风险等级：可小范围使用、弱平衡隔离、分支不连续、证据不足、疑似不可达。
3. 不运行 A2 扩点实验，除非三点闭环通过。

验收标准：

1. A2-pt05 保持成功且分支风险可解释。
2. A2-pt17 若仍弱平衡，必须被规则稳定隔离，而不是被当作普通失败。
3. A2-pt19 必须明确是分支不连续、灵敏度不可信、还是目标过远。

### P4：扩点门槛

A1 扩点入口：

1. P0 通过。
2. A1-pt01 不退化。
3. A1-pt12 和 A1-pt13 至少完成明确归因；若两点都无法改善，需先修改策略，不进入扩点。

A2 扩点入口：

1. A2 三点失败闭环通过。
2. 至少一个成功点保持成功，弱平衡和分支不连续点有稳定隔离规则。

扩点顺序：

1. A1 先做 5 点，再做 10 点，再做 20 点。
2. A2 先做 3 点闭环，再做 6 点小回归，最后才考虑 20 点。

## 六、被否决的路线

1. 直接把当前两阶段烟测扩展到 A1 20 点。原因是该烟测属于热启动零迭代流程验证，证据强度不足。
2. 全局放开推进量。原因是推进量可能只适合入盆阶段，不一定适合精修阶段。
3. 继续只调阻尼、迭代次数或接受阈值。原因是当前主要矛盾不是单一阻尼参数，而是证据口径、通道门禁和分支连续性。
4. 将 A1 门禁策略直接用于 A2。原因是 A2 的主要风险是弱平衡和分支不连续。
5. 以全域可达性采样替代当前审计。原因是现有问题尚未排除灵敏度、门禁和分支因素，直接采样会掩盖根因。
6. 放宽 `5 mm` 阈值、FK 容差或离散化网格。原因是这会破坏与既有结果的可比性。

## 七、适用边界

本计划仅适用于当前无重力、A1/A2 单点磁化导管、末端位置控制任务。若后续加入重力、末端姿态约束、多点磁化、不同离散化网格或不同 FK 容差，必须重新执行 P0 与代表点审计。

## 八、建议下一步

下一轮无人值守任务应围绕 P0 到 P3 展开，但不能追求一次性全量扩点。最小有效目标是：

1. 修复并固化证据口径。
2. 完成 A1 三点因果矩阵，得到 A1 是否能继续推进扩点的结论。
3. 完成 A2 三点失败闭环，得到 A2 是否能进入小回归的结论。
4. 若某阶段失败，不停止在“失败”结论，而是按主因返回对应修正环节。
