# A1-pt13分支冲突闭合进展纪要

## 一、结论摘要

截至本轮实验，A1-pt13不应再被归类为物理不可达点。它在不同初始分支上表现差异很大：一条分支停滞在约`49 mm`，另一条接近成功分支可被进一步精修到`4.716 mm`，已经进入`5 mm`交付阈值。

这说明A1-pt13的主要问题不是目标点绝对不可达，而是外层有监督逆运动学对平衡分支和初值继承高度敏感。后续A1交付流程必须把候选分支管理作为核心模块，而不能只依赖单一路径热启动。

## 二、关键实验证据

### 2.1 局部停滞分支

实验目录：

`experiment_records_ik_optimize/20260714150305_p2_a1_pt13_predred_bypass_gate_probe/`

输出目录：

`DELIVER_TO_EXP/formal_experiments/20260714150407_A1_A2_5mm_supervised_IK_no_gravity/`

结果：

- 初始真实末端误差：`49.206 mm`。
- 最终真实末端误差：`46.110 mm`。
- 外层迭代：25轮。
- 结论：预测下降门禁绕过修正确实释放了有效候选步，但在该局部分支上只能有限改善，不能进入`5 mm`阈值。

### 2.2 两阶段入盆尝试

实验目录：

`experiment_records_ik_optimize/20260714151351_p3_a1_pt13_two_stage_basin_probe/`

输出目录：

`DELIVER_TO_EXP/formal_experiments/20260714151447_A1_A2_5mm_supervised_IK_no_gravity/`

结果：

- 入盆阶段误差：`47.152 mm`。
- 精修阶段误差：`46.872 mm`。
- 结论：把`I3`加入入盆通道没有把`49 mm`停滞分支带入更好吸引域。

### 2.3 接近成功分支精修

实验目录：

`experiment_records_ik_optimize/20260714152216_p3_a1_pt13_near_success_refine_probe/`

输出目录：

`DELIVER_TO_EXP/formal_experiments/20260714152311_A1_A2_5mm_supervised_IK_no_gravity/`

结果：

- 初始真实末端误差：`5.778 mm`。
- 最终真实末端误差：`4.716 mm`。
- 外层迭代：1轮。
- 接受步数：2。
- 拒绝步数：0。
- FK状态：`GOOD`。
- 结论：接近成功分支继承正确时，A1-pt13可以在固定物理模型、固定网格和固定容差下达到`5 mm`阈值。

## 三、对A1交付策略的影响

1. A1-pt13应标记为“分支继承可解”，不能再作为物理不可达证据。
2. A1正式交付流程需要候选分支池，至少包含相邻成功点热启动、反向遍历和已保存近解分支三类来源。
3. 候选分支必须经过真实末端误差、FK平衡质量、内部状态重载和中心线一致性门禁，不能只凭最终误差筛选。
4. 对于仍失败的点，应优先判断是否存在历史或邻域近解分支，而不是继续在单一停滞分支内调大步长或放宽容差。

## 四、下一步

优先把A1-pt13的“近解分支继承加精修”固化为候选池策略，然后对A1的剩余失败点做相同筛查。若多个点都能通过候选分支池进入`5 mm`，再运行A1十点小回归；若只有pt13有效，则继续定位其他失败点的主因。
