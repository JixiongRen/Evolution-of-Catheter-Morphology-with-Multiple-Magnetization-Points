# A1/A2 有监督逆运动学诊断审计修正计划 V2

## 一、文档目的

本文档综合 2026 年 7 月 14 日多智能体审阅意见和现有诊断结果，给出下一阶段 A1/A2 有监督逆运动学的修正计划。

这里的有监督逆运动学指：外层调整八路线圈电流和推进量，内层调用正运动学求解器重新求解导管静力平衡，并以最后刚性段远端的真实末端位置作为主要监督量。本阶段仍只讨论末端位置控制，不讨论末端姿态控制。

本轮审计的核心结论是：

1. 当前不能把历史完整 40 点实验中的原始命中率当作算法冷启动能力。
2. A1 的主要问题不是灵敏度公式整体错误，而是入盆失败、平衡分支选择、有效步长塌缩和外层阻尼策略失效。
3. A1-pt13 的历史近阈值结果具有强分支依赖，不能计入冷启动成功率。
4. A2 尚未具备扩点优化条件，应先做三哨兵风险封存。
5. 下一阶段必须先修统计口径和分支可追溯性，再修外层求解器，最后分级扩点。

## 二、术语说明

- 冷启动：从标准初始形态和标准控制初值开始求解，不加载历史平衡状态。
- 热启动：使用相邻点、历史成功点、人工初值或历史平衡状态继续求解。
- 平衡分支：同一控制量下，导管可能收敛到的不同静力平衡形态。
- 分支状态重放：加载历史求解保存的内部平衡状态，使正运动学回到历史形态。
- 入盆：外层优化进入目标附近的小邻域，使局部线性近似开始有效。
- 有效步长塌缩：名义更新步存在，但经过阻尼、回溯、边界裁剪或门禁裁剪后，实际执行的电流和推进量变化接近零。
- 信赖域：限制每次更新的物理步长，避免局部线性模型在过大范围内失效。

## 三、多智能体审阅结论

### 3.1 灵敏度与末端定义

现有证据支持如下判断：A1 的局部灵敏度在源状态绑定、同分支回环门禁和小扰动范围内部分可信，但不可外推到其他平衡分支。A2 尚无生产级灵敏度证据。

真实末端定义已经在文档层面统一为最后刚性段远端，但台账脚本仍存在口径穿透风险。原因是台账中仍读取上游 `success_5mm` 字段，而不是在脚本内强制使用 `err_true_mm <= 5` 重新计算成功。后续必须显式生成 `success_true_tip_5mm`，并把柔性段末端误差仅作为辅助诊断量。

### 3.2 外层优化器

A1-pt13 的核心停止原因不是“迭代次数不足”，而是有效步长低于阈值。`reject_stall` 只是报告层推断标签，不应作为根因。外层求解器在连续拒绝后只会单调增大阻尼，容易把物理步长压到接近零；这说明必须修改接受规则、回溯后的预测下降计算、阻尼恢复和候选切换。

### 3.3 成功台账与分支依赖

全量历史扫描中，原始 `5 mm` 成功行数为 `61`，严格冷启动成功只有 `19`。对当前最关键的完整 40 点基线，原始成功为 `11/40`，严格冷启动成功为 `0/40`。因此，不能再把 `A1 7/20、A2 4/20` 描述为冷启动算法成功率。

A1-pt13 的证据链已经闭合：

1. 历史 `2.810 mm` 和 `5.778 mm` 结果均不是标准冷启动。
2. 只给定历史 `5.778 mm` 控制量，不加载分支状态时误差变为 `176.565 mm`。
3. 给定同一控制量并加载历史分支状态时，误差恢复到 `5.778 mm`。
4. 历史 `2.810 mm` 控制量单独重放时误差为 `180.966 mm`，继续优化还发生超时。
5. A1-pt01 前向候选可把 A1-pt13 拉到 `7.436 mm`，但仍未进入 `5 mm`，且发生分支回环停滞。

结论：A1-pt13 的主因是分支选择、候选不足和局部步长塌缩，不是简单不可达或迭代不足。

### 3.4 可达性与交付路线

当前不能把失败直接归因为物理不可达。已有可达性采样规模太小，只能提示存在性，不能证明不可达。多数失败发生在外层更新阶段，内层正运动学仍能给出平衡结果。A1 可进入分级修复与扩点流程，A2 应先完成三哨兵风险封存。

## 四、数学解释

控制变量定义为：

```text
c = [I_1, I_2, ..., I_8, x]^T
```

其中 `I_1` 到 `I_8` 为线圈电流，`x` 为推进量。平衡状态记为 `z`，静力平衡方程可写为：

```text
F(z, c) = 0
```

真实末端位置为：

```text
p = p(z, c)
```

若当前平衡分支保持不变，则局部线性化为：

```text
p(c + Δc) ≈ p(c) + J(c) Δc
```

其中 `J(c)` 是真实末端位置对控制变量的局部灵敏度。该线性近似只在当前平衡分支的小邻域内成立。若同一控制量从不同初始状态收敛到不同平衡形态，则原来的 `J(c)` 没有跨分支预测意义。

外层信赖域应关注预测下降与真实下降的一致性：

```text
ρ = 实际下降量 / 预测下降量
```

若 `ρ` 持续异常，说明当前局部模型不再可靠。此时应重新线性化、切换候选、缩小物理步长或回到入盆阶段，而不是继续单调增大阻尼。

## 五、正式统计口径

后续结果必须分层统计，不得混报。

| 类别 | 定义 | 是否计入冷启动成功率 |
|---|---|---|
| 冷启动成功 | 标准初始形态起步，不加载历史分支状态，真实末端误差不超过 `5 mm` | 是 |
| 失败后冷重启成功 | 前一点失败后重新从冷启动状态出发并成功 | 单独统计，不并入标准冷启动 |
| 邻点延拓成功 | 使用相邻目标点或旧成功点控制量作为初值 | 否 |
| 人工初值成功 | 手动给定控制量或历史控制量作为初值 | 否 |
| 分支状态重放成功 | 加载历史平衡状态后成功 | 否 |
| 阶段辅助结果 | 入盆阶段、精修阶段或烟测结果 | 否 |

冷启动成功的硬门禁为：

1. `initial_branch_state.enabled=false`。
2. 初值来源为标准冷启动。
3. `algorithm_statistics_included=true`。
4. 脚本内重新计算 `err_true_mm <= 5`。
5. 结果、摘要、报告和图像均使用最后刚性段远端作为末端。

## 六、修正任务

### P0：统计口径和记录封口

目标：先防止成功率继续被路径依赖污染。

任务：

1. 修改成功台账脚本，在脚本内强制计算 `success_true_tip_5mm = err_true_mm <= 5`。
2. 固定并输出 `success_flex_tip_5mm`，仅作对照，不作成功判据。
3. 把原始命中、严格冷启动、冷重启、邻点延拓、人工初值、分支重放、阶段辅助分开输出。
4. 为 A1-pt13 候选池补写 `record.md`，补齐 `historical_2p810_control_init_opt` 超时闭环说明。
5. 新增正式统计口径说明文件，避免后续再把热启动和冷启动混算。

验收标准：

1. 完整 40 点基线可重新输出分层统计表。
2. 旧 `success_5mm` 与新 `success_true_tip_5mm` 若不一致，必须标记为口径漂移。
3. 任意成功行均可追溯初值来源、分支来源和是否计入正式统计。

### P1：A1-pt13 分支候选池与停滞退出

目标：闭合 A1-pt13 主因，并尽量使其在不加载历史分支状态的条件下进入 `5 mm` 或至少稳定进入 `10 mm`。

任务：

1. 建立最小候选池：标准冷启动、A1-pt01 前向候选、反向邻点候选、确定性小扰动候选、历史分支状态候选。
2. 历史分支状态候选只作诊断，不能进入冷启动成功率。
3. 增加分支回环门禁：若中心线或状态哈希重复、误差改善小于 `0.1 mm` 且有效步长跌破阈值，则标记为分支回环停滞。
4. 对 `5--10 mm` 候选触发小信赖域精修；若失败，必须输出候选耗尽或局部模型失效。
5. 每个候选保存控制量、误差轨迹、电流轨迹、推进量轨迹、状态哈希、中心线哈希和停止原因。

验收标准：

1. 若非分支状态候选进入 `5 mm`，必须做只给控制量的重放确认。
2. 若仅历史分支状态候选接近目标，则主因归为强分支依赖。
3. 若所有非分支候选停在 `5--10 mm`，主因归为候选入盆不足与局部步长塌缩。

### P2：A1-pt12 入盆失败归因

目标：把 A1-pt12 从“未收敛”转化为唯一主因结论。

任务：

1. 运行标准冷启动、邻点候选、反向候选、确定性扰动候选和历史最好候选。
2. 记录任务秩、主要奇异值、推进量边界余量、电流边界余量、真实末端误差和平衡质量。
3. 做低成本局部采样，判断是否存在 `10 mm` 内候选。
4. 若找到近目标候选，归因为入盆失败；若多候选均远离目标，再归为疑似可达边界或可控方向不足。

验收标准：

1. 不允许最终只写“未收敛”。
2. 必须给出一个主因：入盆失败、可控方向不足、分支跳变、弱平衡或疑似可达边界。
3. 若发现近目标候选，必须形成下一轮初始化策略。

### P3：外层求解器稳定化

目标：减少有效步长塌缩和错误早停。

任务：

1. 修改接受规则：近阈值区域结合真实下降、预测下降、非恶化容差和正则项变化。
2. 回溯和物理裁剪后，使用实际执行步长重算预测下降。
3. 连续拒绝后触发重新线性化、阻尼重置、候选切换或回到入盆阶段，而不是只增大阻尼。
4. 记录步长塌缩来源：阻尼、物理边界、通道门禁、控制裁剪或数值异常。
5. 保留原路径作为对照开关。

验收标准：

1. A1-pt01 不退化，仍进入 `5 mm`。
2. A1-pt13 不再以不可解释的步长塌缩结束。
3. 所有新增策略均可关闭，且开关状态写入结果。

### P4：A2 三哨兵风险封存

目标：不追求当前 A2 扩点成功率，先给出可追溯风险标签。

对象：

1. A2-pt05：成功点，复核分支连续性和适用边界。
2. A2-pt17：弱平衡点，确认换初值后是否仍为弱平衡。
3. A2-pt19：严重失败点，拆分分支不连续、弱响应和目标过远。

任务：

1. 对三个点做只给控制量重放、分支状态重放和回环检查。
2. 对有效状态做有限差分审计，有限差分只作验证器，不作为生产灵敏度来源。
3. 输出风险等级：有限使用、弱平衡隔离、分支不连续、证据不足或疑似可达边界。

验收标准：

1. A2-pt05 若成功，必须说明是否依赖邻点延拓。
2. A2-pt17 若仍为弱平衡，应稳定隔离。
3. A2-pt19 必须完成主因拆分。
4. 未完成三哨兵封存前，不运行 A2 全量扩点。

### P5：A1 分级扩点

目标：在代表点闭合后恢复 A1 交付线。

扩点顺序：

1. A1 三点：pt01、pt12、pt13。
2. A1 五点：加入两个邻近或历史失败代表点。
3. A1 十点：覆盖圆周不同象限。
4. A1 二十点：正式交付候选。

门槛：

1. pt01 不退化。
2. pt12 有唯一主因。
3. pt13 成功或唯一主因闭合。
4. 成功率必须同时报告原始命中率、冷启动成功率、冷重启成功率、延拓成功率和分支重放成功数。

## 七、可视化和文档要求

每轮实验必须输出：

## 八、风险与边界

1. 不得把热启动或分支状态重放结果写成冷启动算法能力。
2. 不得把小规模采样未覆盖目标写成严格物理不可达。
3. 不得把 A1 代表点局部灵敏度外推到 A2。
4. 不得把 A1-pt13 历史 `5.778 mm` 当作正式成功。
5. 不得在 A2 三哨兵封存前做 A2 全量扩点。
6. 不得仅靠增加迭代次数解决有效步长塌缩。

## 九、建议执行顺序

1. 完成 P0，修复统计口径和记录缺口。
2. 完成 P1，闭合 A1-pt13 分支依赖与停滞主因。
3. 完成 P2，给出 A1-pt12 唯一主因。
4. 实现 P3 外层稳定化，并用 A1-pt01、pt12、pt13 回归验证。
5. 完成 P4，封存 A2 三哨兵风险。
6. 满足门槛后进入 P5，逐步扩展 A1。

## 十、当前阶段性判断

当前不能宣称 A1/A2 有监督 IK 已可交付。更准确的表述是：

1. A1 已完成代表点证据重建，具备继续修复并分级扩点的条件。
2. A1-pt13 主因已经高度明确，下一步应重点做候选池和分支停滞处理。
3. A1-pt12 仍需从“未收敛”转化为唯一主因。
4. A2 只能先做三哨兵风险封存。
5. 完整 40 点实验目前只能作为路径依赖和风险地图，不能作为冷启动算法成功率。
