# A1/A2 有监督逆运动学诊断审计修正计划（三版）

## 一、目标

本计划用于承接 A1/A2 单点磁化导管有监督逆运动学的诊断与审计结果，形成下一阶段可执行的修正路线。当前目标不是扩大正式实验规模，而是把已有诊断结论转化为求解器内的硬约束、策略表和验证流程，使后续实验能够区分以下三类问题：

1. 目标点在物理上可能可达，但当前外层优化策略失败。
2. 局部灵敏度在特定平衡分支上不可靠，导致更新方向错误。
3. 目标点高度疑似超出当前导管构型与电流约束下的可达区域。

固定实验基线保持不变：

- 重力关闭。
- 离散化参数为 `M_list=5`。
- 正运动学收敛容差为 `1e-5`。
- 单路线圈电流范围为 `[-20, 20] A`。
- 推进量范围为 `[0.003001, 0.203] m`。
- 成功判据只使用最后刚性段远端的真实末端位置，阈值为 `5 mm`。
- 必须使用 GPU。CPU 回退批次只作为环境异常记录，不纳入数值结论。

## 二、多智能体讨论后的共识

### 2.1 已经可以确认的结论

1. 当前 A1/A2 有监督逆运动学尚未达到稳定交付水平。历史正式批次中 A1 约为 `7/20` 进入 `5 mm`；A2 的独立正式口径约为 `3/20`，若包含补跑合并结果可到 `4/20`。后续必须按实验模式分账，不能混合统计独立运行、顺序热启动和人工分支种子补跑。

2. A1-pt13 的近解具有显著平衡分支依赖。四组重载对照中，只有同时复用控制量和内部平衡状态时能回到 `5.778 mm` 附近；只复用控制量或只复用内部状态均会落到远离近解的形态。因此灵敏度必须绑定控制量和平衡状态对：

   \[
   \Delta \mathbf p \approx
   \mathbf J(\mathbf c^\*,\mathbf z^\*)\Delta \mathbf c ,
   \]

   其中 \(\mathbf c^\*\) 为电流与推进量，\(\mathbf z^\*\) 为正运动学内部平衡状态。若 \(\mathbf z^\*\) 改变，不能复用同一局部灵敏度结论。

3. A1-pt13 的全通道复审显示没有生产级通道。保守聚合结果为：I5 仅是有限使用候选，安全步长约 `0.125 A`；推进量和其余电流通道均暂不放行。推进量通道在当前近解邻域中表现为“可回环但线性误差超限”，不能作为可信雅可比列直接参与生产更新。

4. 同分支 I5 小步精修只有弱改进。误差从 `5.778 mm` 降至约 `5.689 mm`，说明 I5 并非完全无效，但不足以解释全部剩余误差，也不能证明“门控过窄”就是主因。

5. 现有证据不能把 A1-pt12、A1-pt13 或其他失败点判为物理不可达。可达性采样和历史补跑只能否定“已经证明不可达”，不能证明“只要优化器修好必然可达”。

### 2.2 仍不能直接下结论的事项

1. 不能把 I5+x 三臂实验中的任何改善解释为推进量灵敏度正确。若 x 未通过审计，I5+x 最多说明额外控制自由度具有经验价值。

2. 不能把 A1-pt13 的局部结论外推到 A1/A2 全部点位。A1-pt13 是调参和审计样本，不应同时作为泛化能力的主要证明。

3. 不能把 `best_accept`、`final`、`last_accept` 视为真正独立的三个状态选择器。当前 A1-pt13 审计中这些状态的哈希基本一致，不能证明对多平衡状态具有鲁棒性。

4. 不能混用不同日期、不同提交和不同实验链路中的 A1-pt13 结果。当前修正主线以 `20260713232320` 源实验的 `5.778 mm` 近解为准。

## 三、当前代码层面的主要断点

### 3.1 灵敏度可信度没有进入外层决策

外层求解目前容易把“能算出灵敏度矩阵”近似等同于“可以使用该灵敏度”。但审计结果表明，许多状态虽然能得到矩阵，实际处于病态截断、有效秩不足或预测误差过大的状态。后续需要把灵敏度状态、有效秩、截断阈值和通道审计结果共同用于外层更新决策。

### 3.2 通道门控过于二值化

当前门控主要是放行或屏蔽，无法表达“有限使用、带安全步长、带证据等级”的通道。A1-pt13 的 I5 就属于有限使用候选，而不是生产级通道。门控结构必须升级为：

- 禁用：不参与局部线性更新。
- 有限使用：允许参与，但必须有安全步长上限和证据来源。
- 生产使用：可正常参与，但仍需记录审计版本。

### 3.3 推进量通道需要降级处理

当前推进量的隐式灵敏度在 A1-pt13 上不满足局部线性精度要求。生产路径中不应默认把推进量作为可信雅可比列。推进量可保留为经验性微小搜索变量或单独有限差分审计变量，但不能未经门禁直接参与主线更新。

### 3.4 分支连续性没有成为硬约束

批量正式实验中跨点热启动主要传递控制量，而 A1-pt13 已证明只传控制量不足以回到同一平衡分支。后续同分支模式必须显式传递并验证内部平衡状态，至少记录并检查：

- 源控制量哈希。
- 当前控制量哈希。
- 内部状态哈希。
- 真实末端重放误差。
- 中心线重放误差。

### 3.5 实验模式统计尚需分账

独立求解、顺序热启动、人工分支种子、补跑合并结果具有不同含义。后续报告中的成功率必须分开统计，不能把补跑成功率混入独立求解成功率。

## 四、修正路线

### P0：证据冻结与实验分账

目标：让每条实验记录都可追溯、可复算、可按模式分类。

任务：

- 在审计和正式实验输出中统一记录提交号、GPU 设备、协议版本、实验模式、源快照、控制量哈希、内部状态哈希、真实末端误差和中心线哈希。
- 将实验模式至少分为独立运行、顺序热启动、人工分支种子和补跑合并。
- 缺少关键哈希、设备回退 CPU 或协议版本不一致的记录自动标记为无效。

验收：

- 任意一行审计或正式结果都能定位到唯一源状态与唯一控制量。
- 汇总表不再混合统计不同实验模式。

### P1：统一审计协议与分类器

目标：避免不同脚本、不同扰动尺度和不同状态选择器生成互相冲突的门控结论。

任务：

- 以现有灵敏度复审链路为主审计入口，生成唯一协议版本。
- 每个通道只能落入生产使用、有限使用、禁用、状态依赖或证据不足之一。
- 对有限使用通道记录安全步长、扰动尺度、回环分段、相对误差中位数和 90 分位数。

验收：

- A1-pt13 的 I5 保留为有限使用候选。
- A1-pt13 的推进量在当前协议下保持禁用或状态依赖，不得被直接放行为生产通道。

### P2：同分支重载硬门禁

目标：让同分支灵敏度和同分支精修只能在可重放的平衡分支上进行。

任务：

- 将同分支重载门禁接入正式实验脚本和外层求解器入口。
- 同分支模式下，若真实末端回放误差大于 `0.1 mm` 或中心线最大误差大于 `0.5 mm`，则该状态不可用于局部灵敏度更新。
- 跨点热启动必须支持同时传递控制量和内部平衡状态，而不是只传递电流和推进量。

验收：

- A1-pt13 的 `control_and_state` 通过门禁。
- `control_only`、`state_only` 或 `none` 不能伪装成同分支证据。

### P3：通道策略表与安全步长

目标：把审计结果变成外层求解器能直接使用的点级策略。

策略表字段至少包含：

- 点位编号。
- 状态选择器。
- 源快照路径。
- 通道类型和通道编号。
- 通道等级。
- 安全步长。
- 证据来源和协议版本。
- 中位相对误差和 90 分位相对误差。
- 是否弱响应。

外层更新规则：

- 禁用通道不进入局部线性系统。
- 有限使用通道必须执行每通道步长上限。
- 若推进量被禁用，则与推进量耦合的正则项不得间接压制可信电流更新。
- 灵敏度状态不是正常时，只允许使用通过审计的有限子空间。

验收：

- A1-pt13 默认只允许 I5 的有限使用策略，推进量不作为生产雅可比列。
- 没有可信控制子空间时，求解器应给出合法停止原因，而不是继续使用坏灵敏度迭代。

### P4：三臂同分支精修消融

目标：判断额外控制自由度是否对 A1-pt13 有经验价值，但不把该实验误读为通道灵敏度放行。

三臂必须从同一重载状态独立起跑：

- I5-only。
- x-only。
- I5+x。

解释规则：

- 若 I5+x 相对 I5-only 稳定改善至少 `0.3 mm`，说明额外自由度具有经验控制价值，但仍需单独审计 x 灵敏度。
- 若三臂均改善有限，优先检查目标函数尺度、接受准则、同分支局部可达性和灵敏度公式链。
- 若 x-only 有明显改善但灵敏度审计仍失败，应将 x 作为经验性线搜索变量，而不是生产雅可比列。

验收：

- 三臂独立运行、可重放、可复测。
- 所有结论明确区分“控制效益”和“灵敏度可信度”。

### P5：两阶段外层求解

目标：避免强门控小步策略破坏全局入盆，同时避免近解阶段继续使用不可靠通道。

阶段一为全局入盆：

- 不启用硬通道门控，或只使用软惩罚。
- 允许较大的电流和推进量探索。
- 目标是进入 `10-15 mm` 局部邻域。

阶段二为同分支精修：

- 必须通过同分支重载门禁。
- 使用点级通道策略表和安全步长。
- 接受准则优先真实末端误差，不允许正则项改善掩盖末端误差退化。

验收：

- A1-pt01 不得从历史 `3.614 mm` 水平明显退化。
- A1-pt13 应进入 `5 mm`，或给出唯一主因明确的阻塞包。
- A1-pt12 相对强门控失败结果必须有可解释改善；若无改善，应转入分支池或可达性诊断。

### P6：A1 分级回归与 A2 哨兵准入

目标：防止局部样本修复被误判为全局可用。

顺序：

1. A1 三点：pt01、pt12、pt13。
2. A1 十点，包含未参与调参的保留点。
3. A1 二十点正式回归。
4. A2 哨兵点：pt05、pt17、pt19。
5. A2 六点小回归，最后再考虑 A2 二十点。

验收：

- A1 三点中旧成功点不退化超过 `0.25 mm`。
- A1 十点至少 `7/10` 进入 `5 mm`，且所有失败点都有主因标签。
- A1 二十点目标为至少 `15/20` 进入 `5 mm`，中位误差不超过 `3 mm`。
- A2 不得直接使用 A1 的点级通道策略，必须先通过哨兵点审计。

## 五、代码修改优先级

### 第一优先级

- `DELIVER_TO_EXP/run_a1_a2_sensitivity_reaudit.py`：统一审计协议和分类器。
- `inverse_kinematics/ik_control_gate.py`：支持禁用、有限使用、生产使用、安全步长和证据字段。
- `inverse_kinematics/ik_multisite_lm_opt.py`：将灵敏度状态、通道安全步长和真实末端优先接受准则接入外层更新。
- `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py`：支持实验模式分账、同分支重载门禁和跨点控制量加内部状态传递。

### 第二优先级

- `inverse_kinematics/ik_branch_state.py`：完善同分支重载、回环和中心线一致性门禁的输出。
- 正式实验汇总脚本：统一成功率、尾部误差、失败主因和模式分账。

### 暂缓进入主线的研究项

- 替换灵敏度公式为新的谱过滤方式。
- 在线小扰动探测决定当步可用通道。
- 多分支状态池自动选择。

这些方向有研究价值，但在证据冻结、通道策略表和同分支门禁稳定前，不宜作为主线改动。

## 六、失败保护

- 不允许通过修改 FK 物理模型、放宽容差、改变目标圆定义或替换成功判据来改善 IK 表现。
- 任何通道若回环失败、弱响应或跨协议冲突，默认不得晋升为生产使用。
- 三臂消融必须独立起跑，禁止串行接力。
- 若关键结论来自人工分支种子，必须单独标注，不能计入独立求解成功率。
- 若没有可信控制子空间，应输出阻塞包，而不是继续盲目迭代。

## 七、下一阶段执行结论

下一阶段应先完成 A1-pt13 的三臂同分支精修消融，并同时落地通道策略表、安全步长和同分支重载门禁的最小实现。若三臂实验显示额外自由度确有价值，则进入两阶段外层求解器原型；若三臂改善有限，则转向目标函数尺度、接受准则和同分支局部可达性复核。只有 A1 三点通过后，才进入 A1 十点和 A2 哨兵点。
