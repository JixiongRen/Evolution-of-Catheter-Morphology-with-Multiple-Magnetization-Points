# A1/A2 有监督逆运动学灵敏度修正计划

## 一、文档目的

本文档基于 `20260713203859_p1_clean_failed_channel_reaudit` 清洁复审结果和多智能体审阅意见，修订下一阶段 A1/A2 有监督逆运动学修正路线。核心原则是：先把已经确认不可信的灵敏度通道从外层逆运动学更新中隔离，再对持续异常通道做定向公式复核，最后用少量代表点验证是否能改善正式圆周跟踪实验。

这里的“有监督逆运动学”指外层按目标末端位置优化电流和推进量，内层每一步调用正运动学求解器获得平衡姿态。当前讨论的“灵敏度”指控制量微小变化引起真实末端位置变化的局部导数。

## 三、当前可以严格支持的结论

### 3.1 已证实事实

1. A1 的 `pt13` 中，电流 3 和电流 4 的灵敏度误差在当前复审设置下明显超限，不能作为生产级外层更新通道。
2. A2 的 `pt05` 中，电流 1 和电流 3 的灵敏度误差仍不稳定，至多只能作为有限使用通道。
3. A2 的 `pt19` 中，电流 5 的灵敏度误差超限，不能直接进入完整九维更新。
4. A2 的 `pt17` 中，电流 4 比上述问题电流通道更接近可用，但仍应按有限使用处理。
5. 推进量通道在当前少量扰动点下表现明显好于问题电流通道，但仍需保留信赖域限制。
6. 目前不应继续使用完整九维更新作为默认策略。完整九维更新指同时使用 8 路线圈电流和 1 个推进量通道构造外层步长。

### 3.2 尚不能严格支持的说法

以下判断只能作为待验证假设，不能写成已证实结论：

1. 不能仅凭当前数据断言某个失败样本已经发生平衡分支跳变。当前字段把“分支不一致”和“重放失败”合并记录，证据不够干净。
2. 不能直接断言异常主因是磁场偏导、尺度归一或奇异值截断错误。当前数据只能说明这些环节需要复核。
3. 不能直接断言 A2-pt17 的主要问题是外层策略、目标不可达或初值分支。当前 P1 数据只证明它的局部灵敏度不是最坏嫌疑。
4. 不能把“弱响应”作为机器判定结论。当前复审中弱响应触发行数为 0，后续需要改进弱响应门禁字段和分类器。

## 四、数学定义与门禁原则

控制向量定义为

\[
\mathbf c=[I_1,I_2,\ldots,I_8,x]^T ,
\]

其中 \(I_i\) 为第 \(i\) 路线圈电流，\(x\) 为推进量。真实末端位置为

\[
\mathbf p_{\mathrm{end}}=\mathbf f(\mathbf c).
\]

局部灵敏度矩阵为

\[
\mathbf J=\frac{\partial \mathbf p_{\mathrm{end}}}{\partial \mathbf c}.
\]

有限差分校验使用

\[
\mathbf J_{\mathrm{FD},j}
=
\frac{\mathbf f(\mathbf c+h_j\mathbf e_j)-\mathbf f(\mathbf c-h_j\mathbf e_j)}
{2h_j}.
\]

相对误差为

\[
E_j=
\frac{\|\mathbf J_j-\mathbf J_{\mathrm{FD},j}\|}
{\max(\|\mathbf J_{\mathrm{FD},j}\|,\epsilon)}.
\]

工程门禁不应只看相对误差，还应同时检查有限差分位移幅值、正反扰动是否回到同一平衡分支、重放是否收敛、方向夹角和绝对误差。若证据不足，默认视为不可信，而不是默认放行。

## 五、修正路线

### P2-lite：外层可靠子空间更新

这是下一阶段最高优先级。其目标不是先修复所有灵敏度公式，而是立刻阻止已知不可靠通道污染外层逆运动学。

需要实现的机制如下：

1. 生成机器可读的通道允许清单，至少包含导管类型、点位、状态选择器、通道编号、通道等级、审计提交号、配置摘要和阈值版本。
2. 外层逆运动学启动时必须加载该清单。若清单缺失、版本不匹配或通道证据不足，默认禁止对应通道参与更新。
3. 外层更新从完整九维问题改为可靠子空间问题：

\[
\min_{\Delta \mathbf c_S}
\|\mathbf J_S \Delta \mathbf c_S+\mathbf r\|_2^2
+\lambda \|\mathbf D_S \Delta \mathbf c_S\|_2^2 ,
\]

其中 \(S\) 为通过门禁的通道集合，\(\mathbf r\) 为真实末端位置误差，\(\lambda\) 为阻尼系数，\(\mathbf D_S\) 为尺度归一矩阵。

4. 每一步必须记录实际启用通道、被屏蔽通道、屏蔽原因、子空间维度、步长、接受或拒绝原因。
5. 接受准则以真实刚性末端位置误差为主，不再以柔性段末端或代理指标替代。
6. 若某一点所有电流通道都不可信，则允许仅使用推进量或冷启动策略，但必须在结果中标注“有限控制能力”。

### P2-audit：持续异常电流通道定向复核

该阶段只复核明确异常的通道，避免无差别扩展实验规模。优先对象为：

1. A1-pt13 的电流 3 和电流 4。
2. A2-pt05 的电流 1 和电流 3。
3. A2-pt19 的电流 5。

复核内容包括：

1. 电流到磁场映射是否与 SUPIEE 标定文件一致。
2. 磁场对永磁体力和力矩的偏导是否与当前正运动学残差定义一致。
3. 无量纲化尺度是否同时作用在有限差分审计和隐式灵敏度中。
4. 奇异值截断是否改变方向，而不是仅抑制数值噪声。
5. 真实刚性末端位置链式偏导是否完整包含最后刚段几何。

该阶段只允许得到“已修复”“仍异常但原因未定”“证据不足”三类结论，不允许过早宣称物理不可达。

### P2-regression：A1 三点回归

完成 P2-lite 后，先运行 A1 三点回归，而不是直接跑完整 40 点。代表点为：

1. `pt01`：成功基准点，用于检查是否退化。
2. `pt12`：末端定义敏感点，用于检查真实末端门禁。
3. `pt13`：平台停滞点，用于检查可靠子空间更新是否有收益。

每个点至少保存误差迭代曲线、电流和推进量曲线、启用通道记录、最终姿态图和运行环境。若 `pt01` 明显退化，则停止扩展并回滚策略；若 `pt13` 改善但仍未进入 5 mm，则进入聚焦诊断；若三点均满足门禁，再扩展至 A1 五点。

### P1.5-focused：聚焦分支与初值诊断

该阶段只对 P2-lite 后仍无法解释的点执行。优先对象为 A2-pt17，其次为 P2 回归后仍异常的 A1-pt13。

诊断内容包括：

1. 冷启动、顺序热启动、反向热启动和邻近成功点热启动对照。
2. 同一控制量下不同正运动学初值是否收敛到不同形态。
3. 正反扰动回环误差是否超过门限。
4. 若存在明显多平衡分支，外层更新必须加入分支连续性门禁。

## 六、分类器修正

当前通道分类只有三类，不能支撑计划中的细粒度归因。下一步分类器应改为两级结构。

一级分类用于工程门禁：

1. 可生产使用。
2. 可有限使用。
3. 同分支误差超限。
4. 分支或重放失败。
5. 弱响应或证据不足。

二级分类用于科研解释：

1. 疑似弱响应。
2. 疑似线性窗口过窄。
3. 疑似奇异值截断失配。
4. 疑似磁场或力矩偏导失配。
5. 疑似真实末端链式偏导缺失。
6. 疑似平衡分支跳变。
7. 疑似目标接近可达边界。

只有一级分类达到“可生产使用”或“可有限使用”的通道，才允许进入外层更新；二级分类只作为后续修复方向，不作为直接放行依据。

## 七、验收标准

下一阶段完成时应满足以下要求：

1. 外层逆运动学具有默认失败关闭机制。未通过审计、证据不足、版本不匹配或重放失败的通道不得参与更新。
2. 每一步外层迭代都能追溯实际启用通道和屏蔽原因。
3. A1 三点回归中，`pt01` 不出现明显退化，`pt13` 相比原始结果有可量化改善；若不能进入 5 mm，必须给出可复核原因。
4. 所有实验必须使用 GPU。若退回 CPU，该组结果标为无效。
5. 所有实验继续使用无重力、`M_list=5`、正运动学容差 `1e-5`、电流范围 `[-20,20] A`、推进范围 `[0.003001,0.203] m` 和真实末端 5 mm 阈值。
6. 实验记录必须包含运行命令、日志、环境、轨迹图、误差曲线、通道门禁表和中文报告。
7. 每轮大实验结束后提交到本地 `ik_optimize` 分支，不推送远程。

## 八、当前优先级

1. 实现 P2-lite：可靠子空间更新和通道硬门禁。
2. 修正通道分类器：把当前三分类扩展为两级分类，避免人为过度归因。
3. 对异常电流通道做定向公式复核。
4. 运行 A1 三点回归。
5. 只对残余失败点进入 P1.5-focused。

该顺序的理由是：当前已经足以证明完整九维更新存在风险，但尚不足以证明具体物理机理。因此，最稳妥的工程路线是先隔离风险通道，再用更细的诊断字段逐步定位根因。
