# A1/A2 有监督逆运动学诊断审计结果修正计划 V2

## 一、文档目的

本文档基于近期 A1/A2 有监督逆运动学实验、诊断审计和多智能体复核意见，给出下一阶段可执行的修正计划。

这里的有监督逆运动学指：外层调整线圈电流和推进量，内层调用正运动学求解器重新求解静力平衡，并以最后刚性段远端的真实末端位置作为监督信号。当前阶段只讨论末端位置控制，不讨论末端姿态控制。

本文档的核心判断是：当前不能直接扩大到 A1/A2 全量交付实验。必须先把 A1-pt13 的近阈值停滞、A1-pt12 的入盆失败或可控性不足、A2 的弱平衡和分支风险分别闭合。

## 二、多智能体复核摘要

本轮复核从三个角度进行：

1. 证据链复核：确认哪些结论已经由实验记录和数表直接支撑。
2. 反例与风险复核：识别哪些结论可能被过度解释。
3. 修正路径复核：给出阶段划分、验收条件和失败后的转向规则。

三个方向的意见基本一致：

1. P0 证据口径修复已经生效，但它只解决“怎么记账”，不能自动证明算法能力。
2. A1 与 A2 必须分开处理，不能把 A1 的局部修正策略直接外推到 A2。
3. A1-pt13 的近阈值停滞是真实现象，但它属于特定平衡分支上的局部现象，不能直接等同于 pt13 的全局可解性。
4. A1-pt12 目前只能排除“单纯推进量门禁导致失败”，还不能判定为不可达。
5. A2 当前最主要的问题不是外层参数调节，而是弱平衡、分支不连续和可统计样本不足。
6. 后续必须继续区分流程验证、热启动验证、冷启动算法验证、辅助阶段行和最终判定行。

## 三、已经确认的事实

### 3.1 证据口径

P0 证据口径修复已经落地。两阶段热启动结果、零迭代通过结果和辅助阶段结果已经能够从正式算法统计中剥离。A1 三点因果矩阵中，`p2_two_stage_gate` 的精修行被标记为流程验证，不进入算法成功率统计。

这说明当前已经能避免一种严重误判：把历史分支状态读取成功或零迭代通过误写成算法本身成功。

### 3.2 A1-pt01

A1-pt01 的因果关系已经较明确：

| 策略 | 真实末端误差 |
|---|---:|
| 无门禁 P2 | `3.614 mm` |
| 精修门禁 | `27.787 mm` |
| 入盆门禁 | `4.383 mm` |
| 两阶段门禁 | `4.383 mm`，但属于流程验证 |

结论：推进量在入盆阶段是必要自由度。把推进量全流程硬禁用会破坏已知成功点。

### 3.3 A1-pt12

A1-pt12 在四组策略下均没有进入 `5 mm`：

| 策略 | 真实末端误差 |
|---|---:|
| 无门禁 P2 | `50.478 mm` |
| 精修门禁 | `81.688 mm` |
| 入盆门禁 | `58.235 mm` |
| 两阶段门禁 | `56.020 mm`，但属于流程验证 |

结论：A1-pt12 的失败不能再简单归因为推进量被禁用。它更可能涉及入盆失败、局部可控方向不足、平衡分支不合适，或目标接近当前配置的可达边界。

### 3.4 A1-pt13

A1-pt13 的当前最好正式统计结果是无门禁 P2，真实末端误差为 `5.778 mm`，接近但未进入 `5 mm`。历史记录已确认，该点没有被汇总遗漏的更优接受状态。

进一步检查显示，最后阶段更新步长极小，误差仍缓慢下降但停在阈值外。这更符合局部模型、步长压缩或停止逻辑导致的近阈值停滞，而不是单纯迭代次数不足。

必须注意：A1-pt13 的近阈值状态只代表一个特定平衡分支。此前代表点审计中，pt13 在另一源状态下仍约为 `69.830 mm`。因此不能只围绕 `5.778 mm` 分支做局部修补后就声称 pt13 已全局解决。

### 3.5 A2

A2 当前不能进入正式扩点：

1. A2-pt05 可以进入 `5 mm`，但分支稳定性和有限差分统计样本不足，不能直接生产化。
2. A2-pt17 已被识别为弱平衡隔离对象，需要确认换分支或换初值后是否仍弱平衡。
3. A2-pt19 误差大、分支失败和弱响应样本多，尚不能在分支不连续、弱响应、目标过远之间唯一归因。

## 四、核心数学判断

外层逆运动学本质上是在控制变量

```text
c = [I_1, I_2, ..., I_8, x]^T
```

上寻找末端位置满足目标的状态。局部线性模型可以写作：

```text
p(c + Δc) ≈ p(c) + J(c) Δc
```

其中 `J(c)` 是当前平衡分支上的末端位置灵敏度。该模型只在当前平衡分支附近的小邻域内有效。

因此有三个重要后果：

1. 若平衡分支发生跳变，即使 `J(c)` 在原状态附近准确，也不能保证外层更新有效。
2. 若硬门禁删除了必要控制通道，矩阵 `J(c)` 的任务秩会下降，目标可能从可调变成不可调。
3. 若步长被裁剪或回溯到极小，预测下降量与真实下降量必须重新核对，否则可能在阈值外过早停滞。

信赖域判据应同时比较预测下降和真实下降：

```text
ρ = 实际下降量 / 预测下降量
```

若小步准确、大步失败，说明线性化半径过小，应修正步长和回溯策略。若小步也失败，则应优先怀疑灵敏度、分支连续性或平衡质量。

## 五、总体修正原则

1. 不改变 FK 容差、离散化网格、重力设置、真实末端定义、成功阈值或控制边界来换取成功率。
2. 不把热启动零迭代通过计入算法成功率。
3. 不把近解分支上的经验微搜结果写成可泛化灵敏度。
4. 不把门禁表从源状态外推到未经审计的状态。
5. 不把 A1 的策略直接套用到 A2。
6. 不把可达性采样未覆盖写成严格不可达。
7. 每个失败点必须给出唯一主因和证据等级。

## 六、分阶段修正计划

### P0：证据口径冻结与运行准入

目标：保证后续实验结果可解释、可复现、不可混淆。

任务：

1. 继续保留并检查以下字段：实验类型、是否热启动、是否零迭代通过、是否辅助阶段行、是否最终判定行、初始状态来源、初始状态哈希、门禁表哈希、停止原因、是否纳入算法统计。
2. 正式实验前记录 GPU、提交号、工作区状态、命令、门禁文件哈希、初始分支状态哈希和运行环境。
3. 若 GPU 回退、真实末端定义漂移、门禁缺键、图像索引错误或摘要字段缺失，对应实验作废。

验收标准：

1. 所有结果都能分清流程验证、热启动验证和冷启动算法验证。
2. 每个目标点最多只有一行进入正式成功率统计。
3. 报告、摘要、命令、图像和运行环境互相一致。

### P1：A1-pt13 近阈值停滞专项修正

目标：解释并尽量修复 pt13 停在 `5.778 mm` 的问题。

任务：

1. 在核心求解器中显式记录真实停止原因，包括有效步长过小、预测下降过小、连续拒绝、达到最大迭代、达到目标阈值。
2. 区分报告层面的 `10 mm 内但未达标` 与核心求解器停止原因，避免把报告标签误当成算法终止条件。
3. 增加近阈值补救策略：当误差在 `5--10 mm` 且真实误差仍有下降趋势时，触发重新线性化、小信赖域搜索或经验微搜。
4. 经验微搜只能作为物理候选搜索，不得直接声明推进量灵敏度已经可信。
5. 对 pt01 同步回归，防止修复 pt13 时破坏已知成功点。

验收标准：

1. A1-pt01 保持 `5 mm` 内。
2. A1-pt13 若进入 `5 mm`，必须说明它是冷启动统一协议成功、热启动流程成功，还是近解分支局部补救成功。
3. 若仍未进入 `5 mm`，必须输出唯一主因：步长下限、局部模型失效、分支迁移、可控方向不足或疑似可达边界。

### P2：A1-pt12 入盆失败与可控性审计

目标：判断 pt12 失败究竟来自外层入盆、任务降秩、分支问题还是目标接近可达边界。

任务：

1. 记录每轮控制量、真实末端误差、任务秩、奇异值、推进量、电流边界余量和平衡分类。
2. 对 pt12 进行多初值短跑，包括零电流冷启动、邻近成功点、反向遍历、确定性小扰动和历史最好状态。
3. 进行低成本经验可达性采样，寻找是否存在 `5 mm` 或 `10 mm` 内的候选控制量。
4. 若采样中存在近目标候选而外层失败，归因为优化器入盆失败；若多初值和采样均远离目标，再写为高度疑似可达边界。

验收标准：

1. pt12 不得只写“未收敛”。
2. 必须在入盆失败、任务降秩、分支跳变、弱平衡、疑似可达边界之间给出主因。
3. 若找到近目标候选，必须把候选作为下一轮外层初始化策略输入。

### P3：A2 三点风险封存

目标：不急于优化 A2 成功率，先明确 A2 的主要风险类型。

对象：

1. A2-pt05：成功点，复核分支连续性。
2. A2-pt17：弱平衡点，复核换初值或换分支后是否仍弱平衡。
3. A2-pt19：严重失败点，拆分分支不连续、弱响应和目标过远。

任务：

1. 对三个点做平衡质量、分支重放、回环误差和有限差分稳定性检查。
2. 对每个点输出风险等级：可小范围使用、弱平衡隔离、分支不连续、证据不足或疑似可达边界。
3. A2 三点未闭合前，不运行 A2 扩点实验。

验收标准：

1. A2-pt05 若保持成功，仍需说明适用条件和风险边界。
2. A2-pt17 若继续弱平衡，应被稳定隔离。
3. A2-pt19 必须完成主因拆分。

### P4：外层求解器稳定化

目标：把 P1--P3 的诊断结果转成可复用算法改动。

任务：

1. 增强停止原因记录，避免“早停或平台期”这种不可诊断标签成为最终结论。
2. 增加分阶段信赖域：入盆阶段允许较大物理步长，精修阶段收缩到灵敏度可信范围。
3. 回溯后必须基于实际裁剪步长重算预测下降。
4. 连续拒绝或有效步长接近零时，不应只增大阻尼；应触发重新线性化、换候选初值或返回入盆阶段。
5. 将经验微搜与生产灵敏度分离记录。

验收标准：

1. A1-pt01 不退化。
2. A1-pt13 得到闭合结论，优先争取进入 `5 mm`。
3. A1-pt12 得到闭合主因。
4. 所有新增策略都有开关和记录字段，不覆盖旧基线。

### P5：小规模回归与扩点门槛

2. pt13 成功或主因闭合。
3. pt12 主因闭合。
