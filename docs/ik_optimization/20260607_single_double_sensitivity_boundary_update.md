# 单点与两点磁控导管 IK 灵敏度边界更新

## 目的

本文汇总 P2c51 至 P2c56 的阶段性证据，说明当前单点与两点磁控导管在打靶式逆运动学灵敏度研究中的可信性边界。本文不作为算法完成报告，而是作为下一阶段模型修复和工程边界选择的依据。

## 判定口径

当前仍坚持“先物理可信，再谈灵敏度”的顺序。末端位置拟合很小，只说明零阶几何目标被命中；只有同时满足一阶最优性、条件数、接口连续、载荷传播和分支一致性后，局部灵敏度才具备发布基础。

本阶段继续沿用硬门禁：

- 一阶最优性残差原则上不大于 `1e-5`。
- 条件数小于 `1e7` 才进入正常灵敏度审计；`1e7-1e9` 仅谨慎诊断。
- 接口连续残差原则上不大于 `1e-3`。
- 接口力跳变相对刚性磁体段外力比例目标不大于 `1.5`；若大于 `2`，默认不可发布。

## 两点磁控导管结论

对应工况为 `n2_z_pair_rand12, alpha=0.10`，任务为三维末端位置。

P2c52 复现了 P2c50 的同源分支结果：末端位置误差约 `1.19e-7 m`，一阶最优性残差约 `1.31e-7`，说明该分支在数值优化意义上可以形成很好的驻点。但是条件数约 `1.17e8`，接口连续残差约 `1.96e-3`，接口力跳变比约 `4.37`，因此不能发布。

P2c51 与 P2c52 对比显示，直接使用 FK oracle 分段内力初值会进入不同分支，不能复现 P2c50 的优质一阶最优性。这说明两点工况存在明显分支依赖，不能把单一路径成功视为稳定可复现。

P2c53 排除了简单刚性磁体段外载传播符号错误。当前刚段传播公式的归一化接口跳变总量最小，优于“忽略刚段外载”和“刚段外载反号”两种对照。因此当前失败不应简单归因于公式正负号错误。

P2c55 的组合门禁进一步表明：该分支不仅相对刚段外力跳变过大，相对接口内力跳变也达到约 `1.0`。这说明相邻柔性段之间的力传递没有形成稳定闭合。内矩跳变很小，主要问题集中在接口力连续性和病态条件数。

因此，两点磁控当前不能发布三维末端位置灵敏度，也不建议进入扰动重求解灵敏度扫描。下一步应优先修复接口力连续约束尺度、刚性磁体段载荷传播表述或状态参数化，而不是继续追求末端误差。

## 单点磁控导管结论

对应工况为 `n1_tip_z_rand15, alpha=0.10`，任务为末端位置。

P2c48 显示，单点磁控的近似隐式末端位置响应具有二维有效子空间，奇异值约为 `[9.21e-4, 2.59e-4, 1.86e-12]`。这说明单点磁控不应强推完整三维末端位置灵敏度，更合理的目标是有效子空间灵敏度。

但是 P2c56 复核后，单点工况基线仍明显不可发布：一阶最优性残差约 `2.45`，条件数约 `4.50e9`，接口连续残差约 `6.64e-3`，最大相对刚段外力跳变约 `17.7`。这些指标远超发布门禁。

因此，单点磁控目前只能保留“二维有效子空间结构”作为模型诊断线索，不能发布有效子空间灵敏度，也不能接入外层 IK。

## 工程边界建议

当前阶段不建议将单点或两点打靶灵敏度接入外层 IK。原因不是末端拟合不足，而是物理闭合和局部分支可信性不足。

近期任务应收缩为：

1. 单点磁控：停止完整三维末端位置灵敏度目标，保留二维有效子空间作为诊断对象。
2. 两点磁控：停止电流幅值扫描，优先修复接口力连续性和条件数病态。
3. 任务层级：继续只推进 position-only；position + one axis 和 full pose 暂不作为成功目标。
4. 发布策略：任何扰动灵敏度扫描都必须在基线门禁通过后进行；当前 n1/n2 均未达到该条件。

## 下一步计划

下一轮应围绕“接口力连续性修复”开展，而不是继续扫电流、初值或扰动步长。可选方向包括：

1. 调整接口连续残差的物理尺度，使力连续项与末端位置项、边界项在数值上更相容。
2. 引入更明确的刚性磁体段载荷传播残差，避免相邻柔段内力块自由跳变。
3. 对显式分段内力状态做条件数改善，例如变量尺度重整、分块正则或低维力传递参数化。
4. 修复后先复测 n2，因为 n2 已能形成较好一阶驻点；再复测 n1 的二维有效子空间。
