# A1/A2 有监督逆运动学诊断审计后修正计划

## 一、文档目的

本文基于 A1/A2 单点磁化导管的 40 点正式实验、失败诊断、可达性采样、P0 状态闭环实验和本轮多智能体审查意见，给出下一阶段有监督逆运动学的修正路线。

本计划的核心目标不是继续解释失败现象，而是建立一条可执行、可审计、可回退的算法修正路径，使后续实验能明确区分以下四类问题：

1. 外层控制更新算法失效。
2. 局部灵敏度计算失真。
3. 平衡分支跳变或热启动路径依赖。
4. 目标点处于当前控制范围下的困难区域或疑似不可达区域。

本文适用边界为：无重力、A1/A2 单磁体导管、位置控制任务、`M_list=5`、FK 容差 `1e-5`、电流范围 `[-20,20] A`、推进范围 `[0.003001,0.203] m`、真实刚性远端位置误差阈值 `5 mm`。若后续加入重力、末端姿态约束、双磁体导管或改变网格与容差，必须重新执行本文的 P0.5 与 P1 门禁。

## 三、当前诊断结论的可信边界

### 3.1 可以确认的事实

A1 20 个目标点中有 7 个进入 `5 mm` 阈值，A2 20 个目标点中有 4 个进入 `5 mm` 阈值。大多数失败点的内层 FK 平衡状态为 `GOOD`，因此失败主要发生在外层控制量更新环节，而不是 FK 完全不能求解平衡。

40 点实验已经排除了若干前置错误：GPU 回退、单磁体配置错误、真实末端定义漂移和明显的 FK 容差错误都不是本轮主因。

P0 已经完成状态保存和重载闭环。六个代表点共 195 个状态快照可以从 `.npz` 文件重新提取真实末端和中心线，重载误差为零。这说明状态文件本身可追溯，后续可以以保存状态作为审计入口。

### 3.2 不能过度外推的结论

P0 只证明状态可重载，不证明控制量扰动后仍沿同一平衡分支演化。因此，P0 还不能直接支持“同分支灵敏度已经验证”的结论。

现有 D1 灵敏度审计只覆盖少数代表点。A1 中“推进量方向较可靠、电流方向病态”的观察主要来自个别样本；A2 中“整体灵敏度不可信”的判断也主要来自典型失败点。它们是强工作假设，不是导管级定论。

D4 可达性采样只新增了 15 个样本，其中每个未覆盖目标附近基本只有一次局部试探。该结果不能证明目标不可达，也不能充分排除工作空间与目标轨迹本身的限制。它只能用于证据分层。

“阻尼过大导致停滞”应视为失败表征，而不是独立根因。其上游原因可能是灵敏度方向错误、控制变量尺度失衡、边界参数化饱和、分支跳变或局部模型有效域过小。

### 3.3 必须修正的证据口径

后续所有审计必须区分四类证据：

- 保存状态重载：只证明状态文件自洽。
- 接受状态重放：只证明部分历史状态可复现。
- 完整历史重放：用于判断原运行路径能否复现。
- 扰动回环重放：用于判断控制量扰动后是否保持同一平衡分支。

只有同时满足真实末端、中心线形态、往返回环和 FK 平衡门禁，才能称为同分支审计样本。

## 四、总体修正路线

推荐主线为：

`P0.5 基线与分支门禁补证 -> P1 可信灵敏度基准 -> P2 外层受限优化器 -> P3 按需分支管理 -> P4 A1 正式回归 -> P5 A2 门禁回归 -> P6 残余困难点可达性验证`

该顺序的理由是：在灵敏度和分支门禁未明确前，直接调大迭代次数、改阻尼或扩展可达性采样都会混淆根因。A1 已表现出一定可控性，应优先建立可交付路径；A2 当前成功率更低，且代表点灵敏度问题更严重，必须先过灵敏度门禁再进入全量优化。

## 五、P0.5：基线复现与同分支门禁补证

### 5.1 目标

在 P0 的状态重载基础上，补齐两个证据缺口：

1. 新运行是否能复现原 40 点代表案例的终态误差和成功/失败分类。
2. 对控制量做小扰动后，FK 是否仍返回同一平衡分支。

### 5.2 任务

对 A1-pt01、A1-pt12、A1-pt13、A2-pt05、A2-pt17、A2-pt19 执行基线复现检查。带状态保存的新运行需要与原代表点比较真实末端误差、终止原因、成功/失败分类和最终控制量。

对每个代表点选择一个关键状态作为审计基准，优先选择历史最小真实末端误差状态，而不是机械地选择最终状态。若该点为成功点，则选择首次进入 `5 mm` 的接受状态。

对每个基准状态执行小扰动回环：从基准状态出发，控制量扰动到 `c+h` 和 `c-h`，再回到 `c`。回到 `c` 后，真实末端误差不超过 `0.25 mm`，中心线对应点最大误差不超过 `0.5 mm`，FK 平衡仍满足 `tol=1e-5`，才允许进入 P1 灵敏度误差统计。

### 5.3 输出

- `baseline_reproduction.csv`：记录新旧运行终态误差、成功分类和终止原因是否一致。
- `branch_roundtrip_gate.csv`：记录每个代表点、每个扰动方向、每个控制通道的回环误差。
- `provenance_manifest.jsonl`：记录 `run_id`、`target_id`、`eval_id`、重放方法、状态哈希、参数哈希和代码版本。
- 中文记录文档 `record.md`。

### 5.4 门禁

若新运行不能复现原代表点分类，应将其标记为“新运行证据”，不得用于解释旧失败案例。

若大多数代表点无法通过回环门禁，应暂停 P1 的灵敏度公式比较，优先进入 P3 的分支管理或检查 FK 热启动路径。

## 六、P1：可信灵敏度基准

### 6.1 数学定义

内层 FK 可写为非线性最小二乘问题：

```math
z^*(c)=\arg\min_z \frac{1}{2}\|E(z,c)\|_2^2,
```

其中 \(z\) 为导管状态变量，\(c=[I_1,\ldots,I_8,x]^T\) 为八个线圈电流和推进量组成的控制向量。

若当前平衡分支局部连续，则一阶驻点方程为：

```math
g(z,c)=J_z^T E=0,
\qquad J_z=\frac{\partial E}{\partial z}.
```

对应局部灵敏度为：

```math
\frac{\mathrm dz^*}{\mathrm dc}
=-\left(\frac{\partial g}{\partial z}\right)^\dagger
\frac{\partial g}{\partial c},
```

```math
\frac{\mathrm dp}{\mathrm dc}
=\frac{\partial p}{\partial c}
+\frac{\partial p}{\partial z}
\frac{\mathrm dz^*}{\mathrm dc}.
```

现有实现存在一个关键风险：它可能把 FK 求解器最后一次阻尼作为物理平衡分支导数的一部分。该阻尼反映的是数值求解过程，不是物理平衡方程本身。因此 P1 必须比较三种灵敏度：

- 旧求解器响应灵敏度：用于解释旧结果，不直接作为生产候选。
- 去除求解器阻尼的高斯牛顿灵敏度：作为优先在线候选。
- 精确驻点灵敏度：通过驻点方程自动微分获得，作为离线正确性基准。

### 6.2 审计范围

不得对 P0 的 195 个状态全部展开九通道多步长差分。第一轮只审六个代表点，每点一个关键状态。每个点先审推进量和响应最大的两个电流通道；只有通过初筛后再扩展到九个控制通道。

对电流扰动建议使用 `{0.25, 0.125, 0.0625} A`，对推进量扰动建议使用 `{0.5, 0.25, 0.125} mm`。所有差分样本必须先通过 P0.5 回环门禁。

### 6.3 强通道与弱通道

若有限差分导致的真实末端位移小于 `0.25 mm`，该通道视为弱通道。弱通道不使用相对误差作为主要判据，避免把接近零响应误判为灾难性错误。

强响应通道采用相对误差、方向夹角和相邻步长稳定性评价。弱响应通道采用绝对位移误差评价。

### 6.4 门禁

强响应通道误差中位数不超过 `5%`，90 分位不超过 `10%`，方向夹角 90 分位不超过 `15 deg`。

弱响应通道绝对位移误差 90 分位不超过 `0.10 mm`。

相邻两档差分步长的强响应结果差异 90 分位不超过 `5%`。

小步末端位移预测方向正确率不低于 `95%`。

若 A1 只在少数电流弱通道失败，可进入可靠子空间优化。若 A2 代表点强通道大面积失败，则不得进入 A2 外层全量优化。

## 七、P2：外层受限优化器修正

### 7.1 目标

在不改变 FK 物理模型、网格和容差的前提下，减少外层错误方向、阻尼膨胀和微步停滞。

### 7.2 任务

在尺度化控制空间中执行受限更新。尺度化控制空间是指把电流和推进量先转换到可比较的无量纲坐标，再计算步长和信赖域半径，避免电流与推进量因量纲差异导致更新方向失衡。

采用投影信赖域策略。信赖域是指限制每次控制量变化只在局部线性模型可信的邻域内发生；投影是指当候选步越过电流或推进量边界时，将其投回可行域。投影后必须重新计算实际执行步的预测下降量，不能沿用投影前的预测值。

采用真实末端误差优先的接受判据。正则项下降不能掩盖真实末端误差恶化。若预测下降和真实下降方向不一致，应先回溯缩步并重新评估；连续失败时重新计算灵敏度，而不是只增大阻尼并重复同一方向。

加入微步停滞门禁。若连续若干步的控制量变化和真实末端改善都低于数值阈值，则不能继续把极小代价下降当作有效收敛，应终止、重新线性化或切换初值。

### 7.3 门禁

六个代表点不应再出现无解释的阻尼无限增长。若阻尼超过 `1e5`、末五步末端改善均小于 `0.1 mm`，或同一方向回溯三次仍失败，应给出唯一终止原因。

旧成功点不得退化到 `5 mm` 之外。

A1 的 10 点小回归至少应有 7 点进入 `5 mm`，否则不得开启 A1 全量 20 点。

## 八、P3：按需分支管理与初始化

P3 不是默认步骤。只有当 P0.5 或 P2 证明残余失败主要来自分支跳变、冷热启动差异或顺序依赖时，才启用 P3。

候选初值包括：零电流冷启动、相邻成功点热启动、反向遍历热启动、确定性小电流扰动和当前最好状态的半步预测。每个目标最多使用有限数量候选，防止组合爆炸。

每个候选都必须记录被选择或被拒绝的原因。若增加候选后最小末端误差没有改善，应停止扩展候选池。

## 九、P4：A1 正式回归

A1 是近期交付优先对象。流程为：

1. 运行 A1 10 点小回归。
2. 若小回归通过，运行 A1 20 点首轮。
3. 若首轮达到最低线，再做反向或第二次正向复测。

最低通过线为：A1 至少 `15/20` 进入 `5 mm`，所有旧成功点保持成功，失败点均有可追溯原因。

阶段交付线为：A1 至少 `15/20` 进入 `5 mm`，末端误差中位数不超过 `3 mm`，95 分位不超过 `10 mm`，复测分类一致率不低于 `90%`。

若 A1 小回归失败，按错误类型回退：灵敏度错误回 P1，预测下降错误回 P2，分支跳变回 P3，目标长期未覆盖回 P6。

## 十、P5：A2 门禁回归

A2 不应直接套用 A1 修正后的外层优化器。进入 A2 全量实验前必须满足：

- 三个 A2 代表点中至少两个点的强响应通道通过 P1。
- 任何可审计代表点的全局灵敏度误差不得超过 `20%`。
- A2 6 点小回归相对旧基线有一致改善，旧成功点不退化。

A2 阶段目标采用分级评价：`8/20` 为算法有效性门槛，`12/20` 为阶段候选，`16/20` 为长期增强目标。若只能稳定控制低维子空间，应明确报告适用工作区和有效控制维数，不应伪装成全工作区全维可控。

## 十一、P6：残余困难点可达性验证

P6 只处理算法修正后仍失败的点。优先采用历史最佳控制附近的局部加密、多初值 FK 和双向延拓，而不是继续进行低效率全域随机采样。

新增采样必须使最近目标距离至少改善 `5 mm` 或提升一个证据等级，否则停止同类采样。

只有同时满足多初值稳定落入同一大误差分支、局部加密不再改善、控制量或工作空间接近边界、有效控制秩不足等条件时，才允许写作“高度疑似困难区域”。除非有解析物理上界证明，不得写作严格不可达。

## 十四、停止与转向规则

出现以下情况应立即停止当前阶段：

- GPU 回退、FK 容差改变或真实末端定义漂移。
- 分支门禁失败样本仍被纳入灵敏度误差统计。
- A1 小回归旧成功点退化。
- A2 未过 P1 代表点门禁却启动全量 20 点。
- 新增采样没有让最近目标距离改善 `5 mm`，却继续堆采样数量。
- 单点 P1 审计超过 120 次 FK 仍不能关闭一个算法分支。

转向原则如下：

- 回环门禁失败多：优先修分支管理和热启动路径。
- 灵敏度强通道失败多：优先修 `ik_diff.py` 的隐式灵敏度公式和正则策略。
- 灵敏度通过但外层仍停滞：优先修信赖域、回溯和微步停止逻辑。
- 多初值均稳定落入大误差解：进入 P6 可达性验证，不再盲目增加外层迭代。
