# A1/A2 有监督逆运动学灵敏度与分支修正计划

## 一、文档目的

本文基于当前 A1/A2 有监督逆运动学诊断、有限差分审计、多智能体复核和代码入口审查，给出下一阶段可执行的修正计划。本文的目标不是宣称当前算法已经可交付，而是把现有证据转化为明确的代码修改、实验门禁和回退路径。

固定适用条件如下：

- 无重力。
- 离散化网格 `M_list=5`。
- 前向运动学容差 `1e-5`。
- 单线圈电流范围 `[-20, 20] A`。
- 推进量范围 `[0.003001, 0.203] m`。
- 真实末端定义为最后刚段远端。
- 成功阈值为真实末端位置误差 `5 mm`。

若改变重力、网格、容差、磁体数量、末端定义或控制边界，本文结论不能直接外推，必须重新执行分支门禁和灵敏度审计。

## 四、主要根因判断

### 4.1 灵敏度病态已经大幅缓解

旧路径会把前向求解器中的数值阻尼混入灵敏度方程。该阻尼是数值稳定化参数，不是物理平衡方程本身，因此会污染控制量到真实末端位置的导数。

当前更可信的做法是直接在残差空间求解：

```math
J_z \frac{\partial z}{\partial c} = -J_c ,
```

其中 \(z\) 是导管平衡状态，\(c=[I_1,\ldots,I_8,x]^T\) 是八个线圈电流和推进量组成的控制量，\(J_z\) 是平衡残差对状态的雅可比矩阵，\(J_c\) 是平衡残差对控制量的导数。

该方法避免了法方程

```math
J_z^T J_z \Delta z = -J_z^T J_c \Delta c
```

导致的条件数平方放大。实验上，A1-pt12 在硬截断阈值 `1e-8` 下曾有 `15%` 到 `45%` 的幅值偏差；将阈值改为 `1e-9` 后，关键电流通道误差降至约 `1%` 以内。

因此，下一轮应锁定如下基线：

- 灵敏度模式：残差空间奇异值分解。
- 谱滤波方式：硬截断。
- 截断阈值：`1e-9`。

### 4.2 分支保持是当前首要卡点

同一控制量附近可能存在多个平衡分支。若扰动控制量后，前向求解落到另一条平衡分支，则有限差分不再代表同一局部解的导数。

当前分支风险主要表现为：

- A1-pt13：电流通道 3 和 4 在 `0.25/0.125/0.0625 A` 下全部回环失败。
- A2-pt05：电流通道 1 和 3 的 `0.25/0.125 A` 回环失败，仅 `0.0625 A` 有效。
- A2-pt17：电流通道 4 的 `0.25 A` 回环失败。
- A2-pt19：电流通道 5 的 `0.25 A` 回环失败。

这类样本不能被直接纳入单分支灵敏度统计，也不能用来判定灵敏度公式错误。下一步必须先判断这些失败是否能通过缩小步长、分段回环或更可靠的状态初始化解决。

### 4.3 A2 仍存在少量幅值偏差

A2-pt19 的电流通道 5 在 `0.125/0.0625 A` 下已经通过回环门禁，但误差仍约 `12%` 到 `13%`。这更像残余谱截断或局部非线性问题，不像符号级公式错误。

该问题应采用窄范围参数扫描处理，优先比较 `svd_rcond=1e-9` 与 `1e-10`，必要时再试局部软阻尼。不能因此重新回到旧的法方程路径。

### 4.4 正式实验入口存在工程追溯缺口

当前 `inverse_kinematics/ik_multisite_lm_opt.py` 已支持新灵敏度参数，但正式 A1/A2 圆周实验脚本 `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py` 的命令构造中尚未显式传入这些参数。因此，如果直接重跑正式实验，可能仍然使用旧默认灵敏度路径。

此外，`result.json` 与 `formal_point_summary.json` 中对灵敏度配置的记录不足，后续难以判断某个点到底使用了哪种灵敏度、截断阈值和谱滤波方式。

这属于修正前的硬门禁：在追溯字段补齐前，不应启动新的正式 20 点结论性实验。

## 五、修正原则

### 5.1 不改变前向物理模型

本轮修正不得改变前向运动学模型、网格、容差、磁体定义、真实末端定义和控制边界。所有改动应集中在：

- 灵敏度求解后端选择。
- 分支门禁和扰动审计。
- 外层控制更新算法。
- 日志、追溯和实验入口。

### 5.2 先可追溯，后谈性能和成功率

正式批处理必须记录每个点使用的灵敏度模式、截断阈值、谱滤波方式、推进量灵敏度方式、是否有限差分回退、分支状态文件和代码版本。否则成功率没有复现实验价值。

### 5.3 先同分支，再比较灵敏度

有限差分只在同一平衡分支内有意义。所有扰动样本必须先通过真实末端回环、中心线回环和 FK 平衡门禁，才能用于计算相对误差。

### 5.4 先 A1，后 A2

A1 的代表点已有较强证据，适合先形成可交付的小回归闭环。A2 仍要先补代表点门禁，不能直接进入全量 20 点正式实验。

## 六、分阶段修正计划

### P0：工程追溯与正式入口修复

目标：确保新灵敏度基线真正进入正式实验路径，并且每个结果都可追溯。

任务：

1. 在 `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py` 中增加灵敏度参数，并传入 `inverse_kinematics.ik_multisite_lm_opt`。
2. 默认配置可保持旧值，但下一轮正式修复实验必须显式传入：
   - `--sensitivity_mode residual_svd`
   - `--sensitivity_svd_rcond 1e-9`
   - `--sensitivity_spectral_filter hard`
3. 在 `result.json`、`history.json` 或 `run_config.json` 中记录完整灵敏度配置。
4. 在 `formal_point_summary.json` 和批次 `summary.csv` 中记录关键灵敏度配置。
5. 补充审计脚本输出字段，使审计 CSV 能记录截断阈值、谱滤波参数、推进量灵敏度方式和是否回退。

验收：

- 正式脚本日志中的命令行包含新灵敏度参数。
- 单点烟测的 `result.json` 能明确追溯灵敏度配置。
- 不改变 FK 模型、网格、容差和控制边界。

### P1：失败通道分支与步长判别

目标：解释当前不可审计样本是步长过大、分支跳变还是残余灵敏度偏差。

最小代表集合：

- A1-pt13：电流通道 3、4。
- A2-pt05：电流通道 1、3。
- A2-pt17：电流通道 4。
- A2-pt19：电流通道 5。

实验设计：

1. 使用 `residual_svd + hard + svd_rcond=1e-9`。
2. 电流扰动步长增加更小档位：`0.0625/0.03125/0.015625 A`。
3. 若单步回环失败，尝试分段回环，即把一次扰动拆成多次小扰动并逐段用上一段状态热启动。
4. 对 A2-pt19 通道 5 额外比较 `svd_rcond=1e-10`。
5. 每个样本记录真实末端回环误差、中心线最大回环误差、前向平衡残差、相对误差和方向角。

判定：

- 缩小步长后通过：主要问题是局部线性域太小，进入 P2 的信赖域修正。
- 分段回环通过、单步失败：主要问题是分支路径依赖，进入 P2/P3 的分支连续性门禁。
- 小步和分段均失败：该状态通道必须标记为分支不稳定，不纳入单分支灵敏度统计。
- 同分支有效但误差仍超过 `10%`：进入局部谱参数扫描，不扩大到全量点。

### P2：外层受限优化器修正

目标：在保持前向物理模型不变的前提下，减少错误方向、过大步长、边界投影失真和阻尼停滞。

任务：

1. 在物理控制空间中计算步长上限，电流和推进量分别尺度化。
2. 引入信赖域。信赖域是指只允许控制量在局部线性模型可信范围内变化。
3. 候选步投影到电流和推进量边界后，必须重新计算实际步长对应的预测下降量。
4. 接受判据以真实末端误差为一级指标，总代价为二级指标。不能让正则项下降掩盖末端误差恶化。
5. 若预测下降和真实下降不一致，应缩步并重新评估；连续失败后必须重新计算灵敏度。
6. 若连续多步真实末端改善小于 `0.1 mm`，应终止或切换初值，不能继续把微小数值下降当作收敛。

验收：

- 旧成功点不得退化到 `5 mm` 之外。
- A1 十点小回归至少 `7/10` 进入 `5 mm`。
- 每个失败点必须有唯一主因：灵敏度失败、分支失败、局部线性域过小、边界限制或疑似不可达。

### P3：按需分支管理

目标：只在 P1/P2 证明分支问题仍阻断收敛时启用，避免过早扩大计算量。

候选策略：

1. 零电流冷启动。
2. 相邻成功点热启动。
3. 反向圆周遍历热启动。
4. 确定性小电流扰动。
5. 当前最好状态的半步预测。

每个候选必须记录选择理由、拒绝理由和最终误差。若候选池不能改善最小真实末端误差，应停止扩展候选数量。

### P4：A1 小回归与正式回归

流程：

1. 先运行 A1 10 点小回归。
2. 若达到 `7/10`，进入 A1 20 点正式回归。
3. 若 A1 20 点至少 `15/20` 进入 `5 mm`，且旧成功点不退化，才可称为阶段性可交付候选。
4. 若未达到，应按失败主因回退到 P1、P2 或 P3，而不是直接调大迭代次数。

阶段性目标：

- A1 20 点至少 `15/20` 达到 `5 mm`。
- 真实末端误差中位数不超过 `3 mm`。
- 95 分位误差不超过 `10 mm`。
- 全部失败点均有可追溯主因。

### P5：A2 门禁补审与小回归

A2 不直接套用 A1 的交付结论。进入 A2 小回归前必须满足：

- 三个 A2 代表点中至少两个点的强响应通道通过 P1。
- A2 有效强响应样本 90 分位相对误差不超过 `10%`，或所有超过项均被明确标记为弱响应、分支跳变或局部线性域外。
- A2-pt19 通道 5 的稳定幅值偏差得到解释或修正。

A2 阶段目标采用分级评价：

- `8/20`：算法有效性门槛。
- `12/20`：阶段候选。
- `16/20`：长期增强目标。
