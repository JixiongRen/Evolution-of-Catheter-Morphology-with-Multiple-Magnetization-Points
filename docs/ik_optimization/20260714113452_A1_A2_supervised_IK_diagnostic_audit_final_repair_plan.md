# A1/A2 有监督逆运动学诊断审计修正计划

## 一、文档目的

本文档综合 2026 年 7 月 13 日至 7 月 14 日的 A1/A2 有监督逆运动学诊断、审计、复测和多智能体复核意见，给出下一阶段可执行的修正计划。

这里的有监督逆运动学指：外层调整线圈电流和推进量，内层调用正运动学求解器重新求解静力平衡，并以最后刚性段远端的真实末端位置作为主要监督量。本阶段仍只讨论末端位置控制，不讨论末端姿态控制。

本文档的核心结论是：

1. A1 不能再简单描述为“灵敏度整体错误”。在源状态绑定和回环门禁成立时，A1 代表点的局部灵敏度基本可用，但只在当前平衡分支的小邻域内有效。
2. A1 当前主矛盾是入盆失败、平衡分支选择、步长塌缩和外层阻尼策略失效。
3. A1-pt13 的历史近阈值结果不是冷启动算法成功，而是强分支依赖结果。
4. A2 当前不能进入扩点优化，只能先做弱平衡、分支不连续和局部灵敏度失真的风险封存。
5. 后续必须建立分账台账，区分冷启动成功、冷重启成功、邻点延拓成功、分支状态重放成功和流程验证成功。

## 二、多智能体审计摘要

本轮多智能体复核分为四个方向：

| 方向 | 主要结论 |
|---|---|
| 灵敏度与模型一致性 | A1 代表点的截断子空间局部灵敏度可用，但必须绑定控制量、平衡状态和真实末端定义；A2 尚未具备生产级灵敏度证据。 |
| 外层优化与停止条件 | `reject_stall` 只是报告层推断标签，真正核心停止原因多为有效物理步长塌缩；当前阻尼和回溯策略会在近阈值区域把步长压到数值阈值以下。 |
| 平衡分支与可达性 | A1-pt13 的 `5.778 mm` 历史结果必须归为分支依赖；D4 可达性采样只能提示存在性，不能证明冷启动可达。 |
| 工程交付与阶段计划 | 不应继续重复 P0/P1 审计；下一阶段应转入 A1 代表点闭合和 A2 三哨兵风险封存。 |

## 三、关键证据

### 3.1 A1-pt13 的历史近阈值结果不能算冷启动成功

`20260714092428` 中 A1-pt13 曾达到 `5.778 mm`，但该结果来自 `last_success_before_failed_point` 热启动，即使用了 A1-pt01 成功点的控制量作为初值。它不是标准冷启动结果。

分支重放实验进一步证明，同一组控制量在不加载历史平衡状态时，真实末端误差变为 `176.565 mm`；加载历史分支状态后才能恢复到 `5.778 mm`。

证据路径：

- `experiment_records_ik_optimize/20260714111704_a1_pt13_branch_dependency_replay/record.md`
- `DELIVER_TO_EXP/formal_experiments/20260714111355_A1_A2_5mm_supervised_IK_no_gravity/`
- `DELIVER_TO_EXP/formal_experiments/20260714111559_A1_A2_5mm_supervised_IK_no_gravity/`

结论：A1-pt13 的 `5.778 mm` 结果必须归为分支依赖和热启动流程验证，不得计入冷启动算法成功率。

### 3.2 邻点热启动有效但不足

使用 A1-pt01 成功点控制量作为 A1-pt13 初值，可以把误差从冷启动复测的 `49.203 mm` 降到 `7.436 mm`。但是该结果仍未进入 `5 mm`，且中心线哈希与历史 `5.778 mm` 分支不同。

证据路径：

- `experiment_records_ik_optimize/20260714112421_a1_pt13_neighbor_hotstart_probe/record.md`

结论：候选初值池有价值，但单个邻点热启动不足以证明稳定可达。后续应使用多候选、双向延拓和分支回环门禁。

### 3.3 核心停止原因是步长塌缩，不是简单迭代不足

A1-pt13 冷启动复测的报告层停止原因为 `reject_stall`，核心求解器停止原因为 `effective_step_below_tolerance`。最终最大电流步长约 `1.04e-7 A`，推进步长约 `2.72e-10 m`。

证据路径：

- `experiment_records_ik_optimize/20260714105540_ik_stop_reason_traceability/record.md`
- `experiment_records_ik_optimize/20260714111014_a1_pt13_stop_reason_rerun/record.md`

结论：单纯增加外层迭代次数不是优先方向。必须修改外层接受规则、阻尼恢复、回溯后预测重算、分支候选切换和停滞判定。

### 3.4 A1 代表点局部灵敏度可用，但不能外推

P1b 代表点审计显示，在严格健康门禁、源状态绑定和同分支回环成立时，A1-pt01、A1-pt12、A1-pt13 的局部灵敏度相对误差处于可接受范围。但 A1-pt12 和 A1-pt13 的基准状态仍远离目标。

证据路径：

- `experiment_records_ik_optimize/20260714070559_p1b_representative_sensitivity_audit/record.md`

结论：A1 的问题不再优先归因为导数公式整体错误，而应转向入盆策略、分支管理和外层稳定化。

### 3.5 A2 尚未具备扩点条件

P1b 审计显示：

- A2-pt05 可以成功，但存在多行分支回环失败。
- A2-pt17 被健康门禁拦截为弱平衡。
- A2-pt19 可统计样本少，且相对误差高分位过大。

证据路径：

- `experiment_records_ik_optimize/20260714070559_p1b_representative_sensitivity_audit/record.md`

结论：A2 不应跟随 A1 直接扩点。应先完成三哨兵点风险封存。

## 四、数学与物理解释

外层控制变量写为：

```text
c = [I_1, I_2, ..., I_8, x]^T
```

其中 `I_1` 到 `I_8` 是八个线圈电流，`x` 是推进量。平衡状态记为 `z`，静力平衡方程可写为：

```text
F(z, c) = 0
```

末端位置为：

```text
p = p(z, c)
```

若当前平衡分支不变，则局部线性化为：

```text
p(c + Δc) ≈ p(c) + J(c) Δc
```

其中 `J(c)` 是末端位置对控制变量的局部灵敏度。该灵敏度只能描述当前平衡分支附近的小扰动响应。若同一控制量从不同初值求解到不同平衡形态，则原来的 `J(c)` 没有跨分支预测意义。

因此，当前 IK 困难不是“有 FK 就能直接反推 IK”，而是受到三个因素共同限制：

1. 软体导管静力平衡存在多分支，同一控制量可能对应不同形态。
2. 末端位置对电流和推进量的响应高度病态，部分方向非常弱。
3. 外层阻尼最小二乘法在预测下降和真实下降不一致时容易持续增大阻尼，最终导致有效步长趋近于零。

外层信赖域应记录实际下降和预测下降的比值：

```text
ρ = 实际下降量 / 预测下降量
```

若 `ρ` 持续异常，说明局部模型已经不适合继续沿同一方向更新。此时应重新线性化、切换候选初值、缩小物理步长或回到入盆阶段，而不是继续单调增大阻尼。

## 五、成功口径重新定义

后续必须将所有 IK 结果分为以下类别：

| 类别 | 定义 | 是否可计入冷启动成功率 |
|---|---|---|
| 冷启动成功 | 未加载外部分支状态，初值为标准初始配置，最终真实末端误差不超过 `5 mm` | 是 |
| 冷重启成功 | 前一目标失败后，从标准或明确冷重启状态开始，最终成功 | 可单独统计 |
| 邻点延拓成功 | 使用相邻目标或上一个成功点控制量作为初值 | 否，应单独统计 |
| 分支状态重放成功 | 加载历史 `z_star` 或分支状态后成功 | 否，只能作为分支存在性证据 |
| 热启动流程验证 | 用于验证流程能否重放或延续 | 否 |
| 辅助阶段结果 | 入盆阶段或精修阶段中间结果 | 否 |

冷启动成功门禁：

1. 不加载外部分支状态。
2. `warm_start_source` 属于冷启动或冷重启类别。
3. `algorithm_statistics_included=true`。
4. 真实刚性末端误差 `err_true_mm <= 5`。
5. 结果、摘要、报告、图像和运行命令口径一致。

## 六、总体修正路线

### P0：证据台账与配置冻结

目标：防止继续混淆算法能力和流程验证。

任务：

1. 重算一份成功台账，至少分为冷启动、冷重启、邻点延拓、分支状态重放和流程验证。
2. 报告根因时只使用核心求解器的停止原因，不再把 `reject_stall` 当作根因。
3. 固定外层线性化模式、正则化参数、截断阈值、推进量列设置和门禁配置。若配置变化，必须标为版本对照，不能与旧结果直接比较。
4. 记录真实末端和柔性末端，但成功判据只使用最后刚性段远端。
5. 保存每个接受状态的控制量、平衡状态、中心线哈希、状态哈希、平衡分类、停止原因和是否进入算法统计。

验收标准：

1. 每个点只有一条最终判定行进入正式成功率统计。
2. 任意成功结果都能追溯其初值来源和分支来源。
3. 分支状态重放结果不会被写入冷启动成功率。

### P1：A1-pt13 分支候选池与回环门禁

目标：闭合 A1-pt13 的主因，优先证明它是否能在不加载历史分支状态的情况下稳定进入 `5 mm` 或至少稳定进入 `10 mm`。

任务：

1. 建立最小候选池：标准冷启动、pt01 前向候选、反向邻点候选、确定性小扰动候选、历史分支状态候选。
2. 历史分支状态候选只能作为诊断，不进入成功率。
3. 增加分支回环门禁：若中心线哈希或状态哈希重复出现，误差改善小于 `0.1 mm`，且有效步长跌破阈值，则标记为分支回环停滞。
4. 对进入 `5--10 mm` 的候选，触发小信赖域精修或经验微搜，但必须标注为分支局部补救。
5. 每个候选输出控制量、分支哈希、误差轨迹、电流轨迹、推进量轨迹和停止原因。

验收标准：

1. 若存在非分支状态候选进入 `5 mm`，再做 control-only 重放确认。
2. 若所有非分支状态候选只能进入 `5--10 mm`，主因归为分支选择与局部停滞混合问题。
3. 若只有历史分支状态候选可接近目标，主因归为强分支依赖。

### P2：A1-pt12 入盆失败与可控性归因

目标：将 A1-pt12 从“未收敛”转化为唯一主因结论。

任务：

1. 运行多初值短跑：标准冷启动、邻点候选、反向候选、确定性扰动候选、历史最好候选。
2. 记录每轮任务秩、主要奇异值、电流边界余量、推进量边界余量、真实末端误差和平衡分类。
3. 对局部响应较弱的方向进行低成本采样，判断是否存在 `10 mm` 内候选。
4. 若采样或候选池发现近目标点，归因为入盆失败；若多候选均稳定远离目标，再归为疑似可达边界或可控方向不足。

验收标准：

1. 不允许最终只写“未收敛”。
2. 必须在入盆失败、可控方向不足、分支跳变、弱平衡、疑似可达边界之间给出一个主因。
3. 若找到近目标候选，必须形成下一轮初始化策略。

### P3：外层求解器稳定化

目标：减少有效步长塌缩和错误早停。

任务：

1. 修改接受规则：近阈值区域不只看真实末端是否严格下降，还应结合非恶化容差、真实下降量、预测下降量和正则项变化。
2. 回溯和物理裁剪后，必须使用实际执行步长重新计算预测下降。
3. 连续拒绝后不再只单调增大阻尼，应触发重新线性化、阻尼重置、候选切换或回到入盆阶段。
4. 对有效步长塌缩记录来源：由阻尼导致、由物理边界导致、由通道门禁安全步长导致，还是由控制裁剪导致。
5. 保留原路径作为对照开关，避免一次性覆盖基线行为。

验收标准：

1. A1-pt01 不退化，仍进入 `5 mm`。
2. A1-pt13 不再以不可解释的步长塌缩结束；若失败，必须报告候选耗尽、分支回环或局部模型失效。
3. 所有新增策略均可关闭，并在结果中落盘开关状态。

### P4：A2 三哨兵风险封存

目标：不追求当前 A2 成功率，先给出可追溯风险标签。

对象：

1. A2-pt05：成功点，复核分支连续性和适用边界。
2. A2-pt17：弱平衡点，确认换初值后是否仍为弱平衡。
3. A2-pt19：严重失败点，拆分分支不连续、弱响应和目标过远。

任务：

1. 对三个点做 control-only 重放、分支状态重放和回环检查。
2. 对有效状态做有限差分审计，只作为验证器，不作为生产灵敏度来源。
3. 输出风险等级：有限使用、弱平衡隔离、分支不连续、证据不足或疑似可达边界。

验收标准：

1. A2-pt05 若继续成功，也必须说明它是否依赖邻点延拓。
2. A2-pt17 若仍为弱平衡，应稳定隔离。
3. A2-pt19 必须完成主因拆分。
4. 未完成三哨兵封存前，不运行 A2 扩点实验。

### P5：A1 小规模回归与扩点

目标：在代表点闭合后，逐步恢复 A1 交付线。

扩点顺序：

1. A1 三点：pt01、pt12、pt13。
2. A1 五点：加入两个邻近或历史失败代表点。
3. A1 十点：覆盖圆周上半圈和后半圈。
4. A1 二十点：正式交付候选。

扩点门槛：

1. pt01 不退化。
2. pt13 成功或主因闭合。
3. pt12 主因闭合。
4. 成功台账已分账，邻点延拓不混入冷启动成功率。

近期交付目标：

1. 冷启动成功率单独报告。
2. 邻点延拓成功率单独报告。
3. 若工程上允许连续轨迹执行，则可以把双向延拓稳定成功作为“轨迹连续控制可用性”证据，但不能写成独立点冷启动成功。

## 十、下一阶段建议

下一阶段不建议继续扩大全量点数，而应采用“少点、强证据、严分账”的方式：

1. 先做 A1-pt13 候选池和分支回环门禁。
2. 再做 A1-pt12 入盆失败归因。
3. 同步保护 A1-pt01。

5. 最后根据结果决定是否进入 A1 五点或十点回归。

该路线比直接扩点慢，但能避免继续把分支依赖和热启动流程验证误报为算法能力，更适合形成可交付、可解释的实验侧算法版本。
