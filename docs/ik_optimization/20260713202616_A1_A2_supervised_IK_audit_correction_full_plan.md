# A1/A2 有监督逆运动学诊断审计修正计划

日期：2026-07-13

## 一、背景与目标

本计划面向 A1/A2 单点磁化导管的有监督逆运动学。这里的有监督逆运动学是指：外层调节八个线圈电流和推进量，内层每一步调用前向运动学求静力平衡，并用前向运动学结果评价最后刚段远端的真实末端误差。

当前目标不是立即扩大到 20 点或 40 点正式实验，而是先把失败原因拆清楚，并形成可复现、可审计、可交付的修正路径。

## 二、证据来源

本计划综合以下结果形成：

- `experiment_records_ik_optimize/20260713194538_p1_failed_strong_channel_reaudit/`
- `experiment_records_ik_optimize/20260713190019_p2_a1_representative_outer_solver_compare/`
- `docs/ik_optimization/20260713193308_A1_A2_supervised_IK_diagnostic_audit_correction_plan.md`
- 三个独立审查智能体关于灵敏度、外层优化器和计划完整性的审查意见。

需要强调：`20260713135237` 与 `20260713141233` 两组所谓“正式 20 点实验”实际只请求并运行了 3 个代表点。因此它们只能作为代表点子集，不能作为全圆周成功率基线。

## 三、当前可靠结论

### 3.1 灵敏度结论必须收窄

现有证据足以说明：本轮被复审的失败强电流通道尚不能稳定作为生产灵敏度依据。现有证据不足以说明：A1/A2 全部灵敏度路径都普遍不可信。

A1-pt13 的电流 3、4 在复审中出现有效行不足和回环不稳，说明有限差分扰动已经跨越平衡分支，不能被解释为同一平衡分支上的导数。

A2-pt05、A2-pt17、A2-pt19 的若干电流通道回环通过，但位移幅值多低于 0.25 mm 强响应门限，相对误差会被小分母放大。因此这些通道应先归为弱响应或近弱响应，而不是直接归为公式错误。

推进量通道整体更稳定，A1-pt13 约 1% 到 2%，A2-pt19 约 2% 到 4%，但多数样本也接近弱响应区，生产中应降低权重。

### 3.2 灵敏度求解路径

`solver_response` 和 `stationarity_exact` 与有限差分明显失配，只保留为诊断路径。

`residual_svd` 和 `gn_svd` 在本轮数值上几乎一致，均明显优于前两种路径。现阶段可继续以 `residual_svd` 为生产候选，但不能宣称它显著优于 `gn_svd`。

这里的残差谱分解是指直接对平衡残差关于状态变量的线性化矩阵做奇异值截断，避免把矩阵病态程度在法方程中平方放大：

```math
J_z \Delta z \approx -J_c \Delta c
```

其中 `z` 是静力平衡状态，`c` 是控制量。

### 3.3 外层优化器结论

P2 受限外层策略不能整包推广。A1 代表点对照显示：

- pt01：普通外层 3.639 mm，P2 为 3.614 mm，均成功。
- pt12：普通外层 51.713 mm，P2 为 51.271 mm，改善很小但耗时大幅增加。
- pt13：普通外层 72.626 mm，P2 为 5.777 mm，显著改善但仍未进入 5 mm。

因此 P2 的价值是有限接入分支风险点，而不是作为全局默认策略。

### 3.4 计划完整性风险

当前证据链还有四类硬缺口：

- 代表点子集被报告为正式 20 点实验，口径必须修正。
- 正式代表点实验与后续复审处在不同代码提交，存在跨版本归因污染。
- 热启动路径依赖明显，冷启动和热启动必须并行报告。
- 目标可能不可达或只能在另一平衡分支可达，不能把所有失败都归咎于灵敏度或回溯。

## 四、修正路线

### P-1：证据口径与同版本复现门禁

目标：消除后续论文和交付中的证据污染。

任务：

- 将既有 3 点实验在后续文档中统一标记为代表性子集，不再称为完整 20 点正式实验。
- 对关键失败点保留同一代码提交下的复现实验和修正提交下的复审实验。
- 每份报告必须记录代码提交、目标点数量、请求目标点列表、运行目标点列表和是否全量执行。
- 不再用代表点子集估计全圆周成功率。

验收：任意实验结论都能追溯到代码提交、目标点集合和运行配置。

### P0：审计字段与真实末端一致性修复

目标：先修正数据记录和判据，避免继续产生不可解释统计。

任务：

- 在审计表中增加 `used_in_stats`、`branch_consistent`、`weak_gate_triggered`、`displacement_gate_mm`、`selector` 和 `step_family`。
- 明确区分“计算成功”和“可用于灵敏度统计”。`ok=True` 不能再等价于灵敏度可信。
- 图、表、停止判据、成功判据和 CSV 必须使用同一个真实末端定义。
- 同时记录柔性段末端，但只能作为兼容观测点。
- 若真实末端和柔性段末端会导致成功标签翻转，则该批次必须标记为末端口径敏感，不允许进入正式统计。

验收：审计表可自动给出每一行是否进入统计，以及未进入统计的原因。

### P1：失败通道完整复审

目标：把分支不稳、弱响应、线性窗口过窄和谱截断失配分开。

任务：

- 补全 `last_accept` 与 `best_accept` 双状态选择器。
- 复审 A1-pt13 电流 3、4，A2-pt05 电流 1、3，A2-pt17 电流 4，A2-pt19 电流 5。
- 使用更小扰动和分段回环，至少覆盖三档电流步长和两档推进量步长。
- 对低于强响应门限的通道，不使用相对误差单独判定失败，而改用绝对误差和方向一致性。
- 对同分支且强响应仍超 10% 的通道，进入奇异值截断、尺度归一和磁场偏导复核。

验收：每个通道必须归入分支不稳、弱响应、线性窗口过窄、谱截断失配、可有限使用或可生产使用之一。

### P1.5：分支轨迹与可达性审计

目标：避免把不可达目标或跨分支问题误判为优化器失败。

任务：

- 为每个接受状态记录分支签名，包括真实末端、若干轴线采样点、主要弯曲方向和平衡残差。
- 检查外层迭代和跨点热启动是否发生分支跳变。
- 对失败点同时运行冷启动、多候选热启动和反向圆周遍历。
- 建立小规模经验可达性采样，判断目标是否被当前电流和推进范围覆盖。

验收：每个失败点至少区分为算法未找到、热启动误导、跨分支、疑似不可达或证据不足。

### P2：外层优化器拆包与分级策略

目标：保留 pt13 的改善，同时避免 pt12 一类点耗时暴涨。

任务：

- 将可靠子空间、真实末端优先接受、回溯、推进耦合项开关拆成独立开关。
- 修正推进耦合项开关语义，判据应基于候选步长，而不是当前状态与自身的差。
- 接受准则改为分层规则：先拒绝坏平衡，再优先接受真实末端变好；若真实末端几乎不变，则允许总代价下降且预测可信的候选通过。
- 连续拒绝后不再沿同一方向反复缩步，而是触发重线性化、冷启动或多候选热启动。
- 步长上限不再写死为 5 A 和 20 mm，应由 P1 的安全线性窗口和点位风险决定。

验收：A1 的 pt01 保持成功，pt13 进入或接近 5 mm，pt12 不允许出现显著耗时增加且误差无改善。

### P3：小规模回归到正式扩展

目标：逐步恢复工程交付能力。

任务：

- 先运行 A1 三点同预算对照：pt01、pt12、pt13。
- 通过后运行 A1 五点：pt01、pt08、pt12、pt13、pt17。
- 再运行 A1 十点和 A1 二十点。
- A2 只有在 P1 通道复审通过后进入五点回归。
- 每组回归必须双轨报告冷启动与热启动结果。
- 图像必须正确显示中文，并包含最终姿态、目标圆环、误差迭代、电流和推进量演化。

验收：成功率、失败根因、耗时和分支稳定性均可追溯；失败点不得只写未收敛。

## 五、准入与停止规则

进入下一阶段必须满足：

- 没有 CPU 回退。
- 真实末端定义一致。
- 代表点、全量点和运行点数量口径一致。
- 弱响应样本不使用相对误差单独判定灵敏度失败。
- 回环失败样本不进入同分支灵敏度统计。
- 冷启动和热启动结果均被报告。

停止并回退的条件：

- 新策略使已成功点失去 5 mm 收敛。
- 新策略使代表点平均耗时增加超过 50%，且误差没有实质改善。
- 审计字段无法说明某行数据为何进入或退出统计。
- 发现真实末端和柔性段末端混用。
- 发现代表点子集被误写为全量实验。

## 六、下一步优先级

第一优先级是 P-1 和 P0，因为它们决定证据是否可信。

第二优先级是补全 P1，尤其是 `best_accept` 分支和弱响应门限字段。

第三优先级是 P1.5，将失败点区分为分支问题、初值问题、可达性问题和局部线性化问题。

第四优先级才是 P2 外层优化器拆包修正。

完成上述步骤后，再进入 A1 小规模回归；A2 暂不承诺全量成功率，只做通道复审和风险归因。

## 七、总判断

当前 IK 不是完全不可用，而是局部可用、证据链尚不稳定。A1 已经存在成功点和可改善点；A2 的部分通道方向可用，但弱响应和口径问题较重。后续必须先建立可靠审计和分支管理，再谈正式交付成功率。
