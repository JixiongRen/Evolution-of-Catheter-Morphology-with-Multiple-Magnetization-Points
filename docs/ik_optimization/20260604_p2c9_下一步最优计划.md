# P2c9 证据基础上的下一步最优计划

## 1. 计划目标

在现有证据下，下一步不宜继续做大范围参数扫描，而应围绕 `n3_mixed_base_i4 -> n3_mixed_rand20` 路径上 `alpha=0.2 -> 0.4` 的可线性化断裂点，先完成局部结构诊断，再决定进入“刚性磁体段载荷到末端位姿传播修复”或“硬连续多段打靶”实现分支。该路线兼顾两点：

- 实验上，优先解释断裂机制，而不是重复证明终点难解。
- 工程上，优先做最小闭环原型，而不是同时展开多条高成本实现线。

## 3. 术语约定

- **任务敏感度**：线圈电流发生小变化时，导管末端位置和末端姿态的一阶变化关系。
- **一阶最优性残差**：目标函数对打靶状态变量的一阶导数未接近零的程度。该量过大时，即使末端位姿误差较小，也不能认为当前解适合求敏感度。
- **可线性化性**：当前解附近是否可以用一阶近似描述“电流变化—状态变化—末端位姿变化”的关系。
- **硬连续多段打靶**：将相邻段之间的内力和内矩连续性作为严格等式约束处理，而不是仅作为罚项加入目标函数。
- **一阶约束最优性条件**：约束优化问题中用于描述可行解和驻值点的必要条件；本文仅在需要时保留英文来源 Karush-Kuhn-Tucker 条件。

## 4. 路线比较

### 4.1 路线 A：继续终点大范围扫描

- 内容：继续对 `n3_mixed_rand20` 终点做 `continuity_mu / reg_mu / init / max_iter` 组合扫描。
- 优点：实现成本最低。
- 缺点：P2c9h 已证明该路线只会重复得到“残差下降而平稳性恶化”的低收益结果。
- 结论：不推荐。

### 4.2 路线 B：直接把稳定工况接入更大规模外层验证

- 内容：只在稳定工况上扩大影子回放验证或外层下降实验。
- 优点：短期最容易出正结果。
- 缺点：无法解释 hard case 断裂来源，且会推迟主线纠偏。
- 适用范围：仅适合作为后续回归验证，不应作为当前主任务。

### 4.3 路线 C：断裂点局部结构诊断后再分叉实现

- 内容：围绕 `alpha=0.2 -> 0.4` 做细网格 continuation、分支跟踪、残差块归因与耦合审计。
- 优点：最符合现有证据链，可最低成本决定后续应修模型还是修约束形式。
- 缺点：短期不会直接得到 production 结果。
- 结论：推荐，作为下一步最优路线。

### 4.4 路线 D：立即进入硬连续多段打靶与一阶约束最优性条件原型

- 内容：直接实现硬约束问题形式，并在困难工况上重跑全部门禁。
- 优点：若判断正确，可能一步跨过软连续性瓶颈。
- 缺点：工程量大，且若真正根因是刚段耦合缺失，则会先付出高成本再失败。
- 适用范围：仅在局部诊断显示“连续性残差与终端残差冲突占主导”时启用。

## 5. 多智能体讨论结论汇总

### 5.1 物理建模视角

困难工况中最可疑的不是求解器迭代次数，而是“刚性磁体段总载荷近端集中等效”和“段间连续性软罚项”共同导致的物理自洽性不足。具体表现为：末端位姿仍可近似拟合，但内部力学平衡关系不再能形成稳定的一阶驻点。

后续应优先验证两点：

1. 刚性磁体段的磁力和磁矩是否过度简化为近端总载荷，导致段内力矩分布被低估。
2. 相邻段之间的内力、内矩连续性是否被罚项吸收，而没有严格满足守恒关系。

### 5.2 数值优化视角

困难工况不能继续强行求敏感度。隐式求导要求当前点至少接近稳定驻点；若一阶最优性残差已经失控，求得的敏感度会被正则项、连续性罚项或错误分支主导。

下一步必须将总残差分解为四类：

1. 末端任务残差：末端位置和末端姿态误差。
2. 末端边界残差：末端力和末端力矩平衡误差。
3. 段间连续残差：相邻段内力和内矩连续误差。
4. 分支保持残差：用于维持参考解分支的正则项误差。

不仅要统计各类残差大小，还要统计它们对一阶最优性残差的贡献。如果“段间连续残差”和“分支保持残差”主导一阶最优性残差，则说明当前解主要由数值维持项支撑，不能作为物理敏感度。

### 5.3 实验路线视角

下一轮不应继续在 `alpha=1.0` 终点做普通扫描，而应收缩到 `alpha=0.2 -> 0.4` 的断裂区间。先精确定位断裂阈值，再进行残差分块归因。只有归因明确后，才选择一个实现分支，避免同时展开多个高成本方向。

## 6. 推荐阶段计划

### 阶段 0：证据固化与禁扫清单

- 目标：把“稳定工况可用、困难工况在 `alpha=0.4` 断裂、普通扫描低收益”固化为统一门禁。
- 任务：
  - 汇总 P2c9f/g/i/j/h/e 的成功与失败判据。
  - 明确下一轮唯一主判据：残差、边界残差、平稳性三者同时达标。
  - 写入禁扫清单，避免重复实验。
- 成功判据：
  - 形成统一门禁说明。
  - 后续实验脚本不再只以终端残差判成功。
- 失败判据：
  - 门禁定义仍依赖人工解释。
  - 不同脚本对“成功”含义不一致。

  - 每个 `alpha` 保留“当前延续分支、竞争分支、冷启动参考分支”三类记录，不允许延续初值覆盖分支信息。

## 7. 禁止重复的低收益扫描

- 不再对 `n3_mixed_rand20@alpha=1.0` 重复做大网格“段间连续权重、正则权重、最大迭代次数、初值”扫描。
- 不再把“终端残差足够小”当作可发布灵敏度的充分条件。
- 不再回到高斯-牛顿近似链式灵敏度主线。
- 不在断裂机制未明确前，重跑全四 case 全方向大审计。
- 不在未通过稳定工况回归门禁前，接入正式双层逆运动学流程。

## 8. 工程实施原则

- 一次只推进一条主实现分支；阶段 2 结束前，不并行展开“模型修复”和“硬约束重构”。
- 每轮实验目录必须包含 `record.md`，并直接引用脚本、参数、核心指标与失败分类。
- 每轮大实验结束后，按仓库约定提交本地 `ik_optimize` 分支；不要推送远程。
- 若阶段 2 仍不能给出主导归因，则停止扩展实现，先补诊断工具，不继续试错式扫描。

## 9. 推荐结论

当前最优计划不是“继续扫终点”，也不是“立即全面重写 formulation”，而是：

1. 以 `alpha=0.2 -> 0.4` 为唯一主战场，完成断裂阈值精定位。
2. 以残差块归因和刚段耦合审计决定后续只走一个实现分支。
3. 先做局部最小原型，后做稳定工况回归，再决定是否扩展到 `alpha=1.0` 与全部工况。

该路线的有效边界是：若阶段 2 已明确显示断裂根因单一，则本计划最优；若阶段 2 仍显示多重耦合且无法归因，则应先补诊断基础设施，再重定路线。
