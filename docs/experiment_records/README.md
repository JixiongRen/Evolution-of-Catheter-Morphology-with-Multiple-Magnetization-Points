# Experiment Records

This directory stores one record for each large experiment round.

## Naming

Use this file name format:

`{YYYYMMDD}_exp_{exp_name}_record.md`

Example:

`20260518_exp_single_layer_ik_stage_tuning_record.md`

## Required Sections

Each record must include at least:

1. Experiment Objective
2. Experiment Plan
3. Execution Log
4. Results
5. Data Analysis
6. Conclusion
7. Next Step Plan

## Usage Notes

- Create one record per large experiment round.
- Update the record during execution instead of writing it only at the end.
- Reference output directories, scripts, parameters, and key metrics directly.
- Finalize the record before the local `dev` branch commit for that round.
