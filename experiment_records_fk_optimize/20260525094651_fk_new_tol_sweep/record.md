# 新 FK 不同容差求解对比实验记录

## 实验目的

在同一组固定物理参数下，使用新 FK 分别运行 `tol=1e-5`、`1e-6`、`1e-7`、`1e-4`，观察不同外部容差对最终姿态、收敛过程、迭代次数和耗时的影响。

## 实验方案

固定物理配置与用户给出的 FK 命令一致：

- `flex_lengths=0.03,0.03`
- `rigid_lengths=0.003,0.003,0.003`
- `L_protrude=0.11`
- `M_list=5,5,5`
- 开启重力和磁场
- `coil_currents=0,0,0,0,0,50,0,0`
- `m_body_list=0,0,-0.005301; 0,0,0.005301; 0.005301,0,0`
- `p0=0,0,0`
- `Q0=0.70710678,0,0.70710678,0`
- `axis_body=0,0,1`

执行方式：

- 使用 `forward_kinematics_optimized` 的新 FK 求解器。
- 每组从相同初始猜测开始，不使用上一组容差的热启动结果。
- 使用 `max_iter=100000`、`lm_damping=1e-1`、`jac_method=fwd`。
- 每 50 个 accepted step 记录一次中心线快照。
- 生成一张最终姿态叠加图和四张逐组收敛过程图。

## 数据分析

`tol=1e-4` 明显偏松。它比 `tol=1e-7` 的最大逐点误差达到 `18.24 mm`，约为 `L_ref=0.11 m` 的 `16.58%`，终态形态不可视为同一精度层级。

`tol=1e-5` 与更严格结果相比已有可见漂移。相对 `tol=1e-7` 的最大逐点误差为 `2.06 mm`，约 `1.87% L_ref`。如果只要求大致姿态，可能可接受；如果作为 FK golden baseline，则偏宽。

`tol=1e-6` 与 `tol=1e-7` 很接近。最大逐点误差约 `0.186 mm`，相对 `L_ref` 约 `0.17%`，在当前数值模型下可视为较稳定的姿态结果。

`tol=1e-7` 未严格收敛，停止原因为 `tiny_step`，最终 `||E||=1.188e-7`，距离目标容差很近但没有低于 `1e-7`。这说明继续单纯压低外部容差会触及当前 LM 步长下限或数值停滞，不一定能稳定换来显著更好的几何结果。

## 实验结论

在当前新 FK 直接求解路径下，`tol=1e-6` 是本组实验里较合理的精度折中点：相对 `tol=1e-7` 的几何差异很小，同时能够严格收敛。

`tol=1e-5` 能收敛，但终态相对更严格解存在约 `2 mm` 级别漂移。`tol=1e-4` 会导致明显姿态偏差，不建议作为需要可信 FK 形态的设置。

如果后续需要把 `tol=1e-7` 作为硬门限，需要进一步处理 `tiny_step` 停止条件、变量尺度或 LM 步长策略，否则当前默认求解参数下不能保证严格达到该容差。

## 下一步计划

后续若继续做 FK 正确性基线，建议优先采用 `tol=1e-6` 作为严格但仍稳定的参考配置；若做快速筛选，可以保留 `tol=1e-5`，但需要记录其相对严格解的几何偏差。
