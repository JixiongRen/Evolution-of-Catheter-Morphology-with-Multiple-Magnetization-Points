# 导管配置说明

本目录中的 `catheter_physical_configs.yaml` 是后续实验交付用的导管物理配置库。它描述的是导管真实结构，而不是某一次求解任务。

## 核心约定

- `A1` 和 `A2` 是真实单点磁化导管，配置中只有一个磁体段。
- `B1`、`B2` 和 `B3` 是真实两点磁化导管，配置中只有两个磁体段。
- 不允许用“多放一个磁体段但把磁矩设为零”的方式模拟少磁体导管。
- `magnetic_moment_body_A_m2` 是局部坐标系下的磁偶极矩，单位为 `A*m^2`。
- 当前求解器数组使用近端到远端顺序；用户描述结构时常用远端到近端顺序，配置中已经分别标注。

## 长度约定

单点磁化导管：

```text
近端可控柔性段 -> 远端磁体段
```

两点磁化导管：

```text
近端可控柔性段 2 -> 近端磁体段 2 -> 固定柔性段 1 -> 远端磁体段 1
```

其中最近端柔性段长度由插入深度 `L_protrude` 决定，不在物理配置中强行固定，只给出最大长度 `1 m` 和求解器允许范围。

## 磁矩数值

默认使用 N52 标称剩磁 `Br=1.45 T`，结合直径 `1.5 mm`、长度 `3 mm` 的圆柱磁体几何推导得到：

```text
磁偶极矩约为 0.0061171875 A*m^2
```

历史实验中常用的 `0.005301 A*m^2` 已在配置中作为兼容参考记录，但不作为本交付配置的默认物理真值。
