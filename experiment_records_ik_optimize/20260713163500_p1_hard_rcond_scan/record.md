# P1 残差空间硬截断阈值扫描记录

## 一、实验目的

本轮扫描硬截断阈值，验证 A1-pt12 的电流灵敏度幅值偏差是否由奇异值截断阈值不合适导致。

## 二、实验设置

- 代表点：A1-pt01、A1-pt12。
- 电流通道：0、4。
- 扰动步长：`0.25 A`。
- 灵敏度模式：残差雅可比奇异值分解。
- 谱滤波：硬截断。
- 阈值配置：`svd_rcond=1e-6`、`1e-9`、`1e-10`。

完整命令见 `commands.sh`。

## 三、结果

### 3.1 `svd_rcond=1e-6`

该阈值过大，几乎抹掉电流响应：

- 四个样本相对误差均约为 `100%`。
- 幅值比约为 `0.001`。

该配置不可用。

### 3.2 `svd_rcond=1e-9`

该阈值同时保持 pt01 稳定并修复 pt12：

- pt01 通道 0：相对误差约 `0.40%`。
- pt01 通道 4：相对误差约 `0.82%`。
- pt12 通道 0：相对误差约 `0.97%`。
- pt12 通道 4：相对误差约 `0.16%`。

四个样本均通过同分支回环门禁。

### 3.3 `svd_rcond=1e-10`

该阈值也表现良好：

- pt01 通道 0：相对误差约 `0.47%`。
- pt01 通道 4：相对误差约 `0.88%`。
- pt12 通道 0：相对误差约 `0.10%`。
- pt12 通道 4：相对误差约 `1.24%`。

## 四、结论

A1-pt12 的主要问题不是灵敏度公式方向错误，而是硬截断阈值过高。将 `svd_rcond` 从 `1e-8` 下调到 `1e-9` 或 `1e-10` 后，pt12 的两个关键电流通道均进入 P1 门禁范围。

当前最优候选是：

- `sensitivity_mode=residual_svd`。
- `spectral_filter=hard`。
- `svd_rcond=1e-9`。

该结论仍只覆盖 A1-pt01 和 A1-pt12。A1-pt13 的问题仍属于分支回环不稳定，不能用本轮结果外推。
