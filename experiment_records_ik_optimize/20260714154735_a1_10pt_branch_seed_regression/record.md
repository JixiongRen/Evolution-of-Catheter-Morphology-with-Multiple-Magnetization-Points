# A1十点候选分支小回归记录

## 一、实验目的

本轮实验检验 A1 候选分支登记表能否从单点烟测扩展到多目标小回归，并判断当前流程是否具备进入 A1 20 点正式回归的条件。

本轮不是最终交付实验。它用于回答两个问题：

1. 已登记的候选分支能否在多点流程中自动生效。
2. 对未登记分支的失败点，当前外层优化器是否已经足够稳定。

## 二、实验设置

- 导管配置：A1，单点轴向磁化。
- 目标点：`0,1,2,3,7,9,12,13,16,17`。
- 重力：关闭。
- 离散化：`M_list=5`。
- FK 容差：`1e-5`。
- 真实末端误差阈值：`5 mm`。
- 电流边界：`[-20, 20] A`。
- 推进边界：`[0.003001, 0.203] m`。
- 单点超时：`1800 s`。
- 候选分支登记表：`experiment_records_ik_optimize/20260714154000_a1_branch_seed_registry/a1_branch_seed_registry.csv`。

## 四、结论

1. 候选分支登记表已经在多点流程中生效。`pt_01` 和 `pt_13` 均能自动加载对应历史分支，并进入 `5 mm` 阈值。
2. 当前流程仍不能直接进入 A1 20 点正式交付回归。`pt_00、pt_03、pt_07、pt_12` 仍表现为大误差、长耗时或无有效结果。
3. 当前 A1 的核心瓶颈仍是分支选择和候选初值覆盖不足，而不是单纯登记表加载问题。
4. `pt_16` 虽进入 `5 mm`，但 FK质量为 `WEAK`，不能与 `GOOD` 收敛点等价统计。

## 五、下一步

1. 不建议立即运行 A1 20 点正式回归。当前小回归未达到进入正式回归的证据门槛。
2. 下一步应扩展候选分支池来源，包括反向遍历、邻域成功点、多确定性扰动和历史近解分支筛查。
3. 对 `pt_03、pt_07、pt_12` 优先做分支诊断，判断它们是否存在可重放近解分支；若存在，应纳入登记表；若不存在，再回到外层步长和灵敏度审计。
4. `pt_00` 的误差极大，应单独评估目标可达性和初始推进范围，而不是继续盲目增加迭代次数。
