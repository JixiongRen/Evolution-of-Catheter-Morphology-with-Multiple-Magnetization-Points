# P2c31 随机强电流三磁体扰动半径边界加密扫描

## 实验目的

P2c30 表明 `n3_mixed_rand20, alpha=0.4` 在 `eps<=0.01` 时可获得可发布任务敏感度，而 `eps=0.02` 因轴线分支漂移超过门限被判定为诊断样本。本轮实验在 `0.01` 到 `0.02` 之间加密采样，定位可发布灵敏度向分支漂移失效转变的临界区间。

## 实验方案

固定工况如下：

```text
case = n3_mixed_rand20
alpha = 0.4
eps = 0.0125, 0.015, 0.0175, 0.02
baseline = direct_saved + trf_strict_restart
```

所有扰动点均采用扰动后重新求解，而不是固定状态差分。判定指标包括一阶最优性残差、局部线性化误差、刚段载荷传播比例和轴线分支漂移。

## 判定标准

- 基线解必须通过静态平衡门限。
- 正负扰动后的解必须保持小的一阶最优性残差。
- 局部线性化误差必须小于 `0.05`。
- 轴线分支漂移必须小于 `1e-3 m`。

## 实验结果

本轮实验总墙钟时间为 `79.72 s`。基线解仍通过静态平衡门限，关键指标如下：

| 指标 | 数值 |
|---|---:|
| 末端位置误差 | `6.66e-7 m` |
| 一阶最优性残差 | `1.86e-8` |
| 界面边界残差 | `6.73e-3` |
| 雅可比矩阵条件数 | `1.73e6` |
| 最大冗余内力比例 | `0.069` |
| 基线总函数评估次数 | `243` |

扰动半径加密扫描结果如下：

| 扰动幅值 | 是否可发布 | 灵敏度模长 `m/alpha` | 最大线性化误差 | 最大一阶最优性残差 | 最大分支漂移 |
|---:|---|---:|---:|---:|---:|
| `0.0125` | 否 | `3.09e-5` | `5.32e-6` | `2.81e-7` | `1.57e-3 m` |
| `0.0150` | 否 | `2.86e-5` | `6.13e-6` | `2.03e-7` | `1.45e-3 m` |
| `0.0175` | 否 | `1.73e-5` | `8.53e-6` | `6.28e-7` | `2.58e-3 m` |
| `0.0200` | 否 | `2.72e-5` | `8.15e-6` | `7.10e-8` | `1.26e-3 m` |

四个扰动幅值均未通过发布门限。失败事件全部记录于 `failure_events.jsonl`。本轮同时合并 P2c30 与 P2c31 结果，生成 `combined_p2c30_p2c31_boundary_summary.csv` 和 `combined_p2c30_p2c31_boundary.png`。

## 数据分析

P2c30 已证明 `eps=0.005` 与 `eps=0.01` 可发布，而 P2c31 显示 `eps=0.0125` 已经失败。因此该工况在当前判据下的可发布扰动半径上界位于：

```text
0.01 < eps_critical < 0.0125
```

失效主因是轴线分支漂移，而不是一阶最优性退化或局部线性化误差超限。所有加密样本的一阶最优性残差均保持在 `1e-6` 以内，局部线性化误差也远低于 `0.05`。这说明末端任务响应在数值上仍可近似线性，但导管整体形态已经跨入不同的平衡分支或接近多解竞争区域。

更重要的是，灵敏度向量在临界区间前后发生方向改变。`eps=0.01` 时 x 方向灵敏度为正，而 `eps=0.0125` 后 x 方向灵敏度转为负。这种符号翻转通常不能解释为普通数值噪声，而更符合“扰动重求解落入相邻形态分支”的特征。

从物理角度看，强电流三磁体工况下，磁力和磁矩经刚性磁体段向相邻柔顺段传播后，可能在局部形成多个相近能量的平衡形态。小扰动范围内求解器仍停留在同一形态分支，因此可获得局部灵敏度；扰动半径超过临界值后，重求解过程可能转入另一条形态分支，导致轴线漂移和灵敏度方向突变。

## 实验结论

本轮结论如下：

- 已验证结论：`n3_mixed_rand20, alpha=0.4` 的高置信灵敏度只应在 `eps<=0.01` 的小邻域内发布。
- 已验证结论：当前判据下，失效边界位于 `0.01` 到 `0.0125` 之间。
- 已验证结论：`eps>=0.0125` 的失败主要来自形态分支漂移，不是一阶最优性残差或线性化误差。
- 待验证假设：该工况存在多解竞争或近分岔行为，且该行为首先表现为轴线形态漂移，再影响末端任务灵敏度。
- 适用工况：三磁体混合磁化、随机强电流组合、`alpha=0.4`、当前打靶变量与当前网格配置。
- 已知失效边界：外层逆运动学若在该区域采用过大的电流比例步长，可能跨越形态分支并得到方向错误的敏感度。

## 下一步计划

下一步不应继续在同一区间做密集重复采样，信息增益已经较低。建议转向两类实验：

1. 对 `n3_mixed_rand20` 改变 `alpha`，绘制扰动半径临界值随目标加载程度变化的相图，判断分支漂移是否集中出现在 `alpha=0.4` 附近。
2. 对其他三磁体随机电流工况做同样的粗粒度扫描，判断 `0.01` 左右的安全扰动半径是该工况特例，还是强电流三磁体配置的共性限制。

工程建议：在该类工况下，外层逆运动学的单步电流比例更新应暂时限制在 `0.01` 以内，并在每步后检查轴线分支漂移；若漂移超过 `1e-3 m`，应拒绝该步长并采用更小步长或重新选择初始分支。
