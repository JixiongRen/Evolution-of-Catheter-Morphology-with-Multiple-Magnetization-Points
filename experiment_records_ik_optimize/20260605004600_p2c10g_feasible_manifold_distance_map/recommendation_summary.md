# P2c10g 工程建议摘要

## 结论等级

本轮结论属于“工作空间边界诊断证据”。结果不能用于发布敏感度，但可用于定义当前导管配置和电流方向下的高风险操作区。

## 失败类别

| 类别 | 证据 | 判断 |
|---|---|---|
| 可达域受限 | 物理可行分支与目标末端位姿相距 `8.6-12.7 mm`、`27-33 deg` | 主要机制 |
| 多分支竞争 | 物理可行分支低边界、低连续，但远离目标分支 | 高度可疑 |
| 一阶最优性不足 | 所有点一阶最优性残差均高于门禁 | 禁止发布敏感度 |
| 段间连续性冲突 | 原始连续残差很低，但目标距离仍大 | 连续性本身不是唯一问题 |

## 工作空间建议

- `alpha < 0.20`：仍需继续验证，但可作为当前路径下更优先的可信候选区。
- `alpha=0.20`：虽然历史稳定敏感度较好，但物理可行分支距离目标已有 `8.63 mm` 和 `27.26 deg`，应视为保守上限附近。
- `0.20 <= alpha <= 0.25`：建议归类为边界诊断区，不发布任务敏感度。
- `alpha > 0.25`：建议归类为高风险区，除非后续更换导管配置、磁化模式或控制目标。

## 导管构型建议

- 当前三段混合磁化构型在该电流方向下会造成目标分支与物理可行分支明显分离。
- 若目标是稳定敏感度，应优先测试磁化方向更一致或磁化段数更少的构型。
- 若必须保留三段混合磁化，应收缩目标工作空间，并在控制器中引入物理可行分支距离门禁。

## 线圈电流建议

- 不建议仅使用单线圈幅值上限，应对电流方向建立限幅。
- 对接近 `n3_mixed_rand20` 的方向，建议把 `alpha=0.20` 作为当前保守上限参考。
- 一旦物理可行分支到目标末端的距离超过约 `8 mm` 或姿态误差超过约 `25 deg`，应禁止发布敏感度。

## 下一步建议

下一轮应从单一路径诊断转入代表性工况覆盖，建立“物理可行分支距离相图”。该相图应覆盖不同磁化段数、磁化方向和电流方向，用于给出更普适的工作空间和电流限幅建议。
