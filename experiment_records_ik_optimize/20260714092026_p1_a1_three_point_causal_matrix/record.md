# P1 A1 三点因果矩阵实验记录

## 一、实验目的

本轮实验用于验证 A1 单点轴向磁化导管在 `pt01`、`pt12`、`pt13` 三个代表目标上的门禁因果关系。重点判断：推进量作为入盆通道是否能够避免旧成功点退化，并解释两个失败点的主因。

## 二、固定条件

- 导管：A1。
- 目标点：`pt01`、`pt12`、`pt13`。
- 重力：关闭。
- 离散化：`M_list=5`。
- FK 容差：`1e-5`。
- 成功阈值：真实刚性远端误差不超过 `5 mm`。
- 电流范围：`[-20, 20] A`。
- 推进范围：`[0.003001, 0.203] m`。
- 运行环境：`evolution_of_mcrs`，强制 `JAX_PLATFORMS=cuda`。

## 三、实验矩阵

本轮运行四组：

1. `p2_no_gate`：P2 外层策略，不启用通道门禁。
2. `p2_refine_gate`：P2 外层策略，使用精修门禁。
3. `p2_basin_gate`：P2 外层策略，使用入盆门禁。
4. `p2_two_stage_gate`：先入盆门禁，再从入盆状态切换到精修门禁。

## 四、当前状态

实验已完成，四组均自然结束，退出码均为 `0`。运行命令见 `commands.sh`。

## 六、诊断结论

1. P0 证据口径修正生效。两阶段精修行被标记为“热启动流程验证”，`algorithm_statistics_included=False`，不会被误计入算法成功率。
2. A1-pt01 的主因已经比较明确：精修门禁禁用推进量会破坏旧成功点，误差从无门禁的 `3.614 mm` 退化到 `27.787 mm`。入盆门禁允许推进量后可恢复到 `4.383 mm`。
3. A1-pt12 没有被当前门禁策略改善。无门禁、入盆门禁、两阶段门禁均停留在 `50--58 mm` 量级；精修门禁进一步退化到 `81.688 mm`。当前应归因为入盆失败或目标附近可控方向不足，不能再简单归因于推进量被禁用。
4. A1-pt13 最优结果来自 P2 无门禁，为 `5.778 mm`，接近但未进入 `5 mm`。精修门禁和入盆门禁均明显退化；两阶段流程验证可把精修最终误差降到 `25.529 mm`，但仍不成功，且不能作为算法统计证据。
5. 当前两阶段策略不能作为 A1 扩点依据。它保住了 pt01 的流程，但没有以算法统计口径证明 pt12/pt13 可收敛。
6. 对无门禁组进一步检查 `history.json` 后确认：pt12 和 pt13 的历史最小误差均等于最终误差，未发现更优状态被汇总遗漏。pt13 最后数步仍有极小幅改善，但停在 `5.778 mm`，更符合近阈值局部停滞，而不是落盘口径错误。

## 七、下一步建议

1. 对 A1-pt13 优先做局部近阈值修正。它在无门禁 P2 下已经达到 `5.778 mm`，应检查历史最小状态、接受判据和最后几步的真实末端误差变化，判断是否存在被停止策略或微步策略卡在阈值外的问题。
2. 对 A1-pt12 进入入盆失败诊断。需要检查控制量轨迹、推进量是否触及边界、任务秩和误差下降方向，而不是继续调整现有门禁。
3. 精修门禁当前不应进入正式回归。它会破坏旧成功点，并使失败点进一步退化。
4. A1 扩展到 5 点、10 点或 20 点前，必须先解决 pt13 近阈值问题，并给出 pt12 的主因证据。
