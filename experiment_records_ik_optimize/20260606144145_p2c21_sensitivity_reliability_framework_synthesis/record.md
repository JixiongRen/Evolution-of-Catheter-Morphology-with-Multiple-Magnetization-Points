# P2c21 任务敏感度可靠性框架汇总实验

## 实验目的

本实验不新增打靶求解，而是整合 P2c15 至 P2c20 的已保存证据，形成面向长期研究目标的可靠性判定框架。核心目标是将“能否发布高置信任务敏感度”从单一数值结果转化为一组可审计门禁，包括一阶最优性、局部线性化、分支一致性、刚性磁体段载荷传播一致性和时间成本。

## 实验方案

1. 读取 P2c15 至 P2c19 的 `summary.json`，提取各 `alpha` 点的敏感度、线性化误差、一阶最优性、分支差异和载荷传播指标。
2. 读取 P2c20 的多初值分支审计结果，提取物理分支可进入性和初值依赖性。
3. 按统一规则生成可靠性分类表和失败归因表。
4. 绘制 `alpha` 相图、失败模式统计图、P2c20 初值门禁图和时间成本图。
5. 输出面向后续跨工况采样的工程建议。

## 数学表述

令打靶优化问题为

```math
y^*(p)=\arg\min_y F(y,p),
```

其中 `p` 表示电流、磁化配置、导管构型或目标工况参数。任务量记为

```math
\Phi(p)=\Phi(y^*(p),p).
```

只有当 `y^*(p)` 满足一阶最优性、约束相容性、局部分支稳定性和局部线性化条件时，任务敏感度

```math
J_\Phi(p)=\frac{d\Phi}{dp}
```

才可作为高置信结果发布。本实验使用以下线性化误差作为局部可导性的实验证据：

```math
r_{\mathrm{lin}}
=
\frac{\|\Phi(p+\Delta p)-\Phi(p)-J_\Phi \Delta p\|}
{\|\Phi(p)\|}.
```

若一阶最优性残差、条件数、分支差异、载荷传播指标或线性化误差超过门限，则该点只能作为诊断样本。

## 数据分析

综合 P2c15 至 P2c20 的证据，当前 `n3_mixed_rand20` 工况下的敏感度可信区域可以暂时分为三类。

第一类是高置信区域。已有样本显示，`alpha=0.3752` 至 `0.425` 的若干离散点满足线性化误差、一阶最优性、分支一致性和载荷传播门禁。这些点可以发布局部任务敏感度，但结论目前只对已测试的固定导管构型、三磁化段混合磁化模式和当前电流缩放路径成立。

第二类是临界边界区域。`alpha=0.3750` 的 P2c20 结果表明，物理分支确实存在，并且分支内部重复性很高；但该分支吸引域很窄，19 个初值中只有 4 个进入物理分支。因此该点不能简单归类为“不可解”，更准确的归因是“物理分支存在但独立求解可进入性差”。这类点不应发布高置信敏感度，但应作为分支吸引域退化样本保留。

第三类是诊断区域。`alpha=0.35`、`0.375`、`0.435` 及以上若干样本表现为诊断结果。下界附近主要表现为独立初值进入物理分支困难；上界附近主要表现为路径依赖或临界性增强。由于这些样本尚未在更密集网格和更多扰动方向下完成验证，不能把它们概括为绝对不可用区域。

从物理角度看，失败样本中最突出的现象是一阶最优性退化和刚性磁体段载荷传播失配。低电流或弱驱动区域中，磁体段所受磁力和磁矩不足以稳定地产生目标弯曲，段间内力和内矩自由度可能补偿末端误差，从而形成末端位置较接近但物理不一致的局部解。高电流或边界区域中，磁载荷增强可能导致多平衡竞争、分支切换或局部失稳。

从数学角度看，当前证据支持“先判定再求导”的流程。若最优解 `y^*(p)` 不满足一阶最优性或分支唯一性，则 `dPhi/dp` 没有稳定的局部意义。此时即使有限差分能给出数值斜率，该斜率也可能只是不同分支之间的割线，而不是同一物理分支上的微分。

## 实验结论

1. 当前已形成一套可复用的敏感度可靠性判定框架，覆盖样本级门禁、失败归因、分支审计和工程建议。
2. `n3_mixed_rand20` 在 `0.3752 <= alpha <= 0.425` 的已测试样本中具备高置信敏感度证据。
3. `alpha=0.3750` 是临界样本，物理分支存在且内部稳定，但独立求解可进入性不足。
4. 失败样本不能只按“未收敛”处理，至少应区分一阶最优性退化、分支不一致、载荷传播失配和边界临界。
5. 当前结论仍局限于单一困难工况，尚未覆盖不同磁化段数、磁化方向、导管构型和线圈组合。

## 下一步计划

下一轮应从单一工况转向分层采样框架。建议优先开展小规模跨工况验证，而不是继续加密 `alpha=0.3750` 单点。

具体计划如下：

1. 固定判定门禁，选择 1 段、2 段和 3 段磁化构型各若干代表样本。
2. 每个样本先做物理分支可进入性审计，再计算任务敏感度。
3. 对每个失败样本自动输出失败主类型、残差分块证据和刚性磁体段载荷传播指标。
4. 将本轮 `case_reliability_rows.csv` 和 `seed_branch_rows.csv` 作为长期框架的初始数据表。
5. 若某一类构型连续出现低信息增益样本，应转向未覆盖的磁化方向或线圈组合。
