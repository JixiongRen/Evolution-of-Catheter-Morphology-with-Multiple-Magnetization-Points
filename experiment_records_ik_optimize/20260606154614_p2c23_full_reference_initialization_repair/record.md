# P2c23 完整参考初值修复实验

## 实验目的

P2c22 的跨工况试点显示，四个代表工况均因一阶最优性退化而不能发布高置信敏感度。进一步检查发现，现有 `oracle` 初值只使用 FK 参考打靶变量的前 6 维基底内力和内矩，没有使用段间界面内力和内矩变量。本实验检验完整参考初值能否改善跨工况打靶求解的驻点质量。

## 实验方案

对每个代表工况比较五类初值：

| 初值 | 含义 |
|---|---|
| `truncated_oracle` | 仅使用 `y_ref` 前 6 维 |
| `full_reference` | 使用完整 `y_ref` |
| `half_full_reference` | 使用 `0.5 y_ref` |
| `interface_only` | 仅使用 `y_ref` 的段间界面变量 |
| `zero` | 全零初值 |

每个初值求解同一位置任务打靶问题，并记录一阶最优性、末端位置误差、局部条件数、段间载荷传播指标和多初值中心线差异。

## 数学表述

打靶变量写为

```math
y=[w_0,\lambda_1,\lambda_2,\dots],
```

其中 `w_0` 为基底内力和内矩，`\lambda_i` 为第 `i` 个段间界面传递的内力和内矩修正。P2c22 的截断初值等价于

```math
y_0=[w_0^{FK},0,0,\dots],
```

而完整参考初值为

```math
y_0=[w_0^{FK},\lambda_1^{FK},\lambda_2^{FK},\dots].
```

若完整参考初值显著降低一阶最优性残差，则 P2c22 的失败主要来自初始化信息丢失；若仍失败，则说明问题更可能来自目标函数权重、变量尺度、打靶参数化或 FK 参考与 clean shooting 模型之间的不一致。

## 实验结果

本轮覆盖四个代表工况，每个工况比较五种初值。没有任何样本通过高置信基线门禁，主失败类型均为一阶最优性退化。总体结果如下：

| 工况 | 最佳初值 | 是否可信 | 最佳一阶最优性 | 最佳界面力松弛/刚段外力 | 末端位置误差 | 主失败类型 |
|---|---|---|---:|---:|---:|---|
| `n1_tip_z_rand15` | `half_full_reference` | 否 | `2.52e-2` | `2.71` | `1.58e-4 m` | 一阶最优性退化 |
| `n2_z_pair_rand12` | `truncated_oracle` | 否 | `4.18e-1` | `4.81` | `3.33e-4 m` | 一阶最优性退化 |
| `n3_mixed_base_i4` | `half_full_reference` | 否 | `2.27e-2` | `2.86` | `9.11e-5 m` | 一阶最优性退化 |
| `n3_mixed_rand20` | `zero` | 否 | `4.50e-1` | `10.85` | `1.42e-4 m` | 一阶最优性退化 |

分初值结果显示：

- `full_reference` 并不总是优于截断初值；在 `n3_mixed_base_i4` 中反而造成一阶最优性显著恶化。
- `half_full_reference` 对 `n1_tip_z_rand15` 和 `n3_mixed_base_i4` 明显改善一阶最优性，但仍未达到 `1e-5` 门限，且界面载荷传播指标仍超过 `2.0`。
- `interface_only` 不能稳定改善驻点质量，说明仅保留界面变量不足以恢复物理一致性。
- `n3_mixed_rand20` 的最佳初值仍为 `zero`，说明困难工况的失败并非单纯由参考初值截断导致。

## 数据分析

P2c23 直接检验了 P2c22 的一个关键假设：跨工况一阶最优性退化是否主要来自参考初值截断。实验结果表明，该假设只部分成立。

对 `n1_tip_z_rand15` 和 `n3_mixed_base_i4`，`half_full_reference` 将一阶最优性残差从 P2c22 的约 `0.4` 降低到约 `2e-2`，说明段间界面变量确实携带了重要的物理信息。但是该改进仍远未达到 `1e-5` 的敏感度发布门限，并且界面力松弛与刚段外力比例仍大于 `2.0`。这说明初值信息可以改善求解方向，但不能单独保证段间载荷传播一致。

对 `n2_z_pair_rand12` 和 `n3_mixed_rand20`，完整参考初值没有带来稳定改善。尤其是 `n3_mixed_rand20` 中，完整参考初值的末端误差达到 `9.12e-3 m`，明显劣于零初值。这说明 FK 参考状态和 clean shooting 打靶模型之间可能存在分支或模型不一致；将 FK 参考变量直接作为打靶初值，可能把求解器带入不适合当前残差定义的局部区域。

数学上，设目标残差为

```math
r(y)=
\begin{bmatrix}
r_{\mathrm{tip}}(y) \\
r_{\mathrm{boundary}}(y) \\
r_{\mathrm{slack}}(y)
\end{bmatrix}.
```

一阶最优性要求

```math
J(y)^T r(y)=0.
```

本轮样本中，即使末端误差较小，`||J^T r||` 仍显著大于门限，说明求解点不是残差最小化问题的稳定驻点。因此对应的有限差分响应不能被解释为平衡分支上的高置信敏感度。

物理上，段间界面变量代表刚性磁体段载荷向相邻柔顺段传播时的内力和内矩修正。若这部分变量初始化不合理，求解器会倾向于用界面松弛补偿末端误差；若完整参考变量与当前 clean shooting 残差定义不一致，则又可能引入错误的载荷分配。因此跨工况高质量敏感度需要的不是简单复制 FK 参考变量，而是一个能同时满足末端任务、边界残差和段间载荷连续性的初始化-延续流程。

## 实验结论

1. P2c22 的跨工况失败不完全由截断初值导致。
2. 完整参考初值在部分工况中有帮助，但不能直接恢复高质量驻点。
3. 半参考初值对单磁化段和稳定三磁化段更有效，提示后续可采用逐级引入界面变量的延续策略。
4. 当前跨工况主卡点仍是一阶最优性和段间载荷传播一致性，而不是末端位置误差或局部几何线性化。
5. 对困难三磁化段，FK 参考变量和 clean shooting 模型可能存在更强的局部分支不一致，必须单独审计。

## 下一步计划

下一轮建议开展 P2c24：分阶段界面变量延续和权重延续。

建议流程：

1. 以 `half_full_reference` 为起点，对 `n1_tip_z_rand15` 和 `n3_mixed_base_i4` 做界面变量延续：

```math
y_0(\eta)=[w_0^{FK},\eta\lambda^{FK}], \quad \eta \in [0,1].
```

2. 同时做权重延续，将界面松弛权重和边界权重从低值逐步提高到目标值。
3. 每个阶段记录 `||J^T r||`、末端误差、边界残差和载荷传播比例。
4. 若 `n1` 或 `n3_mixed_base_i4` 能恢复到 `1e-5` 量级，再将流程迁移到 `n2` 和 `n3_mixed_rand20`。
5. 若仍无法恢复，应进入残差雅可比分块审计，判断是否存在变量尺度不匹配或 clean shooting 参数化不足。
