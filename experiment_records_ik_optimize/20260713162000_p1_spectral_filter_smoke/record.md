# P1 残差空间谱滤波烟测记录

## 一、实验目的

本轮用于验证新增谱滤波参数链路是否可运行。该实验只覆盖 A1-pt01 的一个电流通道，不作为 P1 完整结论。

## 二、实验设置

- 代表点：A1-pt01。
- 控制通道：第 0 个电流通道。
- 扰动步长：`0.25 A`。
- 灵敏度模式：残差雅可比奇异值分解。
- 谱滤波：阻尼型软滤波。
- 谱阻尼参数：未显式给定，由 `svd_rcond * 最大奇异值` 自动确定。
- `svd_rcond=1e-8`。

完整命令见 `commands.sh`。

## 三、结果

程序在 GPU 环境下完成运行，并正确输出新增谱滤波字段：

- `spectral_filter=tikhonov`。
- `spectral_lambda=0.001066687610041737`。
- `retained_spectral_energy=1.0`。

该配置通过同分支回环门禁，但灵敏度误差较大：

- 相对误差约 `38.30%`。
- 幅值比约 `0.618`。
- 方向角约 `2.17 deg`。

## 四、结论

新增参数链路可运行，但默认阻尼型软滤波明显过度压低电流响应，不能直接作为正式候选。后续应比较硬截断阈值，而不是直接把软滤波接入外层 IK。
