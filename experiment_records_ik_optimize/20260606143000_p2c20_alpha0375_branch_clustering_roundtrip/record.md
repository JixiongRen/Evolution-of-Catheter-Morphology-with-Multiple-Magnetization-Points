# P2c20 alpha=0.3750 分支聚类与回环稳定性审计

## 实验目的

本实验面向 `n3_mixed_rand20` 工况在 `alpha=0.3750` 附近出现的敏感度断裂现象，分析该点是否存在多平衡分支、初值依赖和路径依赖。实验重点不是发布任务敏感度，而是解释为什么相同物理参数下部分求解路径可以得到低残差解，而严格独立初值可能收敛到物理一致性较差的解。

## 数学表述

设打靶变量为每段近端内力和内矩组成的向量 `y`，电流缩放参数为 `alpha`。对于固定 `alpha`，求解器通过最小化加权残差函数

```math
\min_y \; \|r_{\mathrm{task}}(y,\alpha)\|^2
+ \|r_{\mathrm{boundary}}(y,\alpha)\|^2
+ \lambda_s \|r_{\mathrm{slack}}(y,\alpha)\|^2 .
```

若局部最优点 `y*(alpha)` 唯一且一阶最优性残差足够小，则任务映射 `Phi(alpha)=Phi(y*(alpha), alpha)` 才具备局部线性化解释。若多个初值收敛到几何差异显著的局部极小点，则该点的敏感度不能作为高置信结果发布，只能标记为分支竞争或路径依赖诊断。

## 实验方案

1. 固定 `alpha=0.3750`。
2. 采用多类初值，包括严格独立初值、辅助参考初值、延续路径初值、混合初值和小扰动初值。
3. 对每个初值分别求解，记录末端位置误差、一阶平稳性、雅可比条件数、界面力松弛与刚段外力比值。
4. 计算不同收敛解之间的中心线均方根差异和末端距离。
5. 执行 `alpha=0.3750 -> alpha±0.0002 -> alpha=0.3750` 的回环实验，判断路径返回后是否保持同一分支。

## 判定标准

满足以下条件的解标记为物理分支候选：

- 末端位置误差不超过导管长度的 5%。
- 一阶平稳性残差不超过 `1e-5`。
- 雅可比条件数不超过 `1e10`。
- 界面力松弛与刚段外力比值不超过 `2.0`。

若严格独立初值不能进入物理分支，而延续路径可以进入物理分支，则说明该点附近存在明显路径依赖，不能直接发布高置信敏感度。

## 数据分析

本实验显示，`alpha=0.3750` 附近并非简单的“没有物理解”。物理分支在数值上存在，并且一旦进入该分支，分支内部的中心线差异约为 `1e-9 m`，回环误差也约为 `1e-9 m`。这说明物理分支本身具有很高的局部重复性。

真正的问题是吸引域很窄。严格独立初值中只有 `nearest_seed_0.40` 能进入物理分支，而 `nearest_seed_0.35` 和 `zero` 虽然末端位置误差不一定大，但一阶平稳性残差和界面力松弛显著超限。这说明仅凭末端误差不能判断敏感度质量；在该区域，末端约束可以被非物理的界面载荷分配近似满足。

从物理角度看，低 `alpha` 区域磁驱动力较弱，刚性磁体段受到的磁力和磁矩经段间界面传播后，对柔顺段的有效弯矩不足。此时打靶变量中的界面内力和内矩自由度容易补偿驱动不足，形成数学上能降低末端误差、但不满足段间载荷连续性的局部极小点。因此该点附近的敏感度不应直接发布，而应先判定求解点是否处于物理一致分支。

从数学角度看，任务敏感度可以写为

```math
\frac{d\Phi}{d\alpha}
=
\frac{\partial \Phi}{\partial y}\frac{dy^*}{d\alpha}
+
\frac{\partial \Phi}{\partial \alpha}.
```

只有当 `y*(alpha)` 是局部唯一、分支稳定且满足一阶最优性条件的解时，`dy*/dalpha` 才有明确局部意义。本实验表明，在 `alpha=0.3750` 处，物理分支上的局部导数可能存在，但从独立初值进入该分支并不可靠。因此该点应归类为“分支吸引域过窄导致的高风险敏感度点”，而不是普通稳定点。

## 实验结论

1. `alpha=0.3750` 处存在低残差、载荷传播一致的物理分支，但该分支吸引域很窄。
2. 延续路径可以稳定停留在物理分支，回环误差为 `1e-9 m` 量级，说明分支内部可重复。
3. 多数独立或混合初值会进入非物理解或未解析分支，这些解常表现为界面力松弛与刚段外力比例过高。
4. 该工况下禁止仅根据末端位置误差发布敏感度；必须同时满足一阶平稳性、界面载荷传播和分支一致性门禁。
5. 对长期敏感度框架而言，`alpha=0.3750` 应标记为临界边界点：可以作为失败归因样本，不应作为高置信敏感度样本。

## 下一步计划

下一步应从单点边界归因转向跨工况覆盖框架，重点增加以下能力：

1. 对每个候选工况先进行物理分支可进入性判定，再进行敏感度计算。
2. 将“物理分支存在但吸引域过窄”作为独立失效类型纳入失败分类。
3. 对低电流、弱磁驱动或可达域边界附近工况，增加逐级增载和多初值分支审计。
4. 对可疑工况输出工程建议：避免将工作点布置在物理分支吸引域过窄的区域；若必须经过该区域，应使用路径延续控制而不是独立点求解。
