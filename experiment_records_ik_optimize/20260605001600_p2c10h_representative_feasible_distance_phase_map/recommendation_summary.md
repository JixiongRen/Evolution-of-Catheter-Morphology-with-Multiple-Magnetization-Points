# P2c10h 工程建议摘要

## 结论等级

本轮结论属于“代表性工况相图证据”。结果可用于初步工作空间和电流限幅建议，但不能用于发布敏感度。

## 区域分类

| 分类 | 含义 | 工程处置 |
|---|---|---|
| 可信候选区 | 距离和一阶最优性同时满足严格门禁 | 可进入敏感度审计 |
| 边界候选区 | 目标距离较小，但一阶最优性尚未过门禁 | 只允许做复核，不发布敏感度 |
| 高风险区 | 目标距离或物理残差过大 | 不建议用于敏感度控制 |

本轮没有发现可信候选区。

## 工况建议

| 工况 | 建议 |
|---|---|
| `n1_tip_z_rand15` | 所有采样点均为高风险区，建议重新设计目标方向或降低目标幅值。 |
| `n2_z_pair_rand12` | `alpha=0.25` 可进入严格敏感度复核；`alpha>=0.50` 暂不建议使用。 |
| `n3_mixed_rand20` | `alpha=0.25` 可进入严格敏感度复核；`alpha>=0.50` 暂不建议使用。 |

## 电流限幅建议

- 当前代表性结果支持将双磁化和三磁化强电流工况的初步限幅设为 `alpha<=0.25`。
- `alpha>=0.50` 的双磁化和三磁化样本均进入高风险区，不建议发布敏感度。
- 单磁化末端工况不能简单认为更安全；本轮结果显示其目标距离随电流增强明显增大。

## 导管构型建议

- 磁化段数不是唯一决定因素。目标方向、电流方向和物理可行分支距离共同决定敏感度可信性。
- 三段混合磁化在低载下仍可能有边界候选区，但高载下风险迅速上升。
- 双段轴向磁化在低载下表现相对较好，值得作为下一轮复核对象。

## 下一步建议

优先复核两个边界候选点：

1. `n2_z_pair_rand12@alpha=0.25`
2. `n3_mixed_rand20@alpha=0.25`

复核必须包含一阶最优性、条件数、局部线性化误差、扰动重求解和分支跳变检查。若仍不通过，应将其归类为边界诊断区，而不是可信控制区。
