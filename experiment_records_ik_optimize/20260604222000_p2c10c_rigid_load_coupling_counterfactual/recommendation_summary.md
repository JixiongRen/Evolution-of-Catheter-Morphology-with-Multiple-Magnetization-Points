# P2c10c 工程建议摘要

## 结论等级

本轮结论属于“强诊断证据”，不是“生产模型验证”。反事实耦合显著改善了断裂邻域的一阶最优性残差，但尚未严格通过敏感度发布门禁。

## 失败类别

| 类别 | 证据 | 判断 |
|---|---|---|
| 刚性磁体段载荷传播失配 | `alpha=0.25` 下，一阶最优性残差由 `20.587278` 降至 `0.001439` | 主要嫌疑机制 |
| 段间连续性冲突 | P2c10b 中连续性项不是主导贡献，本轮未直接修复硬连续性 | 次要或待复核机制 |
| 目标不可达 | 总残差和边界残差均较小，反事实后进一步改善 | 证据不足，不宜作为主因 |
| 纯数值病态 | `alpha=0.20` 稳定，`alpha=0.25` 对载荷传播改动高度敏感 | 不能解释全部现象 |

## 工作空间建议

- `alpha <= 0.20`：暂定为当前模型下的可信工作区，可继续发布经过门禁验证的任务敏感度。
- `0.20 < alpha <= 0.25`：定义为重点诊断区。该区域不应直接发布敏感度，但适合作为模型修复验证区。
- `alpha > 0.25`：在刚性磁体段载荷传播修复完成前，暂定为高风险区，不建议用于外层逆运动学敏感度控制。

## 导管构型建议

- 多磁化段混合方向构型应被视为高风险构型，尤其是磁化方向突变明显、末端附近载荷较强的情况。
- 若目标是优先获得稳定敏感度，应优先选取磁化方向更一致、段间载荷传递更平滑的构型。
- 若必须使用三段混合磁化构型，应将其定位为机理研究对象，而不是优先作为工程控制主线。

## 线圈电流建议

- 不建议仅用单线圈幅值上限定义安全范围，应同时限制电流方向组合。
- 对会把系统推向 `n3_mixed_rand20` 类似方向的电流组合，应采用逐级增载并实时检查一阶最优性残差。
- 在物理化载荷传播修复前，建议将该路径的运行包络限制在 `alpha <= 0.20` 附近。

## 下一步建议

下一轮应实现物理化刚性磁体段载荷传播原型，而不是继续增大经验 `beta` 或重复调权重。该原型应显式描述磁力、磁矩在刚性磁体段上的作用位置、力矩臂和向柔顺段的界面传递。
