# P2c10c 刚性磁体段载荷传播反事实实验记录

## 实验目的

本实验用于检验困难工况 `n3_mixed_rand20` 的敏感度断裂是否与“刚性磁体段载荷到末端位姿传播不足”有关。此前 P2c10a 与 P2c10b 显示，沿 `n3_mixed_base_i4 -> n3_mixed_rand20` 的逐级增载路径中，`alpha=0.20` 仍可线性化，而 `alpha=0.25` 出现一阶最优性残差突增；残差分块归因表明，末端位置残差与末端边界残差共同主导该失效。

本轮实验不修改生产求解器，只在实验脚本中引入一个等效反事实耦合系数 `beta`。该系数表示刚性磁体段所受外部力矩对刚段远端姿态产生一个小的等效转动响应。该设置不是经过标定的真实物理模型，仅用于判断“载荷传播路径缺失”这一假设是否具有解释力。

## 实验方案

实验对象为 `n3_mixed_base_i4 -> n3_mixed_rand20` 的两级代表点：

- `alpha=0.20`：此前判定为稳定可线性化点。
- `alpha=0.25`：此前判定为首次断裂邻域。

反事实耦合系数取：

- `beta=0.0`：原模型等价路径。
- `beta=0.005`
- `beta=0.01`
- `beta=0.02`

每组使用相同打靶状态变量、相同残差构成、相同最大迭代次数和相同积分步数。判定条件保持不变：

- 总残差小于等于 `1.0e-2`。
- 末端边界残差小于等于 `2.0e-1`。
- 一阶最优性残差小于等于 `1.0e-3`。

只有三者同时满足时，才允许标记为可线性化。

## 实验命令

```bash
XLA_PYTHON_CLIENT_PREALLOCATE=false conda run -n evolution_of_mcrs python experiment_records_ik_optimize/20260604222000_p2c10c_rigid_load_coupling_counterfactual/run_p2c10c_rigid_load_coupling_counterfactual.py \
  --base_case n3_mixed_base_i4 \
  --target_case n3_mixed_rand20 \
  --alphas 0.20,0.25 \
  --betas 0.0,0.005,0.01,0.02 \
  --continuity_mu 1.0 \
  --reg_mu 1.0e-4 \
  --max_iter 24 \
  --steps_per_flex 4
```

运行设备为 `cuda:0`，总墙钟时间为 `947.06 s`。

## 过程记录

首次运行时，`beta=0` 的零旋转增量在自动微分中产生了未定义梯度，导致雅可比矩阵包含非有限数。该问题来自反事实脚本中的零范数求导处理，不是物理结论。随后将旋转向量范数改为带微小正则项的可微形式，完整实验顺利完成。

## 实验结果

### alpha=0.20

| beta | 总残差 | 一阶最优性残差 | 末端边界残差 | 是否可线性化 |
|---:|---:|---:|---:|---|
| 0.000 | 0.001884 | 7.806e-06 | 0.002706 | 是 |
| 0.005 | 0.001889 | 1.536e-05 | 0.002715 | 是 |
| 0.010 | 0.001893 | 3.021e-05 | 0.002723 | 是 |
| 0.020 | 0.001903 | 5.723e-06 | 0.002739 | 是 |

稳定点未被反事实耦合破坏。`beta=0.02` 仍满足全部门禁。

### alpha=0.25

| beta | 总残差 | 一阶最优性残差 | 末端边界残差 | 是否可线性化 |
|---:|---:|---:|---:|---|
| 0.000 | 0.002196 | 20.587278 | 0.003823 | 否 |
| 0.005 | 0.002152 | 6.358938 | 0.003740 | 否 |
| 0.010 | 0.002166 | 5.916374 | 0.003771 | 否 |
| 0.020 | 0.002070 | 0.001439 | 0.003328 | 否 |

`beta=0.02` 将 `alpha=0.25` 的一阶最优性残差从 `20.587278` 降至 `0.001439`，下降约四个数量级，并且总残差和末端边界残差也同步降低。但该值仍高于 `1.0e-3` 门禁，因此不能发布该点的任务敏感度。

## 数据分析

本轮结果支持如下判断：

1. 刚性磁体段载荷到末端位姿的传播路径确实对断裂邻域的一阶最优性有强影响。若该路径完全无关，改变 `beta` 不应使一阶最优性残差从 `20.59` 接近 `1.0e-3`。
2. 该反事实耦合没有破坏 `alpha=0.20` 的稳定性，说明“刚段载荷传播不足”不是单纯通过牺牲稳定工况换取困难工况改善。
3. `alpha=0.25` 尚未严格通过门禁，说明当前等效耦合只是诊断性证据，不能作为正式物理模型接入外层逆运动学。
4. 末端边界残差随 `beta` 增大而下降，说明此前的断裂很可能不只是数值优化病态，还包含刚性磁体段载荷向相邻柔顺段传递时的物理表述不足。

从数学角度看，打靶问题可写成

$$
\min_y \frac{1}{2}\|r(y, I)\|^2,
$$

其中 `y` 为分段近端内力和内矩，`I` 为线圈电流，`r` 包含末端位姿残差、末端边界残差、分支保持残差与段间连续残差。可发布敏感度要求当前解满足近似驻值条件

$$
\|\nabla_y \frac{1}{2}\|r(y,I)\|^2\| = \|J_y^\mathsf{T}r\| \leq \epsilon.
$$

本轮中 `alpha=0.25, beta=0.02` 的驻值残差已接近阈值但仍未达标，因此该点只能作为“接近可恢复”的诊断样本，不能作为高置信敏感度样本。

## 实验结论

本轮实验没有证明困难点 `alpha=0.25` 已恢复为可发布敏感度点，但提供了强证据支持以下假设：

> 困难工况的敏感度断裂与刚性磁体段磁载荷到末端位姿、边界内力和内矩的传播建模不足密切相关。

由于 `beta=0.02` 已将一阶最优性残差压低至 `0.001439`，下一阶段不应继续重复普通权重扫描，而应转向具有物理意义的刚性磁体段载荷传播修复。该修复必须以段内力矩分布、远端姿态传播和段间内力内矩连续为核心，而不是继续添加任意等效参数。

## 下一步计划

1. 建立刚性磁体段载荷传播的物理化原型，将磁力和磁矩沿刚段长度积分传播到远端，而不是只用经验 `beta` 表示等效转动。
2. 在 `alpha=0.20` 和 `alpha=0.25` 上做回归，要求稳定点不退化，并检查断裂点是否正式通过一阶最优性门禁。
3. 若物理化原型仍未恢复 `alpha=0.25`，则进入硬连续多段打靶，将段间内力和内矩连续性从弱罚项提升为核心约束。
4. 在任何恢复方案接入外层逆运动学前，必须重复影子回放验证和重优化扰动验证。
