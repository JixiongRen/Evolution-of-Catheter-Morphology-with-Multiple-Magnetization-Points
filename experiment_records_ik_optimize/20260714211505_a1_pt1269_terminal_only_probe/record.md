# A1 pt12.6875 末端位置专用步探针记录

## 实验目的

本实验用于判断综合目标中的电流、推进量和步长正则项是否牵制了真实末端误差下降。实验只用真实末端位置残差构造外层更新步，再用相同 FK 和真实末端优先接受判据进行验证。

## 实验条件

- 导管配置：A1，单点轴向磁化。
- 物理设置：无重力，`M_list=5`，FK 容差 `1e-5`。
- 控制边界：电流 `[-20, 20] A`，推进量 `[0.003001, 0.203] m`。
- 目标点：`pt_12.6875`。
- 初始状态：使用 `pt_12.75` 成功状态作为热启动。
- 外层策略：末端位置专用步，可靠子空间关闭，真实末端误差优先，阻尼保持开启，停滞救援上限为 2 次。
- 运行环境：`JAX_PLATFORMS=cuda`，`XLA_PYTHON_CLIENT_PREALLOCATE=false`。

## 实验结果

| 指标 | 数值 |
|---|---:|
| 最终真实末端误差 | `5.476 mm` |
| 是否进入 5 mm | 否 |
| 终止原因 | 有效步长低于阈值 |
| 接受/拒绝次数 | `6 / 58` |
| 墙钟时间 | `858.0 s` |
| FK 平衡分类 | `GOOD` |

## 数据分析

末端位置专用步将误差从约 `5.59 mm` 降到约 `5.48 mm`，改善明显大于关闭可靠子空间的结果。这说明综合正则项确实会牵制末端位置收敛。但是误差仍未进入 `5 mm`，并且后期出现重复拒绝和步长塌缩，说明当前分支附近可能存在局部平台，或需要引入新的平衡分支候选。

## 实验结论

末端位置专用步是有效方向，但不足以单独解决 `pt_12.6875`。当前证据更支持“外层优化方向与分支选择共同限制 A1 困难点”，而不是单一阻尼参数问题。

## 下一步计划

1. 将末端位置专用步改为停滞后备策略，而不是默认主策略。
2. 引入分支候选池，从历史成功点、相邻成功点和反向遍历中选择可回环验证的候选。
3. 对 `pt_12` 和 `pt_12.6875` 做分支一致性验证，区分局部优化失败和疑似可达边界。
