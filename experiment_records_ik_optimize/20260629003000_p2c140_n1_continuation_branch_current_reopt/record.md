# P2c140 单点中段 continuation 分支电流扰动重求解

## 实验目的

P2c139 恢复出一个可重复的 n1 continuation 分支，但该分支与 direct_oracle 分支不同。本轮只在该分支内做小电流扰动重求解，判断其是否满足局部线性化、分支漂移和物理门禁。

## 实验方案

以 P2c139 的 `cont_fine` 终态作为基准状态。选取四个电流方向：基准电流方向、线圈 5、线圈 6、固定随机方向。扰动半径为 `1e-5, 3e-5, 1e-4 A`。同一方向上使用最小半径的真实位移作为经验线性模型，外推到更大半径，并计算相对误差。

## 结果

- base_current_direction：通过 0/3；最大通过半径 None A；最大线性误差 6.613e-03；最大分支漂移 2.658e-08 m；类别 不可发布。
- coil5_positive：通过 0/3；最大通过半径 None A；最大线性误差 1.167e+00；最大分支漂移 2.086e-08 m；类别 不可发布。
- coil6_positive：通过 0/3；最大通过半径 None A；最大线性误差 9.130e-01；最大分支漂移 4.912e-08 m；类别 不可发布。
- random_direction：通过 0/3；最大通过半径 None A；最大线性误差 1.191e+00；最大分支漂移 1.261e-08 m；类别 不可发布。

## 结论

发布状态：not_publishable。本轮所有方向的末端位移均低于可靠判读阈值 `1e-10 m`，因此不能形成可发布灵敏度。物理门禁和分支漂移虽然稳定，但输出信号过小，局部导数在当前数值精度下不可可靠辨识。

## 下一步计划

下一步应维持 P2c138 的 n1 不可发布边界；若继续 n1，应更换工作点、增大可观测位移或改变磁化配置，而不是在当前点继续扰动扫描。
