# P2-lite 控制通道门禁实现记录

## 一、实验目的

本轮工作面向 A1/A2 有监督逆运动学的 P2-lite 阶段，目标是把 P1 清洁复审得到的“通道可信性”从人工报告结论转化为外层逆运动学求解器的程序门禁。

具体目标如下：

1. 未提供通道审计表时保持旧流程兼容。
2. 提供通道审计表时，只允许通过审计的控制通道参与外层步长求解。
3. 对未审计、证据不足或审计失败的通道默认失败关闭。
4. 在每一步候选评估中记录实际启用通道、屏蔽通道和屏蔽原因。
5. 为后续 A1 三点回归提供可复用的命令行入口。

## 二、实验方案

新增 `inverse_kinematics/ik_control_gate.py`，负责解析通道分类表。分类表来自：

`experiment_records_ik_optimize/20260713203859_p1_clean_failed_channel_reaudit/channel_gate_classification.csv`

门禁规则如下：

1. `可生产使用` 通道允许进入外层更新。
2. `可有限使用` 通道默认允许进入外层更新，但可通过参数关闭。
3. 其他分类默认屏蔽。
4. 未审计通道按 `missing_policy` 处理，默认 `block_all`。
5. 未传入审计表时保持旧行为，即允许所有通道。

主求解器 `inverse_kinematics/ik_multisite_lm_opt.py` 的线性步长求解从完整控制空间改为允许通道子空间。对于 8 路电流和 1 个推进量组成的九维控制向量，只在允许通道对应列上求解步长，被屏蔽通道步长固定为零。

正式实验脚本 `DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py` 新增通道门禁参数，并按 `A1_pt13` 这类键将审计表传入每个点的求解器。

## 四、实验结果

语法检查通过。`evolution_of_mcrs` 环境中未安装 `pytest`，因此本轮使用直接断言方式验证门禁逻辑。

真实复审 CSV 的解析结果为：

| 键 | 允许通道 | 屏蔽通道 | 匹配行数 |
|---|---|---|---:|
| A1_pt13 | x | I0, I1, I2, I3, I4, I5, I6, I7 | 12 |
| A2_pt17 | I4, x | I0, I1, I2, I3, I5, I6, I7 | 8 |
| A2_pt05 | x | I0, I1, I2, I3, I4, I5, I6, I7 | 12 |
| A1_pt01 | 无 | I0, I1, I2, I3, I4, I5, I6, I7, x | 0 |

该结果符合当前证据口径：A1-pt13 的问题电流通道不能进入生产更新；未审计点在默认失败关闭策略下不会被误放行。

随后运行了一组真实 IK 小烟测：

`DELIVER_TO_EXP/formal_experiments/20260713220437_A1_A2_5mm_supervised_IK_no_gravity/`

该烟测使用 A1、`pt13`、无重力、5 mm 阈值、外层最多 3 次迭代，并启用通道审计表。运行结果如下：

| 指标 | 数值 |
|---|---:|
| 初始真实末端误差 | 108.852 mm |
| 最终真实末端误差 | 100.708 mm |
| 外层接受次数 | 3 |
| 电流最大变化 | 0 A |
| 推进量变化 | 0.103000 m 到 0.071917 m |
| FK 状态 | GOOD |
| 单点墙钟时间 | 98.3 s |

历史记录显示，每一步均只启用推进量 `x`，8 路电流全部被屏蔽，`dI_max_abs=0` 且 `dI_norm=0`。因此，本轮真实烟测证明程序门禁确实生效。

## 五、数据分析

本轮实现解决的是程序门禁问题，而不是灵敏度公式本身。其主要作用是防止已知不可靠的电流通道继续污染外层优化器。

需要注意的是，默认 `block_all` 策略对未审计点较严格。例如 A1-pt01 由于当前清洁复审表中没有对应行，会被全部屏蔽。因此后续 A1 三点回归有两种选择：

1. 只对已审计代表点启用严格门禁，对未审计点暂不传入门禁表。
2. 先补齐 A1-pt01 和 A1-pt12 的通道审计，再统一启用严格门禁。

从证据闭环角度看，第二种方案更严谨；从工程推进角度看，第一种方案可用于小规模对照，但不能作为最终交付结论。

A1-pt13 烟测同时说明，单独依靠推进量只能让该点误差从约 109 mm 降至约 101 mm，远不能进入 5 mm 阈值。这不是门禁失败，而是说明现有审计表过于严格时，A1-pt13 的可用控制维数不足。后续必须补充或修复电流通道灵敏度，不能把“只用推进量”的结果当作可交付策略。

## 六、实验结论

P2-lite 的第一项基础能力已经完成：外层 IK 支持机器可读通道门禁，并能在允许通道子空间中求解步长。该修改没有改变 FK 物理模型、网格、容差、真实末端定义和控制边界。

本轮尚未证明 A1/A2 成功率改善。A1-pt13 烟测证明门禁机制有效，但也证明当前可用通道过少，不能单独达到目标。

## 七、下一步计划

1. 补齐 A1-pt01 和 A1-pt12 的通道审计，或明确将其作为未门禁对照点。
2. 对 A1-pt13 的电流 3、4 以外通道做补充审计，判断是否存在可安全放行的电流方向。
3. 对已超限的 A1-pt13 电流 3、4 做定向公式复核，重点检查电流到磁场、磁场到力矩、无量纲尺度和真实末端链式偏导。
4. 完成 A1 三点回归，并输出误差曲线、电流/推进曲线、启用通道表和最终姿态图。
5. 若 A1-pt13 仍停滞，进入聚焦分支与初值诊断；若 A1-pt01 退化，优先修复外层更新策略。
