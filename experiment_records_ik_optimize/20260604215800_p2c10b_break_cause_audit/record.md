# P2c10b 可线性化断裂归因审计实验记录

## 实验目的

P2c10a 已将可线性化断裂区间收缩到 `0.20 < alpha <= 0.25`。本轮实验进一步分析断裂原因：判断一阶最优性残差突增主要来自末端任务约束、末端边界条件、段间连续性，还是分支保持项。

这里的一阶最优性残差定义为：

```text
g = J^T r
```

其中，`r` 为总残差，`J` 为总残差对打靶状态变量的雅可比矩阵。若 `||g||` 很大，则当前点不接近稳定驻点，不能发布任务敏感度。

## 实验方案

比较两个点：

- `alpha=0.20`：P2c10a 判定为最后安全点；
- `alpha=0.25`：P2c10a 判定为第一个断裂点。

总残差被分解为五类：

1. 末端位置残差；
2. 末端姿态残差；
3. 末端边界残差；
4. 分支保持残差；
5. 段间连续残差。

对每一类残差，分别计算：

```text
g_i = J_i^T r_i
```

其中，`r_i` 为第 `i` 类残差，`J_i` 为该残差块对打靶状态变量的雅可比矩阵。若某一类 `||g_i||` 很大并且与总 `g` 方向一致，则说明该残差块是当前不可线性化的主导来源。

## 数据分析

本轮结果揭示了断裂机制的关键特征。

在 `alpha=0.20`，各残差块的一阶最优性贡献并不小，但它们在方向上存在显著抵消。末端姿态残差、末端位置残差和段间连续残差贡献方向与总方向相反，末端边界残差贡献方向与总方向相同。由于这些贡献彼此抵消，总一阶最优性残差最终仅为 `7.81e-06`。

这说明 `alpha=0.20` 虽然通过门禁，但其稳定性来自多项力学与数值约束之间的精细平衡，并不是各残差块都独立很小。

在 `alpha=0.25`，该抵消结构失效。末端位置残差和末端边界残差同时沿总一阶最优性方向增长，其中：

- 末端位置残差贡献范数为 `11.80`；
- 末端边界残差贡献范数为 `8.28`；
- 二者合计主导了一阶最优性退化。

相反，段间连续残差贡献范数仅为 `0.191`，且方向与总一阶最优性残差相反。因此，在本轮证据下，断裂的直接主因不是段间连续残差本身，而是末端任务约束与末端物理边界条件之间出现了强冲突。

结合 P2c9e 的刚段耦合审计，当前刚性磁体段位姿传播不显式依赖外部磁力和磁矩。该现象提示：末端任务要求和末端边界条件之所以在 `alpha=0.25` 后冲突，可能与刚性磁体段载荷向末端位姿传播不足有关。也就是说，模型可以通过内部打靶状态拟合末端几何，但无法同时形成与磁载传播相容的末端边界状态。

## 实验结论

1. `alpha=0.25` 的可线性化断裂主要表现为一阶最优性退化。
2. 直接主导项是末端位置残差和末端边界残差，不是段间连续残差。
3. 分支保持残差几乎不贡献一阶最优性退化，因此当前问题不是正则项主导。
4. 段间连续残差不是当前断裂的直接主导项，但其与其他项存在抵消关系，后续仍需作为物理一致性约束审查。
5. 结合刚段耦合审计，下一步应优先检查“刚性磁体段载荷到末端位姿传播不足”这一模型机制。

## 工程建议

在当前模型未修复前：

- 不应在 `alpha >= 0.25` 区间发布任务敏感度；
- 不应仅凭末端残差较小判定工况可用；
- 不宜继续扩大 `n3_mixed_rand20` 终点的普通参数扫描；
- 应优先在 `alpha=0.20` 附近保守使用敏感度，并将 `alpha=0.25` 作为模型修复验证点。

## 下一步计划

建议进入 P2c10c：刚性磁体段载荷传播最小修复原型。

重点任务：

1. 审查刚性磁体段位姿传播函数中，外部磁力和磁矩是否只更新内力与内矩，而不更新位姿。
2. 构造最小修复原型，使刚段外载对远端位姿产生显式影响。
3. 仅在 `alpha=0.20` 和 `alpha=0.25` 附近验证，避免一开始扩展到全部工况。
4. 修复后必须回归稳定工况，确认不会破坏已有可靠敏感度。
