# P2c177 单点磁控 n1 发布边界综合

## 实验目的

当前长期目标要求：若单点磁控无法获得可发布有效子空间灵敏度，必须给出严格证据说明当前模型或配置不可发布。本轮不重跑长耗时求解，而是综合 P2c120、P2c126、P2c128-P2c132、P2c138-P2c140 和 P2c159，形成单点磁控 n1 的发布边界结论。

## 证据摘要

- P2c120：可发布数量为 `0`，主结论为当前模型不可发布。
- P2c126：主失败机制为 `刚性磁体段载荷传播失配与模型耦合缺失`。
- P2c128：只读载荷观测中连续残差为 `6.188e-03`，超过 `1e-3` 门限。
- P2c129：显式刚段载荷残差最小原型通过数为 `0`。
- P2c130：任务降维和保守工作点通过数为 `0`。
- P2c131：配置扫描仅得到 `1` 个基线候选，但未形成可发布灵敏度。
- P2c132：中间分支一致性状态为 `未通过`。
- P2c138：有效子空间发布状态为 `not_publishable`。
- P2c139：虽出现分支条件下恢复，但标记为 `True`，不能视为全局可信。
- P2c140：连续分支电流重求解状态为 `not_publishable`。
- P2c159：工程边界状态为 `n1_current_model_not_publishable`。

## 失败机制

单点磁控当前不是“缺少某个合适扰动半径”的问题，而是模型闭合链路未通过。主失败机制包括：

1. 刚性磁体段载荷传播失配。
2. 条件数病态。
3. 初始化敏感和多平衡竞争。
4. 任务降维后仍不能稳定闭合。
5. 分支条件下证据不足，不能推广为可发布灵敏度。

## 实验结论

单点磁控 n1 当前模型不发布末端位置灵敏度，不发布完整末端位姿灵敏度，不接入外层 IK。它只能用于模型失配分析、分支恢复方法验证、刚性磁体段载荷传播修复对照和工作空间不可发布边界说明。

## 工程建议

1. 不再对当前 n1 模型做批量扰动扫描。
2. 下一步若继续 n1，必须先显式修复刚性磁体段载荷传播模型。
3. 修复后先做基线门禁，再考虑有效子空间灵敏度。
4. 若修复后仍失败，应把单点磁控当前配置列为不可发布配置，而不是继续调权重。
