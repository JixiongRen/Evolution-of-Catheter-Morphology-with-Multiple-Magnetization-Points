# P2c188 两点磁控稳态缓存回放隐藏开销归因

## 实验目的

P2c187 证明预热后稳态回放保持 `40/40` 通过，稳态总耗时约 `53.53 s`。但稳态重求解净耗时只有 `0.91 s`。本轮不重跑求解，而是基于 P2c187 的行级计时数据，归因稳态门禁中的隐藏耗时。

## 数据分析

稳态门禁总耗时为 `53.28 s`，其中优化器记录的净重求解时间为 `0.9053 s`，隐藏门禁开销为 `52.38 s`，占 `98.30%`。这说明即使完成编译预热，当前效率瓶颈仍主要来自 `solve_reduced` 外部的残差预评估、输出评估、返回分支检查、Python 循环和 JAX 调度，而不是最小二乘迭代本身。

## 结论

稳态门禁已经可靠，但门禁耗时主要不在优化器计入的净重求解时间内；下一步应优化 solve_reduced 外部的残差预评估、输出评估和 Python 循环。

## 下一步计划

1. 将 `solve_reduced` 中残差预评估纳入计时，避免低估单次重求解真实成本。
2. 将正负扰动、多初值和回环检查中的输出评估批量化。
3. 先验证多初值解在数值上一致后，再考虑减少重复回环求解。
4. GPU 后端恢复前，当前耗时只能视为 CPU 保守参考。
