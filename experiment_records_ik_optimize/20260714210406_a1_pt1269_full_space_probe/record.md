# A1 pt12.6875 完整控制空间探针记录

## 实验目的

本实验用于判断 `pt_12.6875` 平台误差是否由可靠子空间投影过窄导致。实验关闭可靠子空间，允许外层优化器在全部 8 路电流和推进量组成的控制空间内更新。

## 实验条件

- 导管配置：A1，单点轴向磁化。
- 物理设置：无重力，`M_list=5`，FK 容差 `1e-5`。
- 控制边界：电流 `[-20, 20] A`，推进量 `[0.003001, 0.203] m`。
- 目标点：`pt_12.6875`。
- 初始状态：使用 `pt_12.75` 成功状态作为热启动。
- 外层策略：可靠子空间关闭，真实末端误差优先，阻尼保持开启，停滞救援上限为 2 次。
- 运行环境：`JAX_PLATFORMS=cuda`，`XLA_PYTHON_CLIENT_PREALLOCATE=false`。

## 实验结果

| 指标 | 数值 |
|---|---:|
| 最终真实末端误差 | `5.588 mm` |
| 是否进入 5 mm | 否 |
| 终止原因 | 有效步长低于阈值 |
| 接受/拒绝次数 | `10 / 67` |
| 墙钟时间 | `527.9 s` |
| FK 平衡分类 | `GOOD` |

## 数据分析

关闭可靠子空间后，误差仅从约 `5.594 mm` 降到约 `5.588 mm`，改善幅度很小。外层仍在高阻尼和连续拒绝后进入步长塌缩。该结果说明可靠子空间不是主要瓶颈，至少不是唯一瓶颈。

## 实验结论

完整控制空间更新没有解决 `pt_12.6875` 的平台问题。后续应检查综合目标中的正则项是否使更新方向偏离真实末端误差下降方向。

## 下一步计划

尝试只使用真实末端位置残差构造外层步长，判断正则项对末端收敛的影响。
