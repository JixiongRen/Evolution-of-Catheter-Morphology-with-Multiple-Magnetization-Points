# P2c33 多加载程度严格复核口径审计

## 实验目的

P2c32 建议用 P2c30/P2c31 的严格复核流程重新扫描多个 `alpha`，以消除 P2c16 与 P2c30/P2c31 的实验口径差异。本轮先审计该操作能否直接执行，避免在无人值守阶段把不同目标定义、不同初值来源和不同求解策略混合为同一结论。

## 审计对象

- P2c16：可构造不同 `alpha` 的目标与初值，但使用的是较早的单策略求解与相图流程。
- P2c30/P2c31：使用严格多策略精修和扰动后重求解，但当前加载器依赖 P2c22 保存的目标与初值。
- P2c22：目前仅为 `n3_mixed_rand20, alpha=0.40` 保存了 P2c30/P2c31 所需状态。

## 审计结果

候选扫描点为：

```text
alpha = 0.375, 0.400, 0.425, 0.450
eps = 0.005, 0.010, 0.0125
```

审计结果显示，P2c30/P2c31 当前加载器不能直接用于多 `alpha` 扫描。P2c22 保存状态的可用性如下：

| alpha | 是否存在 P2c22 保存目标与初值 | 是否可直接使用 P2c30/P2c31 |
|---:|---|---|
| `0.375` | 否 | 否 |
| `0.400` | 是 | 是 |
| `0.425` | 否 | 否 |
| `0.450` | 否 | 否 |

因此，若现在直接运行 P2c30/P2c31 的多 `alpha` 版本，只有 `alpha=0.40` 是严格合法的；其余点会因为缺少同口径目标和初值而产生目标定义漂移。

本轮输出文件包括：

- `alpha_state_availability.csv`：各加载点目标与初值状态可用性。
- `recommended_strict_alpha_eps_grid.csv`：下一轮建议扫描网格。
- `failure_events.jsonl`：阻止直接运行的口径问题。
- `summary.json`：审计结论摘要。

## 数学与物理影响

敏感度定义依赖同一个任务映射：

$$
\Phi(\alpha)=p_{\mathrm{tip}}(y^\ast(\alpha),I(\alpha)).
$$

如果不同 `alpha` 的 \(p_{\mathrm{target}}\)、初值来源和求解策略不一致，则差分计算得到的量不再是同一映射 \(\Phi\) 的局部导数，而是混合了以下因素：

1. 目标点构造方式变化。
2. 初始分支选择变化。
3. 求解器精修策略变化。
4. 扰动后重求解是否落在同一形态分支上的差异。

这会导致一个严重问题：即使数值上能得到灵敏度向量，也不能判断它对应真实物理响应、目标定义漂移，还是求解分支切换。因此，在缺少统一目标与初值状态前，跨 `alpha` 严格复核不能作为论文级证据发布。

从物理角度看，`alpha` 改变意味着刚性磁体段所受磁力和磁矩幅值同时改变。如果目标点和初值也随实验路径非受控变化，则无法区分“磁载荷传播导致的灵敏度变化”和“求解器进入另一条平衡分支导致的变化”。这正是当前长期目标要求避免的证据污染。

## 实验结论

本轮结论如下：

- 已验证结论：P2c30/P2c31 当前只能严格支持 `n3_mixed_rand20, alpha=0.40`。
- 已验证结论：`alpha=0.375, 0.425, 0.450` 缺少同口径保存目标与初值，不能直接进入严格复核。
- 已验证结论：P2c16 的加载相图和 P2c30/P2c31 的扰动半径边界目前只能作为互补证据，不能合并为同一统计口径下的相图。
- 待验证假设：若为每个 `alpha` 重新生成统一目标与初值，并接入 P2c27/P2c29 的严格多策略精修，则可以得到真正同口径的加载程度-扰动半径相图。

因此，下一步不应直接长时间重跑多 `alpha` 敏感度，而应先实现统一目标与初值生成层。

## 下一步计划

下一轮应开发 `P2c34`，目标是建立“任意 alpha 的严格复核前处理层”：

1. 对每个候选 `alpha` 生成并保存 canonical target 和初始状态。
2. 统一记录目标点、末端位姿、中心线、初值来源和随机种子。
3. 将 P2c27/P2c29 的严格多策略精修接入 P2c16/P2c10w 的任意 `alpha` 目标路径。
4. 完成后再运行 `alpha={0.375,0.400,0.425,0.450}` 与 `eps={0.005,0.010,0.0125}` 的严格复核网格。

工程建议：在 P2c34 完成前，不要把 `alpha=0.40-0.425` 称为同口径可信窗口，只能称为“已有证据提示的候选可信窗口”。真正可发布结论必须等待统一口径复核。
