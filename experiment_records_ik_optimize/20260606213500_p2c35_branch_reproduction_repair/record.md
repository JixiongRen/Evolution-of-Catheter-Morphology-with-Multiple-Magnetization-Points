# P2c35 多初值分支复现修正

## 实验目的

P2c34 表明，统一目标与初值生成层能够生成多个 `alpha` 的状态，但 `alpha=0.400` 和 `alpha=0.425` 在该路径下未通过静态门禁。本轮检查这些失败是否来自物理不可行，还是来自初值分支选择。

## 实验方案

本轮只处理两个异常加载点：

```text
alpha = 0.400, 0.425
```

对每个加载点保留多个候选分支，并分别进行严格多策略精修。候选初值包括：

- 当前目标路径的 oracle 初值。
- 零初值。
- P2c34 生成的 canonical 初值。
- `alpha=0.400` 的 P2c22 历史可信初值。
- `alpha=0.425` 的 P2c16 历史分支。
- `alpha=0.425` 的 `0.450 -> 0.425` 反向延拓分支。

## 判定标准

- 末端位置误差不超过导管长度的 `5%`。
- 一阶最优性残差不超过 `1e-5`。
- 雅可比矩阵条件数不超过 `1e10`。
- 界面松弛力与刚段外力比例不超过 `2`。
- 同一 `alpha` 下保留候选分支中心线差异，判断是否存在多解竞争。

## 实验结果

本轮实验总墙钟时间为 `174.31 s`，共评估 10 个候选分支，其中 3 个通过静态门禁。

## 数据分析

本轮实验证明，P2c34 中 `alpha=0.400` 与 `alpha=0.425` 的失败不能解释为物理不可行，而应解释为分支初始化不足。

对于 `alpha=0.400`，P2c22 保存的历史可信状态能够恢复 P2c30/P2c31 中的可信分支：一阶最优性残差为 `1.86e-8`，界面松弛力与刚段外力比例为 `0.069`。相比之下，P2c34 canonical 分支虽然一阶最优性残差也不高，但载荷传播比例为 `3.204`，说明该分支依赖非物理界面松弛通道。

对于 `alpha=0.425`，P2c16 历史分支和 `0.450 -> 0.425` 反向延拓分支均能恢复可信状态，载荷传播比例约为 `0.0286`。但 oracle、zero 和 P2c34 canonical 初值会落入另一类几何接近但载荷传播失配的分支，其界面松弛力与刚段外力比例约为 `4.6-5.9`。这说明 `alpha=0.425` 附近至少存在两类局部解：一类物理闭合，另一类几何接近但载荷传播不闭合。

中心线差异进一步支持多分支解释。同一 `alpha` 下候选分支之间的最大中心线均方根差异达到 `1e-2 m` 到 `4e-2 m` 量级，远大于此前分支一致性门限 `1e-3 m`。因此，这不是普通收敛误差，而是不同平衡分支之间的差异。

数学上，当前问题不能简单写成单值映射：

$$
\Phi(\alpha)=p_{\mathrm{tip}}(y^\ast(\alpha),I(\alpha)).
$$

更准确的形式是多分支映射：

$$
\Phi_i(\alpha)=p_{\mathrm{tip}}(y_i^\ast(\alpha),I(\alpha)),
\quad i=1,2,\dots
$$

只有当扰动前后保持同一分支 \(i\) 时，\(\partial \Phi_i/\partial \alpha\) 才能解释为有效任务敏感度。若求解器在不同初值下进入不同分支，则不同分支之间的差分不能作为灵敏度发布。

## 实验结论

本轮结论如下：

- 已验证结论：`alpha=0.400` 的可信分支可由 P2c22 历史可信初值复现。
- 已验证结论：`alpha=0.425` 的可信分支可由 P2c16 历史分支和 `0.450 -> 0.425` 反向延拓复现。
- 已验证结论：P2c34 的失败主要来自分支初始化不充分，而不是物理模型在这些点不可求解。
- 已验证结论：`alpha=0.400` 与 `alpha=0.425` 均存在多分支竞争，且非可信分支可能仍具有较小末端位置误差。
- 待验证假设：只要在敏感度复核中固定可信分支并使用分支漂移门禁，`alpha=0.400` 与 `alpha=0.425` 可以进入后续严格 `eps` 复核。

因此，P2c35 修复了 P2c34 暴露出的关键口径问题：后续不能只保存单个 canonical 状态，而应保存“候选分支集合”和对应门禁分类。

## 下一步计划

下一轮建议开展 `P2c36`，在已复现的可信分支上进行严格敏感度复核：

1. `alpha=0.400` 使用 `p2c22_saved_trusted_seed` 分支。
2. `alpha=0.425` 使用 `p2c16_historical_base_seed` 或 `reverse_from_alpha_0.450_seed` 分支。
3. 对每个可信分支测试 `eps=0.005, 0.010, 0.0125`。
4. 扰动后重求解必须以同一可信分支为初值，并检查中心线是否仍留在该分支附近。
5. 若某个 `eps` 导致中心线漂移超过 `1e-3 m`，则只标记为分支漂移诊断样本，不发布敏感度。

工程建议：外层逆运动学不应只维护一个当前解，还应维护分支身份。对于多磁体强电流工况，每次线性化前必须确认当前状态属于物理闭合分支，而不是几何近似但载荷传播失配的分支。
