# P2c10f 工程建议摘要

## 结论等级

本轮结论属于“可行分支与任务分支分离证据”。可行性优先流程没有恢复可发布敏感度，但证明困难点并非完全没有物理可行状态，而是物理可行状态与目标末端位姿难以同时满足。

## 失败类别

| 类别 | 证据 | 判断 |
|---|---|---|
| 可达域受限 | 纯物理可行层任务残差很大，加入任务后连续性迅速恶化 | 主要机制 |
| 一阶最优性退化 | 所有阶段一阶最优性残差均远高于门禁 | 严重，禁止发布敏感度 |
| 段间连续性冲突 | 任务强度增大时段间连续残差由 `6.647e-05` 升至 `0.190371` | 明确存在 |
| 多分支竞争 | 物理可行分支和任务拟合分支表现出不同趋势 | 高度可疑 |

## 工作空间建议

- `alpha <= 0.20`：仍可作为当前模型下的暂定可信区，但需要继续回归稳定工况。
- `0.20 < alpha <= 0.25`：建议归类为可达域边界诊断区，不发布任务敏感度。
- `alpha > 0.25`：在物理可行流形距离测量完成前，建议视为高风险区。

## 导管构型建议

- 三段混合磁化构型在当前电流方向下会诱发物理可行分支与目标任务分支分离。
- 若工程目标是获得稳定敏感度，应优先选用磁化方向变化较平滑、段间载荷冲突较弱的构型。
- 若必须使用三段混合磁化，应在控制器中加入可行性门禁，而不是只使用末端误差门禁。

## 线圈电流建议

- 对接近 `n3_mixed_rand20` 的电流方向，应采用增载路径限制。
- 当前保守限幅仍建议取 `alpha <= 0.20`。
- 对 `0.20 < alpha <= 0.25` 的操作，必须同时监测段间连续残差、末端边界残差和一阶最优性残差。

## 下一步建议

停止在相同局部权重空间中继续扫描。下一轮应测量目标末端位姿到物理可行流形的距离，并将该距离作为工作空间边界和电流限幅的直接依据。
