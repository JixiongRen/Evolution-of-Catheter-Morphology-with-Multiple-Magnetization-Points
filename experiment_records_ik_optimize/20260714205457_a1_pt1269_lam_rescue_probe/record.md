# A1 pt12.6875 阻尼保持与停滞救援探针记录

## 实验目的

本实验用于验证外层优化器在 `pt_12.6875` 附近的失败是否主要由阻尼持续增大造成。上一轮细分延拓显示该点误差为 `5.593 mm`，距离 `5 mm` 阈值很近，但最终因有效步长低于阈值停止。

## 实验条件

- 导管配置：A1，单点轴向磁化。
- 物理设置：无重力，`M_list=5`，FK 容差 `1e-5`。
- 控制边界：电流 `[-20, 20] A`，推进量 `[0.003001, 0.203] m`。
- 目标点：`pt_12.6875`。
- 初始状态：使用 `pt_12.75` 成功状态作为热启动。
- 外层策略：可靠子空间开启，真实末端误差优先，阻尼保持开启，停滞救援上限为 2 次。
- 运行环境：`JAX_PLATFORMS=cuda`，`XLA_PYTHON_CLIENT_PREALLOCATE=false`。

## 实验结果

| 指标 | 数值 |
|---|---:|
| 最终真实末端误差 | `5.594 mm` |
| 是否进入 5 mm | 否 |
| 终止原因 | 最大外层迭代数 |
| 接受/拒绝次数 | `18 / 64` |
| 墙钟时间 | `463.7 s` |
| FK 平衡分类 | `GOOD` |

## 数据分析

阻尼保持避免了过早的步长塌缩，终止原因从“有效步长低于阈值”变为“最大外层迭代数”。但是误差几乎没有改善，仍停留在约 `5.59 mm`。这说明高阻尼是失败表象之一，但不是唯一根因。

## 实验结论

仅靠阻尼保持和有限停滞救援不能使该点进入 `5 mm`。后续应检查可靠子空间是否限制了有效控制方向，以及综合目标中的正则项是否牵制了末端误差下降。

## 下一步计划

关闭可靠子空间，检查完整控制空间更新是否能降低该平台误差。
