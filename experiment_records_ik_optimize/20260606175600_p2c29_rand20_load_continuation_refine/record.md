# P2c29 随机强电流三磁体工况逐级增载基线精修实验

## 实验目的

P2c28 表明 `n3_mixed_rand20, alpha=0.4` 的扰动分支具有较好的局部线性化和载荷传播表现，但基线一阶最优性严重退化。本实验检验逐级增载和初值选择是否能修复基线状态，从而判断该工况是否具备转化为可发布敏感度样本的潜力。

## 实验方案

固定末端目标为 P2c22 中 `alpha=0.4` 保存的目标点。比较四种基线求解路径：

1. `direct_saved`：直接从保存状态求解 `alpha=0.4`。
2. `direct_zero`：直接从零状态求解 `alpha=0.4`。
3. `homotopy_saved`：从保存状态出发，按 `alpha=0.1,0.2,0.3,0.4` 逐级增载。
4. `homotopy_zero`：从零状态出发，按同样路径逐级增载。

每一级均使用多策略精修，并以物理门限选择最优解。

## 判定标准

最终 `alpha=0.4` 基线必须通过静态门限；若通过，再检查 `eps=0.01` 的扰动重求解门禁。

## 实验结果

正式运行总墙钟时间为 `164.98 s`。四条基线路径中，`direct_saved` 成功通过静态门限，并进一步通过 `eps=0.01` 扰动重求解敏感度门禁。

最终候选对比如下：

| 候选路径 | 是否通过静态门限 | 末端位置误差 | 一阶最优性残差 | 物理条件数 | 界面力松弛/刚段外力 |
|---|---|---:|---:|---:|---:|
| `direct_saved` | 是 | `6.66e-7 m` | `1.86e-8` | `1.73e6` | `0.069` |
| `direct_zero` | 否 | `5.16e-5 m` | `1.22e-4` | `9.91e7` | `3.20` |
| `homotopy_saved` | 否 | `9.15e-3 m` | `4.12e3` | `1.08e7` | `57.04` |
| `homotopy_zero` | 否 | `1.44e-2 m` | `1.39e3` | `1.65e7` | `28.82` |

最佳路径为 `direct_saved`，即从 P2c22 保存状态出发，直接在 `alpha=0.4` 处使用严格信赖域重启精修。其扰动敏感度审计结果如下：

| 指标 | 数值 |
|---|---:|
| 是否可发布 | 是 |
| 敏感度范数 | `3.60e-5 m/alpha` |
| 敏感度向量 | `[3.54e-5, 6.50e-6, -1.11e-6]` |
| 最大线性化误差 | `1.75e-6` |
| 最大扰动一阶最优性 | `3.55e-7` |
| 最大界面力松弛/刚段外力 | `0.099` |
| 最大轴线分支漂移 | `7.35e-4 m` |

## 数据分析

1. P2c28 中 `n3_mixed_rand20` 的失败主因被确认是基线精修不足，而不是局部不可线性化。P2c28 的基线一阶最优性为 `2.08`，本轮 `direct_saved` 精修后降至 `1.86e-8`，改善约 8 个数量级。

2. 该工况扰动分支保持可线性化。扰动敏感度门禁中最大线性化误差为 `1.75e-6`，远低于 `0.05`；扰动后一阶最优性为 `3.55e-7`，也低于 `1e-5`。

3. 载荷传播没有失配。最佳基线的界面力松弛与刚段外力比值为 `0.069`，扰动后最大值为 `0.099`。因此该工况的失败机制与 `n1_tip_z_rand15`、`n2_z_pair_rand12` 不同，不属于刚性磁体段载荷传播失配。

4. 逐级增载路径失败。`homotopy_saved` 和 `homotopy_zero` 在 `alpha=0.4` 处均出现严重一阶最优性退化和载荷传播异常。这说明本实验采用的“固定 alpha=0.4 末端目标、低 alpha 逐级推进”不是合适的同伦路径；低 alpha 阶段虽然可拟合目标，但会把状态推入不适合高 alpha 的非物理或不良吸引域。

5. 初值选择仍然重要。`direct_zero` 未通过门限，表现为载荷传播失配和一阶最优性不足；`direct_saved` 成功。这说明 P2c22 保存状态虽然此前未充分精修，但仍包含正确物理分支信息。

## 实验结论

P2c29 将 `n3_mixed_rand20, alpha=0.4` 从诊断结果推进为可发布的局部任务敏感度样本。

已验证结论：

- `n3_mixed_rand20, alpha=0.4` 在保存状态分支上可以获得高置信局部末端位置敏感度。
- 该工况不属于载荷传播失配；主要问题是基线精修策略不足。
- 固定目标下的逐级增载不是有效修复路径，甚至会诱导到不良分支。

适用范围：

- 当前结论只适用于 `n3_mixed_rand20, alpha=0.4, eps=0.01` 附近。
- 当前任务仍为末端位置任务，不包含完整末端姿态敏感度。
- FK 仍只作为目标来源之一，不作为唯一真值。

## 下一步计划

下一轮建议开展 `P2c30`：

1. 将 `direct_saved + trf_strict_restart` 加入统一审计流程，作为强电流三磁体工况的默认基线精修候选。
2. 对 `n3_mixed_rand20` 做 `eps=0.005,0.01,0.02` 多扰动幅值复核，确认敏感度在更宽局部邻域内稳定。
3. 对 `n1_tip_z_rand15` 与 `n2_z_pair_rand12` 暂停优化器调参，转向硬界面连续性或载荷传播重参数化。
