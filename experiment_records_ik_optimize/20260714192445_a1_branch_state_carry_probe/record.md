# A1 分支状态继承反向延拓验证记录

## 实验目的

上一轮实验表明，单独复用历史控制量无法稳定复现 A1 部分历史好解。本轮实验修正相邻点热启动逻辑：当一个目标点成功时，后续目标不仅继承其电流和推进量，也继承其 FK 平衡状态。随后使用 `pt_13 -> pt_12` 的反向延拓验证，判断邻近成功分支能否帮助 `pt_12` 回到 `5 mm` 阈值内。

## 代码修改

修改文件：

`DELIVER_TO_EXP/run_a1_axial_circle_formal_experiment.py`

修改内容：

- 原逻辑：相邻点热启动只继承成功点的电流和推进量。
- 新逻辑：相邻点热启动同时继承成功点的分支状态文件。
- 目的：让“热启动”真正携带 FK 平衡分支信息，避免每个目标重新落入不同平衡分支。

## 实验条件

- 导管配置：A1，单点轴向磁化。
- 目标顺序：`pt_13 -> pt_12`。
- `pt_13` 初值：来自历史分支状态登记表。
- `pt_12` 初值：继承 `pt_13` 成功后的控制量和 FK 平衡状态。
- 重力：关闭。
- 离散化：`M_list=5`。
- FK 容差：`1e-5`。
- 成功阈值：真实刚性末端误差不超过 `5 mm`。
- 运行设备：GPU，`NVIDIA GeForce RTX 5060 Laptop GPU`。

## 结果分析

`pt_13` 的分支状态可以稳定重放，说明登记表中的 `pt_13` 分支状态本身有效。但是，当该分支状态用于反向延拓到 `pt_12` 时，`pt_12` 仍未收敛。这说明 `pt_12` 的失败不能简单归因于“上一版代码没有继承分支状态”。

当前证据更支持以下判断：

1. `pt_12` 附近可能存在明显的平衡分支断裂或分支吸引域很窄。
2. 现有外层线性化方向在该区域不稳定，无法把成功分支连续推进到目标点。
3. 单纯增加迭代次数不一定有效，因为本轮表现为超时和拒绝停滞。

## 后续任务

1. 将 `pt_12` 标记为 A1 重点诊断点，不再把它视为简单初值问题。
2. 对 `pt_12` 做局部灵敏度审计，尤其检查真实末端对电流和推进量的响应方向是否稳定。
3. 对 `pt_12` 进行小步长反向延拓或圆周角度分段延拓，判断是否存在可通过连续路径进入的好分支。
4. 在 A1 正式交付前，必须明确 `pt_12` 是优化器失败、分支管理失败，还是疑似局部不可达。
