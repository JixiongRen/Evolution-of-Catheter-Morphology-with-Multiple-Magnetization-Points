# P1 双选择器预注册通道灵敏度审计记录

## 一、实验目的

本轮用于补齐 P1 证据链中的两个缺口：

1. 不再只审计历史最小末端误差状态，而是同时审计 `last_accept` 和 `best_accept`。
2. 不再由被测灵敏度自动选择最大响应电流通道，而是使用预注册代表通道。

本轮仍为代表点审计，不是 A1/A2 全量回归。其目标是判断哪些灵敏度实现、哪些导管和哪些局部通道可以进入外层受限优化器。

## 二、固定条件

- 无重力。
- `M_list=5`。
- 前向运动学容差 `1e-5`。
- 电流范围 `[-20,20] A`。
- 推进范围 `[0.003001,0.203] m`。
- 真实末端定义为最后刚段远端。
- 回环末端门限 `0.25 mm`。
- 回环轴线最大误差门限 `0.5 mm`。
- 弱响应位移门限 `0.25 mm`。
- 命令显式设置 `XLA_PYTHON_CLIENT_PREALLOCATE=false` 和 `JAX_PLATFORMS=cuda`。

标准错误日志只包含 JAX 的 GPU 拓扑警告，未出现 CPU 回退、Traceback 或运行错误。

## 四、审计设置

每个代表点分别运行：

- `last_accept`：最后一次接受状态。
- `best_accept`：历史最小真实末端误差状态。

每个状态对比四类灵敏度实现：

1. 求解器响应版。
2. 去阻尼高斯-牛顿版。
3. 驻点方程版。
4. 残差空间版。

扰动步长：

- 电流：`0.25/0.125/0.0625 A`。
- 推进量：`0.5/0.25/0.125 mm`。

每个扰动样本均进行正负扰动和返回基准控制量的回环检查。

## 七、主要结果

### 7.1 残差空间版是当前唯一可信主线

残差空间版在 A1 三个代表点上的表现：

- `last_accept`：强响应中位误差约 `1.16%`，90 分位约 `2.83%`。
- `best_accept`：强响应中位误差约 `1.16%`，90 分位约 `2.83%`。

这说明在 A1 的预注册通道上，`last_accept` 和 `best_accept` 口径基本一致，且残差空间灵敏度满足 P1 门禁。

### 7.2 A2-pt17 通过，A2-pt05 和 A2-pt19 未通过

残差空间版在 A2 上的结果：

- A2-pt17：强响应中位误差约 `4.45%`，90 分位约 `6.04%`，通过门禁。
- A2-pt05：强响应中位误差约 `12.43%`，90 分位约 `12.44%`，未通过门禁。
- A2-pt19：强响应中位误差约 `12.76%`，90 分位约 `13.23%`，未通过门禁。

A2-pt05 和 A2-pt19 的 `last_accept` 与 `best_accept` 结果几乎一致，说明当前偏差不是由只选 `best_accept` 造成。

### 7.3 其他三类灵敏度实现当前不可作为生产路径

求解器响应版、去阻尼高斯-牛顿版和驻点方程版在本轮中均表现出接近 `100%` 的相对误差，方向夹角也明显偏大。该现象在 A1 和 A2 上均一致。

因此，当前不能把这三类实现作为外层优化器的生产灵敏度。它们只能作为待排查实现或公式口径的诊断对象。

### 7.4 回环失败仍是重要证据

残差空间版的不可审计样本主要来自回环失败：

- A1 三点组每个选择器有 6 个不可审计样本。
- A2-pt05 每个选择器有 4 个不可审计样本。
- A2-pt17 每个选择器有 1 个不可审计样本。
- A2-pt19 每个选择器有 1 个不可审计样本。

这些样本不能用于相对误差统计。它们说明部分大步扰动仍会离开同一平衡分支或无法满足回环门禁。

## 八、阶段结论

1. A1 代表点通过 P1 预注册通道审计，可以进入 P2 外层受限优化器代表点对照。
2. A2 尚未通过 P1。A2-pt17 可以作为通过点，A2-pt05 和 A2-pt19 必须继续收口。
3. 当前生产灵敏度只应使用残差空间版。
4. 其他三类灵敏度实现的近 `100%` 偏差需要单独排查，不能直接解释为物理导数失效。
5. P2 外层更新必须保留可靠子空间和回环门禁；对 A2-pt05 和 A2-pt19 的异常通道应降权、剔除或重新线性化后再尝试。

## 九、下一步计划

1. 将残差空间版作为 P2 代表点对照的唯一生产灵敏度。
2. 对 A1 运行六个代表点中的 A1 三点 P2 同预算对照，重点确认旧成功点不退化、真实末端误差优先接受是否有效。
3. 对 A2-pt05 和 A2-pt19 先做局部修正，不直接进入 A2 六点小回归。
4. 单独排查求解器响应版、去阻尼高斯-牛顿版和驻点方程版为什么与有限差分方向严重不一致。
5. 若 P2 对照中 A1 旧成功点不退化且失败点主因明确，再进入 A1 十点小回归。

## 十、多智能体审查状态

本轮 P1 存在门禁失败项，已按长期目标要求启动公式、实现和数值条件三路并行审查。分支方向因智能体额度限制由主线程结合回环失败样本进行补充分析。后续应将审查意见补入阶段报告或下一轮修正文档。

## 十一、多智能体审查补充结论

三路审查形成一致判断：

1. `last_accept` 与 `best_accept` 双选择器确实生效，预注册通道也确实由命令显式指定。本轮不再是只选历史最好状态和自动最大响应通道的乐观审计。
2. 基准状态重放可信。输出中真实末端重载误差和轴线最大重载误差均为 `0.0 mm`。
3. 求解器响应版、去阻尼高斯-牛顿版和驻点方程版接近 `100%` 偏差，不是由选择器或通道选择导致，而主要来自线性系统口径不一致。
4. 法方程路径把 `J^T J` 的平方谱当作 `J` 的原谱处理，同一个 `svd_rcond=1e-9` 用在两类矩阵上并不等价。它会导致有效方向被过度截断，或者在直接降低阈值后放大数值噪声。
5. 求解器响应版的语义本来是“单步求解器响应”，不应与重求解后的平衡分支导数直接比较。
6. 驻点方程版当前仍是诊断路径；在小残差条件下它数值上接近高斯-牛顿，但实现口径尚未达到可发布水平。
7. 本轮 `strong_valid` 和 `weak_valid` 的原始汇总是步长行计数，不是通道级计数。后续已修改审计脚本，使强弱响应按状态-通道统一标记。

## 十二、代码修正与小回归

根据审查意见，进行了两处最小修正：

1. `gn_svd` 在 `solve_mode=svd` 且只有近零 ridge 时，改为直接使用残差雅可比谱空间求解。这对应去阻尼高斯-牛顿灵敏度的稳定数值实现，避免显式分解 `J^T J`。
2. 审计脚本将强/弱响应标签改为状态-通道级标签，同一状态、同一控制通道在不同步长下不再被分别标为强或弱。

修正后运行了小回归：

`experiment_records_ik_optimize/20260713184928_p1_normal_equation_rcond_smoke`

小回归选择 A2-pt19 的通道 5 和推进量通道。结果显示：

- `gn_svd` 与 `residual_svd` 完全一致。
- 电流通道 5 的相对误差约 `12.76%`。
- 推进量通道相对误差约 `1.74%`。
- 求解器响应版仍显著偏离有限差分。
- 驻点方程版仍显著偏离有限差分。

因此，当前可作为生产灵敏度的模式是：

- `residual_svd`
- 修正后的 `gn_svd`，其 SVD 路径等价于残差谱高斯-牛顿实现

不应作为生产灵敏度的模式是：

- 求解器响应版
- 当前驻点方程版

## 十三、修正后的阶段判断

1. A1 的 P1 代表点证据可以进入 P2 外层受限优化器对照，但 A1-pt13 的大步回环失败仍需在 P2 中通过可靠子空间和信赖域处理。
2. A2 仍不能进入六点小回归。A2-pt05 只在最小电流扰动下可用；A2-pt19 在中小步可审计但相对误差仍略超门禁；A2-pt17 在 `0.25 A` 大步下也存在回环风险。
3. 下一步优先级应为：使用 `residual_svd` 或修正后的 `gn_svd`，对 A1 三个代表点做 P2 同预算对照；A2 暂时仅做异常通道收口，不进入正式回归。
