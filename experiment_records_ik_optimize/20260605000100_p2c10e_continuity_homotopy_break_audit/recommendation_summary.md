# P2c10e 工程建议摘要

## 结论等级

本轮结论属于“约束冲突归因证据”。段间连续性权重增大后，原始连续残差可以下降，但末端任务总残差显著升高，因此简单强化连续性罚项不能恢复困难工况敏感度。

## 失败类别

| 类别 | 证据 | 判断 |
|---|---|---|
| 段间连续性冲突 | `mu_c=1000` 时连续残差下降到 `7.992e-04`，但总残差升至 `0.026663` | 主要机制之一 |
| 一阶最优性退化 | `alpha=0.25, mu_c=1~100` 的一阶最优性残差为 `18.64~53.04` | 仍然严重 |
| 单纯权重不足 | 增大权重不能同时通过总残差和连续性门禁 | 基本排除 |
| 物理可行分支不一致 | 末端任务、边界平衡、段间连续性无法同时低残差 | 高度可疑 |

## 工作空间建议

- `alpha <= 0.20`：仍可作为当前模型的暂定可信区，但严格段间连续门禁下存在边界余量不足。
- `0.20 < alpha <= 0.25`：应标记为约束冲突诊断区，不发布敏感度。
- `alpha > 0.25`：在可行性优先流程验证前，不建议作为敏感度控制区。

## 导管构型建议

- 三段混合磁化构型在强耦合电流方向下会放大段间连续性与末端任务之间的冲突。
- 若工程目标是稳定敏感度，应优先选择磁化方向更平滑、段间磁载转移更弱的构型。
- 若必须使用混合磁化构型，应将控制目标限制在可行性门禁明确通过的局部区域。

## 线圈电流建议

- 对接近 `n3_mixed_rand20` 的方向，不能仅以末端误差小判定可控。
- 电流增载时必须同步检查末端边界残差、段间连续残差和一阶最优性残差。
- 当前建议仍将该路径的保守操作包络限制在 `alpha <= 0.20` 附近。

## 下一步建议

下一轮应改用“可行性优先”的分层打靶：先寻找满足末端边界和段间连续性的物理可行分支，再在该分支上加入末端位姿任务。若该流程仍不能恢复 `alpha=0.25`，应将该区域归类为当前模型和构型下的不可发布敏感度区域。
