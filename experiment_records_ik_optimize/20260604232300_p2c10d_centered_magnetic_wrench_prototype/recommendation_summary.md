# P2c10d 工程建议摘要

## 结论等级

本轮结论属于“失败归因证据”。中心磁载荷原型没有恢复 `alpha=0.25` 的可线性化性，因此不能作为修复方向继续扩展。

## 失败类别

| 类别 | 证据 | 判断 |
|---|---|---|
| 磁载荷作用点简化 | 中心磁载荷原型下 `alpha=0.25` 一阶最优性残差为 `27.435227`，高于原模型 | 不是主因 |
| 刚段载荷传播失配 | P2c10c 经验耦合可将一阶最优性残差降至 `0.001439` | 仍是重要嫌疑机制 |
| 段间连续性冲突 | 本轮未强化段间连续性，断裂仍存在 | 下一轮应重点审计 |
| 可达域边界 | 总残差仍较小，但一阶最优性失控 | 不能单独解释现象 |

## 工作空间建议

- `alpha <= 0.20`：仍可作为当前模型下的暂定可信区，但后续修复必须回归验证。
- `0.20 < alpha <= 0.25`：继续作为模型诊断区，不发布敏感度。
- `alpha > 0.25`：在硬连续多段打靶或更完整载荷传播模型完成前，不建议作为敏感度控制区。

## 导管构型建议

- 三段混合磁化构型在强耦合电流方向下仍应视为高风险构型。
- 若工程目标是稳定敏感度，应优先采用磁化方向变化较平滑、段间载荷传递较弱冲突的构型。
- 若保留三段混合磁化，应将其用于失效机理研究，而不是优先作为控制基准。

## 线圈电流建议

- 对接近 `n3_mixed_rand20` 的电流方向，应采用逐级增载并监测一阶最优性残差。
- 单纯降低或调整磁载作用点不足以扩大可信电流包络。
- 当前保守建议仍是将该路径限制在 `alpha <= 0.20` 附近。

## 下一步建议

停止继续做简单磁载作用点微调。下一轮应优先进入硬连续多段打靶原型，明确段间内力和内矩连续性是否是恢复困难工况敏感度的关键条件。
