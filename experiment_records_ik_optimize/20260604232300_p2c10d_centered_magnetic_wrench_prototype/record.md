# P2c10d 刚性磁体中心磁载荷传播原型实验记录

## 实验目的

本实验用于进一步缩小困难工况敏感度断裂的物理原因范围。P2c10c 的经验反事实实验显示，引入刚性磁体段载荷到末端姿态的等效耦合后，`alpha=0.25` 的一阶最优性残差由 `20.587278` 降至 `0.001439`，接近但尚未通过 `1.0e-3` 门禁。该结果提示刚性磁体段载荷传播存在重要影响，但 P2c10c 的 `beta` 仍是经验参数，不能作为物理模型。

本轮实验采用更明确的物理假设：磁力和磁矩应作用于刚性磁体中心，而不是刚段近端。随后将磁力关于刚段近端产生的力矩臂加入近端总力矩。该原型不改变刚体姿态外推关系，也不引入经验姿态增量，因此可用于检验“磁载作用点与力矩臂简化”是否足以解释断裂。

## 数学与物理表述

原有刚段传播可概括为

$$
\mathbf{x}_{r}(\sigma)=G(\mathbf{x}_{p}, \mathbf{F}_{r}, \mathbf{M}_{r}, \sigma),
$$

其中 `x_p` 为刚段近端状态，`F_r` 与 `M_r` 为刚段总外力和关于近端的总外力矩。当前生产路径中，磁场在近端位置 `p_p` 计算：

$$
(\mathbf{F}_{m}, \mathbf{M}_{m})=\mathcal{W}_{m}(\mathbf{p}_{p}, \mathbf{R}_{p}, \mathbf{I}).
$$

本轮原型改为在刚性磁体中心

$$
\mathbf{p}_{c}=\mathbf{p}_{p}+\frac{L_r}{2}\mathbf{R}_{p}\mathbf{v}^{\ast}
$$

处计算磁载荷，并将其平移到近端：

$$
\mathbf{F}_{r}=\mathbf{F}_{m}+\mathbf{F}_{g},
$$

$$
\mathbf{M}_{r}=\mathbf{M}_{m,c}+(\mathbf{p}_{c}-\mathbf{p}_{p})\times \mathbf{F}_{m}+\mathbf{M}_{g}.
$$

若困难断裂主要由“磁载作用点使用近端导致的力矩臂缺失”引起，则该修正应降低断裂邻域的一阶最优性残差，并可能使 `alpha=0.25` 重新通过门禁。

## 实验方案

实验仍使用 `n3_mixed_base_i4 -> n3_mixed_rand20` 的两个关键点：

- `alpha=0.20`：此前稳定可线性化。
- `alpha=0.25`：此前为首次断裂邻域。

判定门禁保持不变：

- 总残差小于等于 `1.0e-2`。
- 末端边界残差小于等于 `2.0e-1`。
- 一阶最优性残差小于等于 `1.0e-3`。

仅当三者同时满足时，才允许发布任务敏感度。

```bash
XLA_PYTHON_CLIENT_PREALLOCATE=false conda run -n evolution_of_mcrs python experiment_records_ik_optimize/20260604232300_p2c10d_centered_magnetic_wrench_prototype/run_p2c10d_centered_magnetic_wrench_prototype.py \
```

## 数据分析

本轮结果表明，仅将磁载荷计算位置从刚段近端移动到刚段中心，并加入磁力关于近端的力矩臂，不能解释或修复 `alpha=0.25` 的敏感度断裂。更具体地说：

1. `alpha=0.20` 仍满足门禁，说明该中心磁载荷原型没有造成稳定点整体崩溃。
2. `alpha=0.25` 的一阶最优性残差升至 `27.435227`，高于原模型的 `20.587278`，说明简单作用点修正不能恢复断裂邻域。
3. 该结果与 P2c10c 的改善形成对照：P2c10c 有效降低最优性残差的部分，不太可能只是磁载荷作用点偏移，而更可能对应“刚性磁体段载荷对相邻柔顺段姿态、曲率或边界弯矩的反馈不足”。

从优化角度看，本轮仍满足“总残差较小但一阶最优性残差极大”的典型非驻点折中特征。该现象说明末端任务残差和边界平衡残差之间仍存在不可忽略的梯度冲突，当前解不适合用于隐式求导，也不允许发布任务敏感度。

## 实验结论

P2c10d 否定了一个简单假设：困难工况的敏感度断裂不能仅通过“把磁载荷从近端改到磁体中心并加入力矩臂”解决。

结合 P2c10c 与 P2c10d，目前更合理的机理判断是：

> 困难工况的主要问题不只是磁载荷作用点，而是刚性磁体段载荷经过段间界面后，未能在打靶模型中形成足够自洽的柔顺段弯矩、姿态和边界平衡响应。

因此，下一步不宜继续做磁载位置微调，而应进入以下二选一路线：

1. 建立更完整的刚段载荷到相邻柔顺段边界弯矩传播模型。
2. 将段间内力和内矩连续性从弱罚项提升为更强的物理约束，开展硬连续多段打靶原型。

## 下一步计划

优先建议推进“硬连续多段打靶”最小原型。原因是 P2c10b 已显示末端位置与末端边界项共同主导一阶最优性失效，而 P2c10d 表明简单磁载作用点修正无效；此时更应直接审计段间内力内矩连续性是否应作为主约束处理。

具体下一步：

1. 以 `alpha=0.20` 和 `alpha=0.25` 为测试点，构建硬连续多段打靶原型。
2. 将段间内力和内矩连续残差作为强约束或高优先级方程，而不是普通弱罚项。
3. 同时记录总残差、末端边界残差、一阶最优性残差、段间连续残差和条件数。
4. 若 `alpha=0.25` 的一阶最优性残差显著下降且稳定点不退化，再扩展到 `alpha=0.30, 0.35, 0.40`。
