# P2c10a 可线性化断裂阈值精定位实验记录

## 实验目的

本轮实验用于精确定位从稳定工况 `n3_mixed_base_i4` 过渡到困难工况 `n3_mixed_rand20` 时，任务敏感度开始失去可靠性的阈值。上一轮实验已经显示，`alpha=0.4` 附近存在可线性化断裂。本轮将区间收缩到 `alpha=0.20 -> 0.40`，以确定更精确的安全边界。

这里的“可线性化”指：在当前解附近，可以用一阶近似描述“线圈电流变化—内部打靶状态变化—导管末端位姿变化”的关系。若一阶最优性残差过大，即使末端残差较小，也不能发布可靠任务敏感度。

## 实验方案

电流路径采用线性过渡：

```text
I(alpha) = (1 - alpha) I_base + alpha I_target
```

其中：

- `I_base` 来自稳定工况 `n3_mixed_base_i4`；
- `I_target` 来自困难工况 `n3_mixed_rand20`。

本轮扫描：

```text
alpha = 0.20, 0.25, 0.30, 0.35, 0.40
```

每个 `alpha` 保留三类分支记录：

1. 当前延续分支：由上一个安全点延续而来。
2. 竞争分支：使用半幅参考初值。
3. 冷启动参考分支：使用当前 `alpha` 下的参考初值。

判定一个点可用于敏感度计算，必须同时满足：

| 判据 | 阈值 |
|---|---:|
| 总残差 | `<= 1.0e-2` |
| 末端边界残差 | `<= 2.0e-1` |
| 一阶最优性残差 | `<= 1.0e-3` |
| 分支任务空间差异 | `<= 1.0e-3` |
| 分支状态差异 | `<= 5.0` |

其中，一阶最优性残差是核心判据。它衡量当前解是否接近优化问题的稳定驻点。

## 实验结果

总体分类：`threshold-refined`。

关键结论：

- 最后一个安全点：`alpha = 0.20`
- 第一个断裂点：`alpha = 0.25`

## 数据分析

本轮结果比 P2c9j 更严格。此前粗定位显示 `alpha=0.4` 已断裂；本轮进一步说明，断裂实际上在 `alpha=0.25` 已经发生。

重要现象是：从 `alpha=0.25` 到 `alpha=0.40`，总残差始终保持在 `0.002` 左右，边界残差也保持在 `0.003` 到 `0.004` 量级，看似仍能较好拟合末端任务。但一阶最优性残差已经从 `alpha=0.20` 的 `7.81e-06` 跃升到 `alpha=0.25` 的 `20.59`。

这说明当前问题不是末端目标不可达，也不是简单的数值残差过大，而是优化问题的驻点条件在 `alpha=0.25` 起已经失效。换言之，该区域内得到的解可能只是“几何上看似接近”，但内部力学状态和数值最优性并不自洽，因此不允许发布任务敏感度。

该现象支持前一阶段的判断：困难工况的核心问题不是单次终点求解失败，而是沿电流过渡路径逐步出现可线性化断裂。

## 实验结论

1. `alpha=0.20` 可作为当前模型下的最后安全点。
2. `alpha=0.25` 已经进入不可发布敏感度区域。
3. 断裂区间被收缩到 `0.20 < alpha <= 0.25`。
4. 后续不应继续扩大 `alpha=1.0` 终点扫描，而应在 `alpha=0.20` 与 `alpha=0.25` 附近做失效归因。

## 下一步计划

下一轮应开展 P2c10b 断裂归因审计，重点比较 `alpha=0.20` 和 `alpha=0.25`：

1. 将总残差分解为末端任务残差、末端边界残差、段间连续残差、分支保持残差。
2. 计算各残差块对一阶最优性残差的贡献。
3. 审查刚性磁体段载荷到末端位姿传播是否存在显式耦合不足。
4. 若段间连续残差主导失效，则转入硬连续多段打靶；若刚段载荷传播主导失效，则优先做刚段载荷传播修复。
