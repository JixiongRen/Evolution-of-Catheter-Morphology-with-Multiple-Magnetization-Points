# P2c132 单点中段磁体候选分支一致性复核

## 实验目的

P2c131 发现 `n1_mid_z_rand15_a010` 的三维末端位置任务可通过基线门禁。本轮检查该结果是否依赖 FK oracle 初值。如果不同合理初值收敛到同一中心线分支，才允许后续进入扰动重求解；否则只能作为初始化敏感候选。

## 实验方案

固定中段单磁体轴向磁化、随机电流 `alpha=0.10` 和三维末端位置任务。测试四种初值：FK oracle 内力、半 FK oracle 内力、零状态、零电流 FK oracle 内力。所有求解使用与 P2c131 相同的显式刚段载荷残差和相同门禁。

分支一致性门禁定义为：至少两条过基线路径之间的中心线最大逐点漂移不超过 `1e-3 m`。

## 基线结果

- 初值 oracle：基线门禁 True；位置误差 3.296e-07 m；一阶最优性 1.956e-10；条件数 8.243e+05；载荷传播比例 1.122e-06；失败分类 通过。
- 初值 half_oracle：基线门禁 False；位置误差 2.636e-06 m；一阶最优性 5.287e-08；条件数 1.535e+07；载荷传播比例 2.933e-06；失败分类 条件数病态。
- 初值 zero_state：基线门禁 False；位置误差 2.636e-06 m；一阶最优性 5.094e-08；条件数 1.535e+07；载荷传播比例 2.933e-06；失败分类 条件数病态。
- 初值 zero_current_oracle：基线门禁 False；位置误差 8.953e-06 m；一阶最优性 2.183e-06；条件数 3.212e+07；载荷传播比例 6.213e-05；失败分类 条件数病态。

## 分支漂移

- oracle vs half_oracle：两者均过基线 False；最大中心线漂移 7.411e-03 m；分支门禁 False。
- oracle vs zero_state：两者均过基线 False；最大中心线漂移 7.411e-03 m；分支门禁 False。
- oracle vs zero_current_oracle：两者均过基线 False；最大中心线漂移 9.121e-03 m；分支门禁 False。
- half_oracle vs zero_state：两者均过基线 False；最大中心线漂移 1.878e-17 m；分支门禁 False。
- half_oracle vs zero_current_oracle：两者均过基线 False；最大中心线漂移 2.694e-03 m；分支门禁 False。
- zero_state vs zero_current_oracle：两者均过基线 False；最大中心线漂移 2.694e-03 m；分支门禁 False。

## 结论

分支一致性结论：未通过。本轮仍不发布灵敏度；若存在至少两条过基线且互相满足分支漂移门禁的路径，下一轮才允许进行小扰动重求解。

## 下一步计划

若分支一致性通过，执行 P2c133：对该中段单磁体候选做 `eps=0.005` 和 `0.010` 的扰动重求解一致性检查。若不通过，先归因初始化敏感或多平衡竞争，不进入扰动扫描。
