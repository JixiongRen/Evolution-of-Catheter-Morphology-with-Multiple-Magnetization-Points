# P1 A1 三点残差空间灵敏度门禁记录

## 一、实验目的

本轮原计划运行 A1/A2 六个代表点，但命令中引用的 A2 路径缺少分支状态文件，实际只被审计脚本识别并运行了 A1 三个代表点。因此本文只作为 A1 三点 P1 门禁记录，不能称为六点完整门禁。

## 二、实验设置

- 代表点：A1-pt01、A1-pt12、A1-pt13。
- 灵敏度模式：残差雅可比奇异值分解。
- 谱滤波：硬截断。
- `svd_rcond=1e-9`。
- 电流通道：自动选择两个响应最大的通道。
- 扰动步长：电流 `0.25/0.125/0.0625 A`，推进 `0.5/0.25/0.125 mm`。
- 强弱响应分类：按“状态-通道”的最大有效末端位移判断，不按单行样本临时漂移。

完整命令见 `commands.sh`。

## 三、结果

本轮得到 27 条有限差分审计记录。

总体统计如下：

- 有效强响应样本：21 条。
- 有效弱响应样本：0 条。
- 不可审计样本：6 条。
- 强响应相对误差中位数：约 `1.19%`。
- 强响应相对误差 90 分位：约 `8.32%`。
- 强响应方向角 90 分位：约 `4.57 deg`。

按统计门禁看，A1 有效强响应样本满足 P1 的误差和方向角要求。

## 四、逐点判断

### 4.1 A1-pt01

pt01 的两个电流通道和推进量通道均通过回环门禁。最大相对误差约 `15.76%`，来自最小推进步长；两个电流通道均保持在低误差范围。

判断：pt01 通过 P1。

### 4.2 A1-pt12

pt12 的两个电流通道在 `rcond=1e-9` 下显著改善。上一轮 `rcond=1e-8` 时曾出现 `15%` 到 `45%` 的幅值偏差，本轮大部分电流样本降至 `1%` 以内，仅通道 3 的 `0.25 A` 大步样本约 `8.32%`。

判断：pt12 通过 P1。

### 4.3 A1-pt13

pt13 的推进量通道通过回环门禁，误差约 `1.1%` 到 `2.5%`。但两个强电流通道在所有三档步长下均未通过回环门禁，不能纳入单分支灵敏度统计。

判断：pt13 的推进方向可审计，但强电流方向属于分支不稳定，不应判定为灵敏度公式失败，也不能作为 P1 通过样本。

## 五、结论

A1 在 pt01 和 pt12 上已获得可信灵敏度；pt13 暴露的是分支保持问题。按计划文档约束，只要代表点出现强通道回环失败，就必须前置分支管理，不能直接把 pt13 纳入 P2 的单分支线性模型解释。

因此，A1 尚不能无条件进入 P2 全量小回归。可行的下一步是：

1. 对 pt13 启动分支管理最小修正，优先检查小步回环和初值路径。
2. 若 P2 小回归先行，只能将其标记为“带分支风险的 A1 外层优化试验”，不能称为完整 P1 通过后的正式回归。
