# P2c30 随机强电流三磁体多扰动幅值复核

## 实验目的

P2c29 表明 `n3_mixed_rand20, alpha=0.4` 可通过 `direct_saved + trf_strict_restart` 精修转化为可发布敏感度样本。本实验复核该结论在多个扰动幅值下是否稳定。

## 实验方案

固定工况：

```text
case = n3_mixed_rand20
alpha = 0.4
baseline = direct_saved + multi-strategy refinement
eps = 0.005, 0.01, 0.02
```

每个扰动点均重新求解，并检查一阶最优性、界面载荷传播、局部线性化和分支稳定。

## 判定标准

所有扰动幅值均需满足：

- 基线解通过静态门限。
- 正负扰动重求解通过静态门限。
- 最大局部线性化误差小于 `0.05`。
- 最大轴线分支漂移小于 `1e-3 m`。

## 实验结果

本轮实验总墙钟时间为 `64.69 s`。运行命令显式关闭 JAX 显存预分配，并强制使用 CPU 后端。日志中仍出现一次 CUDA 插件初始化警告，但计算过程完成，结果文件完整生成。

基线解采用 `direct_saved + trf_strict_restart`，通过静态门限：

| 指标 | 数值 |
|---|---:|
| 末端位置误差 | `6.66e-7 m` |
| 一阶最优性残差 | `1.86e-8` |
| 界面边界残差 | `6.73e-3` |
| 雅可比矩阵条件数 | `1.73e6` |
| 最大冗余内力比例 | `0.069` |
| 求解函数评估次数 | `243` |

多扰动幅值复核结果如下：

| 扰动幅值 | 是否可发布 | 灵敏度模长 `m/alpha` | 最大线性化误差 | 最大一阶最优性残差 | 最大分支漂移 |
|---:|---|---:|---:|---:|---:|
| `0.005` | 是 | `2.20e-5` | `1.78e-7` | `3.24e-7` | `3.06e-4 m` |
| `0.010` | 是 | `3.60e-5` | `1.75e-6` | `3.55e-7` | `7.35e-4 m` |
| `0.020` | 否 | `2.72e-5` | `8.15e-6` | `7.10e-8` | `1.26e-3 m` |

其中 `eps=0.02` 的失败事件已记录在 `failure_events.jsonl`。失败原因不是一阶最优性退化，也不是局部线性化误差超限，而是轴线分支漂移超过 `1e-3 m` 门限。

## 数据分析

本轮实验进一步确认：`n3_mixed_rand20, alpha=0.4` 并非完全不可求导工况，而是存在有限的局部可信邻域。当扰动幅值不超过 `0.01` 时，扰动后重求解能够保持较小的一阶最优性残差，局部线性近似误差也远低于门限，因此可以作为小邻域任务敏感度样本。

但是，`eps=0.02` 时虽然线性化误差和一阶最优性残差仍然较小，轴线分支漂移已经超过门限，且灵敏度向量方向相对 `eps=0.005` 和 `eps=0.01` 出现明显变化。这说明当前工况附近可能存在分支边界或多解竞争区域。该现象的严重性低于末端位置不收敛或静力平衡失败，但足以阻止将该扰动半径下的灵敏度作为高置信结果发布。

从物理角度看，三磁体强电流组合在 `alpha=0.4` 附近可能仍能维持末端任务响应的一阶近似，但导管整体形态对扰动更加敏感。后续应将末端任务敏感度与轴线形态漂移分开评价：前者用于逆运动学外层更新，后者用于判断是否接近分支切换或形态不稳定区域。

## 实验结论

本轮结论如下：

- 已验证结论：`n3_mixed_rand20, alpha=0.4` 在 `eps<=0.01` 的小扰动邻域内可以获得可发布的局部任务敏感度。
- 已验证结论：`eps=0.02` 不应发布为高置信灵敏度，因为轴线分支漂移超过当前门限。
- 待验证假设：该工况的稳定扰动半径位于 `0.01` 到 `0.02` 之间。
- 适用工况：三磁体混合磁化、随机强电流组合、当前目标比例 `alpha=0.4`、当前网格与打靶参数。
- 已知失效边界：较大扰动下出现形态分支漂移，可能对应多解竞争或局部形态不稳定。

## 下一步计划

下一轮建议进行扰动半径加密扫描，优先测试 `eps=0.0125, 0.015, 0.0175, 0.02`，定位 `n3_mixed_rand20, alpha=0.4` 的分支漂移阈值。若阈值稳定存在，应进一步输出该工况的工程建议：外层逆运动学步长不宜超过对应扰动半径，并应在接近该区域时启用分支漂移监测。
