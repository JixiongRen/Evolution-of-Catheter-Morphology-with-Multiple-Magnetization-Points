# 跨版本污染说明

日期：2026-07-13

本目录最初用于失败强通道复审，但原始批处理进程在部分结果提交后仍继续运行。随后仓库代码进入新的 P0 审计字段修正阶段，残余进程继续向本目录写入了新的 `best_accept` 结果。

因此，本目录不能作为统一代码版本下的完整 P1 证据使用。已提交的 `last_accept` 聚合结果仍可作为历史参考，但任何后续结论都必须重新创建独立实验目录，在同一代码提交和干净记录口径下重跑。

处理规则：

- 不再向本目录追加正式 P1 结论。
- 不使用本目录估计 A1/A2 灵敏度总体质量。
- 后续 P1 应在新的唯一时间目录中执行，并记录 `git_tracked_dirty`、`git_untracked_count` 和完整门禁字段。
