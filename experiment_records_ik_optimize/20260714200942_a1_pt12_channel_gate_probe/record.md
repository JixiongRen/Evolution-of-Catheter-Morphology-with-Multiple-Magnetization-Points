# A1-pt12 可靠通道门禁复测记录

## 实验目的

上一轮灵敏度审计显示，A1-`pt_12` 附近只有部分控制通道在回环门禁下保持稳定。因此，本实验将外层优化限制在可信通道内，检验这种保守更新是否能改善 `pt_12` 的收敛质量。

## 门禁策略

根据 `20260714195941_a1_pt12_sensitivity_audit` 的结果，生成 `a1_pt12_channel_gate.csv`：

- 允许精修通道：`I3`、`I6`、`x`。
- 禁用通道：`I0`、`I1`、`I2`、`I4`、`I5`、`I7`。
- 单步上限：`I3=0.125 A`，`I6=0.125 A`，`x=0.25 mm`。

这里的“可靠通道”是指有限差分回环通过、方向误差较小、且没有表现出明显分支跳变的控制通道。

## 实验条件

- 初始状态：`pt_13` 的成功分支状态。
- 目标点：`pt_12`。
- 导管配置：A1，单点轴向磁化。
- 重力：关闭。
- 离散化：`M_list=5`。
- FK 容差：`1e-5`。
- 成功阈值：真实刚性末端误差不超过 `5 mm`。
- 运行设备：GPU，`NVIDIA GeForce RTX 5060 Laptop GPU`。

## 实验结果

输出目录：

`DELIVER_TO_EXP/formal_experiments/20260714201006_A1_A2_5mm_supervised_IK_no_gravity/`

| 指标 | 结果 |
|---|---:|

| FK 分类 | `GOOD` |
| 外层迭代数 | 25 |

| 墙钟时间 | `138.9 s` |
| 终止原因 | 达到最大外层迭代数 |
| 启用通道 | `I3`、`I6`、`x` |

## 结果分析

相比 `pt_13 -> pt_12` 直接反向延拓的最后接受误差约 `27.465 mm`，可靠通道门禁将误差降低到 `21.578 mm`。同时，本轮没有出现拒绝停滞，说明保守通道确实提升了局部更新稳定性。

但该策略仍未使 `pt_12` 达到 `5 mm`。这说明当前问题不只是“错误通道导致发散”，还存在更深层限制：可信通道的可达方向不足，或者需要更细的圆周角度延拓、多候选分支搜索，才能进入目标附近的好分支。

## 结论

可靠通道门禁是有效的稳定化手段，但不能单独解决 A1-`pt_12`。后续应把它作为安全更新模块保留，同时增加更细粒度的路径延拓策略。

## 下一步

1. 在 `pt_13` 与 `pt_12` 之间插入中间角度目标，测试是否能连续推进到 `pt_12`。
2. 对 A1 正式 20 点实验，不应直接跨困难点传播热启动，而应在困难点附近启用角度分段延拓。
3. 若分段延拓仍失败，再将 `pt_12` 归入疑似局部不可达或多分支难控点。
