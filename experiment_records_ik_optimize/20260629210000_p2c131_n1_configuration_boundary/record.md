# P2c131 单点磁体位置配置边界

## 实验目的

P2c130 表明 `n1_tip_z_rand15` 即使降维和降低电流比例仍不能通过基线门禁。本轮更换单点磁体所在刚段，判断单点磁控失败是否具有明显配置依赖性。

## 实验方案

构造三种单磁体配置：基端刚段轴向磁化、中段刚段轴向磁化、末端刚段轴向磁化。电流采用 `n1_tip_z_rand15` 的随机电流并乘以 `alpha=0.10`。每种配置先用 FK oracle 生成目标末端位置，再在显式刚段载荷残差模型下求解 shooting 基线门禁。

任务分两类：三维末端位置任务和有效一维任务。有效一维任务只约束从零电流末端到目标电流末端的位移方向；横向误差只记录，不作为该任务的否决项。

## 结果

- n1_base_z_rand15_a010，effective_1d：门禁 False；位置误差 3.311e-03 m；一阶最优性 3.798e-07；条件数 6.830e+07；载荷传播比例 1.859e-07；失败分类 条件数病态。
- n1_base_z_rand15_a010，position_3d：门禁 False；位置误差 4.649e-06 m；一阶最优性 2.970e-08；条件数 2.671e+07；载荷传播比例 5.276e-06；失败分类 条件数病态。
- n1_mid_z_rand15_a010，effective_1d：门禁 False；位置误差 5.400e-03 m；一阶最优性 2.565e-07；条件数 4.358e+07；载荷传播比例 2.406e-07；失败分类 条件数病态。
- n1_mid_z_rand15_a010，position_3d：门禁 True；位置误差 3.296e-07 m；一阶最优性 3.145e-11；条件数 8.243e+05；载荷传播比例 1.122e-06；失败分类 通过。
- n1_tip_z_rand15_a010，effective_1d：门禁 False；位置误差 3.849e-03 m；一阶最优性 1.350e-05；条件数 1.018e+08；载荷传播比例 3.929e-07；失败分类 一阶最优性退化。
- n1_tip_z_rand15_a010，position_3d：门禁 False；位置误差 1.286e-03 m；一阶最优性 2.252e+02；条件数 2.201e+08；载荷传播比例 3.206e-04；失败分类 任务误差超限。

## 结论

本轮发现至少一个单点配置通过基线门禁。该结果只能说明配置依赖性存在，尚不能发布灵敏度；下一步必须先对通过配置做多初值分支一致性复核，复核通过后才允许扰动重求解。

## 下一步计划

若本轮没有通过样本，应将单点磁控主线转为不可发布边界归纳，并优先推进两点磁控三维末端位置灵敏度；若存在通过样本，应只对通过样本继续分支一致性复核。本轮使用 FK oracle 生成目标和初始内力，因此只能作为配置筛选证据，不能作为灵敏度发布证据。
